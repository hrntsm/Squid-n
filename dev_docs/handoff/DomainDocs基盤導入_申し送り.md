# Domain Docs 基盤導入（CONTEXT.md・ADR） 申し送り

作成日: 2026-09-13
対象: `CONTEXT.md`、`dev_docs/adr/`、`AGENTS.md`、`dev_docs/specs/`、`docs/`、`dev_docs/v_and_v/`

## 背景

設計判断と用語の記録先が、時系列で肥大化した handoff と実装リンク中心の用語集に分かれており、
「いま有効な判断」「いま使う語」を引く場所が定まっていなかった。domain-docs-bootstrap により、
ドメイン語彙の正本と ADR を導入し、dig-with-docs を運用できる初期状態を作った。

## 変更内容

### 1. ドメイン語彙の正本 CONTEXT.md

- ルートに `CONTEXT.md` を新設。階と剛床・床・壁・断面と材料・柱梁接合部・解析・禁止語の
  7 グループ。
- `dev_docs/specs/用語集.md` は実装リンク付き詳細辞書へ位置づけを変更（冒頭に正本の明記）。

### 2. 設計判断の正本 dev_docs/adr

- `dev_docs/adr/` に ADR 0001〜0013 を作成。今後の重要な設計判断は ADR を正本とし、
  handoff は実装経緯・検証・申し送りに専念する。ADR 番号はディレクトリ内の新規連番で、
  既存文書の D 番号は文書ローカルとして扱い変換していない。

### 3. 壁版の用語整理

- 総称を「壁エレメントにならない壁版」、剛性算入されない部分集合を「剛性算入なしの壁版」に改名。
- 旧称「荷重だけを持つ壁版」「荷重のみの壁版」は `_Avoid_` とした。
- `docs/` 3 ページ（`preparation/README.md`・`model_io/03_ST-Bridge_要素別変換状況.md`・
  `calc_basis/04_要素剛性/05_壁エレメントモデル.md`）の文言を更新。コード側の
  `ModelClass::WallPlateLoadOnly`・モデル化図の凡例は別課題。

### 4. TVLEM の撤回

- 耐震壁は壁エレメント置換モデルを正式採用とし、壁谷澤 TVLEM は採用しない（ADR 0013）。
- 撤回の理由（改訂前の P5.5・設計書 §6.6 の記載）: TVLEM は採用文献の確定が着手前ブロッカーで、
  文献間でパラメータ定義（ばね配置・回転中心・スケルトン算定式）が異なり、実験照合
  （妥当性確認、Category B）が必須だった。現行の壁エレメント置換モデルは実装・GUI・入出力・
  数量積算・V&V の経路が揃っている。
- 設計書 §6.6 ほかを現行仕様として書き直し、P5.5 を「MS 実装済み・TVLEM 撤回」へ改訂。
- V&V 索引 #16・未検証一覧・原典照合リスト・P9・P5 の参照を更新（個別の V&V レポート・
  `pending_items.md` は歴史的記録として書き換えていない）。

### 5. スキーマ互換方針の明文化

- スキーマ版間のマイグレーションは git タグで行うリリース以降のみ実装する（未リリースの間は
  破壊的変更に移行コードを書かない）ことを `AGENTS.md` に明記。
- `残課題一覧.md` の「未判断」としていた 3 件（旧 `three_side_slit`・旧 `misc_walls`・旧
  `ThIntegrator`）は、この方針で対応不要として削除した。

## 検証

- `CONTEXT.md` の用語が既存実装（core の型定義・用語集）と一致することを確認。
- ADR の Legacy source のファイルが実在することを確認。
- 変更した参照リンク（ADR・CONTEXT.md）の相対パスを確認。
- 実装コードは変更していない。

## 残課題

- コード側の旧称（`ModelClass::WallPlateLoadOnly`・モデル化図の凡例「荷重のみ(剛性に算入しない)」・
  doc コメント）の改名（実装コード、別課題）。
- 質点系モデルなど、CONTEXT.md に未記載の用語は dig-with-docs の運用で追加する。
