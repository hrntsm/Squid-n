# 高強度せん断補強筋の製品別対応の撤回（申し送り）

Issue #311。高強度せん断補強筋の製品別対応を実装・docs から削除し、非対応グレードを fail loud で停止するようにした。決定は [ADR 0031](../adr/0031-withdraw-high-strength-shear-reinforcement.md) を正とする。

## 削除した実装・API

- `squid_n_design_jp::material_strength::high_strength_hoop` モジュール（`high_strength_group`・`HighStrengthGroup`・`high_strength_pw_cap`・`high_strength_w_ft`・`ultimate_hoop_sigma_wy`・`ultimate_hoop_nu0`・`ultimate_hoop_pw_cap`）
- `squid_n_core::material_grade::{is_high_strength_shear_grade, is_high_strength_shear_material, SHEAR_REBAR_GRADES}`
- `squid_n_design_jp::material_strength::shear_capacity_high_strength`、`rc::allowable::effective_damage_control`
- `UltimateShearOptions::shear_grade`、`MemberDemand::q_simple`
- `rc_wall_capacity::RcWallShearInput::high_strength_shear_rebar`、`rc::wall_nonlinear::WallShearTrilinearInput::high_strength_shear_rebar`、`srrc::beam_nonlinear::SrcNonSolidWebShearInput::high_strength_shear_rebar`

耐震壁 Qu と SRC 非充腹梁のせん断終局強度は、高強度の分岐を削除して常に κ=0.053（耐震壁の分母は `M/(Q·D)+0.12`、SRC 非充腹は従来どおり）とした。終局検定の QL=Q0 読み替えと、対応する `simple_beam_q0_by_gravity_cases` の終局経路での利用も削除した（同関数自体は許容応力度検定で継続使用する）。

## 未対応時の停止箇所

対応グレードは `SR235`・`SR295`・`SD295`（`SD295A`/`SD295B` を含む）・`SD345`・`SD390`・`SD490`。判定は `squid_n_core::material_grade::is_supported_shear_rebar_grade`、文言は `unsupported_shear_rebar_message`。未対応グレードと `fy` 未設定をまとめた判定は `shear_rebar_material_issue` に集約する。

- RC 許容応力度検定・SRC 検定: `CheckOutcome::Skipped`（検定不能・理由付き）
- RC 終局検定: `squid_n_design_jp::ultimate::collect_rc_ultimate_checks` が `Err`
- 解析前チェック: `squid_n_element::factory::input_check::member_strength_issue` と耐震壁の `WallElement::wall_shear_capacity_issue` がエラー（増分・時刻歴）
- 壁エレメントのせん断耐力: 算定不能（`WallElement::shear_capacity_of` は 0）

対応グレードの材料を割り当てているのに `fy` が未設定または 0 以下の場合も同じく入力不備として停止する。無言で既定 295 N/mm² を用いると `SR235`（`fy = 235`）で σwy を 235 から 295 へ増やす危険側の評価になるためである。既定 295 N/mm² は材料未割当のときだけ用いる。

## 通常強度 σwy の扱い

せん断補強筋の σwy は、割り当てた材料の `f_y` から解決する（`squid_n_core::material_grade::shear_rebar_yield_strength`）。材料未割当のときは SD295 相当の代表値である 295 N/mm² を既定とする。対応グレードで `f_y` が未設定の場合は入力不備として停止し、既定値で補わない。高強度専用だった製品別上限は用いない。

## 既知の残課題と実害の評価

- `ElementKind::Brace` は解析前チェック `squid_n_element::factory::input_check::member_strength_issue` の対象外である（`nonlinear_input_issues` は `Beam`・`Fiber`・`MultiSpring`・`Wall` のみを検査する）。ブレースはトラス要素として軸力のみを扱い局所せん断を用いないため、せん断補強筋の未対応グレード・`fy` 未設定が実害となる経路はない。
- 増分解析の実行後にモデルのせん断補強筋材料の `fy` を消したまま保有水平耐力計算を行う「結果陳腐化」の経路では、純関数 `squid_n_core::rc_capacity::rc_capacity_input_from_rect` の既定 295 N/mm² に到達し得る。解析結果と現在のモデル状態の不整合という結果ライフサイクル上の既存論点であり、本 Issue で導入したものではない。
- 壁縦筋 \( \sigma_y \)（\( \beta_u \) 用）の 295 N/mm² フォールバックは、材料未割当・`fy` 未設定のいずれでも働く既存の残課題である（[原典照合リスト](../v_and_v/原典照合リスト.md)）。本 Issue では変更していない。

## 再実装の条件

対象製品の技術評定書（pw 上限・σwy・ν0・w_ft の原典）を揃え、製品別式の安全側／危険側を判定してから再実装する。名称が `SD*`・`SR*` 以外を一律に高強度とみなす一般判定は危険側のため再採用しない。詳細は [ADR 0031](../adr/0031-withdraw-high-strength-shear-reinforcement.md) を参照。
