# ログ表示のレベルとゼブラ 申し送り

作成日: 2026-08-15
対象コード: `crates/squid-n-app/src/app/mod.rs`（`LogLevel` / `EventLog::show`）
関連文書: `../specs/UI設計.md` §1.3、`TONMANUAL.md`（下ドックのログ）

## 1. 目的

下ドックのログはレベルを文字色だけで示しており、色が分からないと重要度が読めない。
また件と件の境がなく、折り返し・改行入りのメッセージで 1 件の範囲が追いづらい。
文頭にレベル名を出し、件ごとに背景を交互にして区切る。

## 2. 表示規約

- 文頭ラベル: `情報` / `注意` / `エラー`。列幅は「エラー」基準で固定し、時刻と本文の
  開始位置を揃える。
- 折り返し・本文中の改行の続き行はメッセージ列からぶら下げる。
- レベル色（Info＝`GRAY_700`、Notice＝`WARN_TEXT`、Error＝`ERROR_RED`）を
  ラベル・時刻・本文のすべてに付ける。背景は偶奇のみ（白 / `lighten(GRAY_100, 0.6)`）。
- ゼブラは見た目の行ではなく `LogEntry` 1 件単位。罫線は付けない。

描画は `EventLog::show`。`LogLevel::label` / `color` が文言と色の単一情報源。

## 3. 残課題

なし。
