# ナビゲータ解析結果ツリー改修 申し送り

作成日: 2026-08-15

## 1. 背景

左ドック・ナビゲータの結果一覧を解析種別で階層化し、振動荷重ケース（立体時刻歴・
質点系）を静的荷重ケースと分離して扱う改修。

## 2. 実装概要

### データモデル（`squid-n-core`）

- `VibrationCaseId` / `LumpedVibrationCaseId`（`ids.rs`）
- `VibrationCase` / `LumpedVibrationCase` と方向・次元 enum（`model/vibration.rs`）
- `Model.vibration_cases` / `Model.lumped_vibration_cases`
- ケース名生成・同名 upsert: `spatial_vibration_case_name`, `upsert_vibration_case` 等

### 結果（`squid-n-app`）

- `ResultsBundle.time_histories` / `lumped_results`（複数保持）
- 表示窓口: `time_history` / `lumped`（従来どおり）
- 旧 `.scz` 移行: `migrate_legacy_time_history`, `migrate_legacy_lumped`
- 適用: `apply_time_history_result`, `apply_lumped_mass_result`（`app/vibration.rs`）

### UI

- `nav_results.rs` — 解析結果ツリー（時刻歴ケース子、質点系 2 グループ）
- `nav_vibration.rs` — 振動荷重ケースセクション
- `inspector.rs` — 振動ケース選択時の読み取り専用設定
- 画面切替集約: `apply_result_tree_action`

利用者向け: [docs/result_view/14_ナビゲータの解析結果ツリー.md](../../docs/result_view/14_ナビゲータの解析結果ツリー.md)

## 3. 確定設計（2026-08-15）

| 項目 | 集約場所 |
|------|----------|
| 振動ケース名 | `squid_n_core::model::vibration` |
| 実行時 upsert | `Model::upsert_vibration_case` / `upsert_lumped_vibration_case` |
| 結果 upsert | `ResultsBundle::upsert_time_history` / `upsert_lumped_result` |
| TH 適用（stale 非立て） | `apply_time_history_result` |
| 質点系 TH / 固有値のみ | `apply_lumped_mass_result` |
| ツリー構築 | `build_result_tree` |
| 葉クリック | `apply_result_tree_action` |
| 振動ケース選択 | `focus_spatial_vibration_case` / `focus_lumped_vibration_case` |
