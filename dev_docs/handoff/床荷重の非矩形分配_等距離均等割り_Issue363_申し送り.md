# 床荷重の非矩形分配 等距離均等割り（Issue #363）申し送り

## 概要

非矩形床の多角形負担面積法（`polygon_edge_areas`）は、各セル中心から最も近い辺へセル面積を
帰属する。従来は 2 乗距離の厳密な `<` 比較で最近接辺を選んでいたため、等距離のセルは
`candidate_edges` の先頭 1 辺へ全量が配分されていた（先勝ち）。本 Issue では、最小距離に
並ぶ辺へセル面積を**均等割り**する形へ変更した。これにより L 形の凹辺で生じていた
有限線分拡張方式との最大 ±22% 差と、頂点列の並べ方に依存する荷重配分の非一意性が解消する。

## 背景

[床荷重XY両方向分配 基準資料比較（2026-09）](../v_and_v/床荷重XY両方向分配_基準資料比較_2026-09.md)
の追加検証（PR #356）で、L 形の凹角を共有する 2 辺（e2・e3）に挟まれた領域は、両辺への
垂線の足が共有端点へクランプされるため距離が恒等的に一致し、等距離集合が線ではなく面になる
ことを確認した。先勝ちではこの領域のセルが e2 へ偏り、e2 が過大・e3 が過小となって最大 ±22%
の差が出る。また、同じ幾何でも頂点列の開始位置や向きで物理辺への帰属結果が変わり、荷重配分が
非一意になる（L 形 3.701e-1・十字形 6.755e-1）。等距離を均等割りすれば、これらが解消する。

## 決定

- 等距離判定は**セル寸法（`dx.max(dy)`）× `1e-9` の相対許容差**とする。距離は 2 乗距離で
  評価し、`d2 <= d_min_sq + tie_limit_sq`
  （`tie_limit_sq = tie_tol * (2.0 * d_min_sq.sqrt() + tie_tol)`）を満たす辺を等距離とみなす。
  これは PR #356 の検証済み等分版 `current_split_edge_areas` と同一規則である。
- 最小距離の辺 1 本=100%、2 本=1/2、3 本=1/3… と均等配分する。
- 切替オプション・旧方式互換モード・新 `DistributionMethod` は追加しない。
- 公開 API・`DistributionMethod`・200×200 固定格子・セル中心サンプリング・有限線分距離は
  維持する。

## 実装

- `crates/squid-n-load/src/floor/polygon.rs`
  - 定数 `TIE_REL_TOL: f64 = 1e-9` を追加。
  - `polygon_edge_areas` のセル走査を、候補辺ごとの 2 乗距離を `dists_sq`（ループ外で 1 回
    確保）へ保存し、最小距離に並ぶ辺を数えてセル面積を均等に配る形へ変更。
  - `distribute_polygon`・`polygon_edge_areas` の doc を現行仕様（等距離は複数辺へ均等割り）
    へ更新。凹形状の乖離に触れていた残課題の記述は削除し、本申し送りと V&V へ移した。
- 片持ち（`cantilever.rs`）が使う候補辺部分集合経路も同じ関数を通るため、非候補辺が 0 の
  まま等距離の均等割りが働く（ケース11 で回帰固定）。

## 検証

- 検証コード `crates/squid-n-load/src/floor/distribution_verification.rs` を整理した。
  - 本番と二重管理だった等分版 `current_split_edge_areas` を削除し、本番 `polygon_edge_areas`
    を直接使う。
  - #363 以前の本番規則（200×200・厳密 `<`・候補先頭へ全量）をテスト内だけで再現する
    `polygon_unsplit_reference_edge_areas` を追加。等距離が生じない形状で結果が不変で
    あることを回帰比較するために使う（本番経路には残さない）。
  - `run_split_case` を「本番 / 先勝ちリファレンス / 有限線分拡張」の 3 方式比較へ再構成し、
    `expect_ties` で本番と先勝ちリファレンスの一致・相違を厳密（相対 1e-9）に assert する。
  - `case9_vertex_order_invariance` は本番の頂点順序不変性のみを確認する形へ変更し、順序
    依存を示していた `assert_maps_differ` を削除。
  - 新規: `case10_convex_shapes_unchanged_by_tie_split`（長方形・台形・凸五角形・正八角形で
    本番 == 先勝ちリファレンス）、`case11_candidate_subset_keeps_tie_split`（候補辺部分集合
    経路の総和保存・非候補辺 0・e2/e3 均等割り）。
- 実行コマンドと結果:
  - `cargo test -p squid-n-load --locked` : 204 passed / 0 failed
  - `cargo clippy -p squid-n-load --all-targets --locked -- -D warnings` : 警告なし
  - `cargo fmt --all -- --check` : 差分なし
- 主な数値（`w`=0.003 N/mm²、200×200 固定格子、本番 vs 有限線分拡張方式の最大相対差）:
  - L 形: 本番 vs 先勝ち 22.0766%、本番 vs 拡張 0.0298%（従来 ±22% が 0.03% へ）
  - T 形: 0.0084%、十字形: 0.0000%
  - 凸五角形: 1.6023%、正八角形: 0.0560%（本番 vs 先勝ちはいずれも 0.0000%）
  - U 字: 1.9807%（本番 vs 先勝ち 10.1974%）
- 頂点順序不変性（200×200 本番）: L 形・十字形とも最大相対差 0.000e0。

## 残課題

- 固定 200×200 格子の位相に起因する深い U/C 字形状の 1〜2% 残差。U 字の内側底辺が担う帯
  y∈[2000, 4000] を 60 mm セルでは 34 行（=2040 mm）と数え、真値 2000 mm を 2% 過大に
  評価する。格子の決め方（セル寸法上限方式など）の見直しを含む別 Issue の検討事項。
- 台形（ケース4a）の辺3 の約 1.99% 差について、基準格子を細分化した辺ごとの参照解を算定し、
  比較方式側の粗さ由来かを切り分ける収束確認が未了。
- 等距離が生じる凸形状（例: 直角二等辺三角形では直角を挟む 2 辺の垂直二等分線が格子中心を
  通る）では、本番の結果が先勝ちから変わり得る。凸形状一般で等距離が生じないとは主張しない。

## 影響

- 非矩形床（L 形・T 形・十字形・U 字など凹形状）の辺荷重配分が変わる。総和保存は維持され、
  凹辺の負担が対称化・平滑化される。
- 矩形床は従来どおり `distribute_rect`（TriTrapezoid・OneWay・TributaryArea）を通り、本変更の
  影響を受けない。大きな矩形（30000×20000）の polygon 経路も等距離が生じないため不変。
- 後方互換性は維持しない方針（[ADR 0014](../adr/0014-schema-compatibility.md)）に従い、
  旧方式との切替は設けない。
