# 耐震壁と保有水平耐力の連携 申し送り

**起票:** 2026-07-25（保有水平耐力プッシュオーバー是正 PR #121 のレビュー中に判明）
**扱い:** PR #121（プッシュオーバー）のスコープ外として起票。**#121 マージ後に着手し、
下記のうち開口低減（耐力用 r2）は対応済み。** 詳細な監査結果と残課題は
[dev_docs/v_and_v/耐震壁_敵対的レビュー_2026-07.md](../v_and_v/耐震壁_敵対的レビュー_2026-07.md) を参照。

## 背景

PR #121 で、告示の Ds 表（耐力壁／筋かいの部材群としての種別 × βu × 柱はりの部材群と
しての種別）と耐力壁の種別（WA〜WD）を実装し、耐震壁を βu・部材種別の算定対象へ
組み込んだ。その過程で、耐震壁まわりに **#121 の範囲では直さない**残課題が複数見つかった
ため、ここに集約する。

耐震壁は `squid_n_element::wall::wall_panel::WallPanelElement`（4 節点 24 自由度。
壁柱＝仮想中央柱を上下の剛梁で挟む構成）であり、シェル要素ではない。幾何は
`wall_panel_geometry`（壁長 lw＝上下辺長さの平均、上下辺は標高 z でソートして判別）を
要素実装と保有水平耐力側で共有している。

## 残課題

### 1. 【対応済み】開口低減が τu の断面に反映されていない（危険側）

耐力壁の平均せん断応力度を `τu = 負担水平力 / (壁厚 t × 壁長 lw)` で算定しているが、
壁要素側はせん断剛性に開口低減率 `r`（`factory::wall_opening_reduction`、複数開口モード
対応）を乗じている。τu の断面には `r` を反映していないため、**開口付き壁で τu を過小
評価し、耐力壁の種別を甘く（WA 寄りに）判定する**。

### 2. 壁式構造の列が未使用（壁式構造で非保守）

告示「耐力壁の種別」表は「壁式構造以外」と「壁式構造」で限界値が異なる
（WA: 0.20 vs 0.1、WB: 0.25 vs 0.125、WC: — vs 0.15）。現在は
`rc_wall_type(.., wall_structure = false, ..)` と固定しており、常に「壁式構造以外」の
緩い列で判定する。階の構造種別（`Story::structure`）から列を切り替える必要がある。

### 3. 耐力壁の脆性破壊（WD）判定が未実装

`rc_wall_type` の `brittle` 引数に常に `false` を渡しており、「せん断破壊その他の急激な
耐力低下のおそれのある破壊」を生じる壁を WD と判定できない。RC 規準の耐震壁のせん断
終局強度（`design_jp::rc::wall`・`wall_nonlinear` を参照）と曲げ終局の比較で判定する
必要がある。

### 4. 側柱を含めた断面との整合

壁要素のせん断剛性は「壁板断面＋側柱断面」（`as_gross`）を用いるが、τu の断面は壁板のみ
（`t × lw`）としている。告示の τu の定義（どこまでを壁の断面とみなすか）と照合し、
側柱の扱いを統一する。

### 5. 連層壁での負担せん断

`horizontal_force` は当該壁要素 1 枚が負担する水平力であり、連層耐震壁では層ごとの
分担・基礎への伝達を含めた評価と乖離しうる。βu の分子として妥当かを検証する。

### 6. `member_response` の壁に対する諸量が無意味（未対応）

`compute_member_response` は 2 節点線材を前提に `LocalFrame::from_nodes(nodes[0], nodes[1])`
で局所軸を作るため、4 節点壁では `m_strong` / `m_weak` / `shear_strong` / `shear_weak` /
`axial` / `rp` が意味を持たない（`horizontal_force` のみ節点群合計で正しく算定される）。
壁を含む部材別応答の型・算定を整理し、壁には壁用の応答量を持たせるべき。
