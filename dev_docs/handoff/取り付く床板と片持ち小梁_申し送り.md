# 取り付く床板の支持辺分配と片持ち小梁 申し送り

作成日: 2026-09-13
対象: `squid-n-core`・`squid-n-load`・`squid-n-job`・`squid-n-solver`・`squid-n-edit`・`squid-n-io`・`squid-n-mcp`・`squid-n-app`・`docs/`・`CONTEXT.md`・`dev_docs/adr/`

## 背景

PR #274 の残課題「`crates/squid-n-load/src/floor/cantilever.rs` の doc コメントに廃止済み
`SlabKind`・`edge_supported` が現役として残る」の解消から始めた。dig の結果、doc の是正だけでは
足りず、次の 2 つが未実装であることが分かったため実装まで行った。

1. 取り付く床板は常に取付き辺へ全量を載せており、周辺の片持ち梁・先端リブ小梁を支持辺として
   扱っていなかった（その部材の応力を過小評価する）。
2. 片持ち小梁（基端支持・先端自由の小梁）というモデル化の分類がなく、自由端を持つ二次部材は
   荷重が載ると解析前チェックのエラーで止まっていた。

## 決定

- [ADR 0015](../adr/0015-cantilever-secondary-members.md): 片持ち小梁は端部支持条件
  `end_support: [Supported / Free; 2]` で表し、基端の鉛直反力のみ伝達する（基端モーメントは
  伝達しない）。
- [ADR 0016](../adr/0016-attached-slabs-between-members.md): 取り付く床板は支持部材の間ごとに
  1 枚とし、付け直しで分割する。分割境界は取付き線に直交して先端まで届く小梁または実梁だけ。
- [ADR 0017](../adr/0017-attached-slab-support-edges.md): 取り付く床板の荷重は、全長を覆う
  支持部材の辺へ最近接負担面積で分配する。

## 実装

### モデル（`squid-n-core`）

- `EndSupport`（`Supported` / `Free`）と `SecondaryMember.end_support` を追加（serde 既定は
  両端 `Supported`）。`SecondaryMember::free_end` / `is_cantilever`。
- `Model::node_on_primary_geometry`・`Model::node_has_geometric_support`・
  `Model::infer_secondary_end_supports` を追加。取り込み時に、主架構にも他の二次部材の内法にも
  載らない端を自由端として推定する。端点が他の部材と一致するだけの端（先端リブと片持ち小梁の
  先端など）は、自分の反対側の端が主架構に載り、かつ相手の材軸が自分の材軸と連続していない
  ときだけ自由端にする（材軸が連続する分割小梁の継ぎ目は自由端にしない）。両端が自由端に
  なる推定はしない。
- `rebuild_floor_regions` に取り付く床板の分割・統合を追加。取付き線に直交し、取付き線から
  先端まで届く小梁または実梁の位置で `SlabShape::Attached` を分割し、取付き線は部分区間 `span`、
  張り出し量は分割位置で線形に内挿する。直交しない・途中までの部材は境界にしない。同じ取付き線・版
  仕様で境界に小梁や実部材がない隣接する床板は 1 枚に統合する。分割・統合は冪等。

### 荷重分配（`squid-n-load`）

- `cascade`: 端部支持条件を支持判定へ反映。自由端は支持を探さず、自由端に載る別の二次部材を
  受け側として扱う。片持ち小梁は自由端の反力を基端へ移す。`SupportAt::Free` を追加。
- `floor::cantilever`: 支持辺（全長を覆う実部材または二次部材の辺。実部材優先）を検出し、
  最近接支持辺の負担面積（200×200 格子。真の多角形面積へ正規化）で分配する。実部材の辺は
  その要素へ、二次部材の辺は `Span`（節点対＋区間）として材軸へ渡す。支持辺がなければ
  従来どおり取付き辺へ `w × 出し幅平均` の等分布。
- `secondary_joist_distribution_split` の対象を全床板（床領域内＋取り付く床板）へ拡張。
  取り付く床板の辺荷重も二次部材へ渡る。
- `joist_design`: `cantilever_extremes`（基端固定・先端自由の M・Q・たわみ）と
  `flip_member_loads` を追加。結果型を `BeamExtremes` へ改名。

### 解析前チェック（`squid-n-solver`）

- 両端が自由端の二次部材は不安定としてエラー。
- 幾何的には支持がある端（主架構または他の二次部材の内法・自由端受け）を自由端として扱う
  場合は警告。
- 取り付く床板の辺を全長で覆わない実部材は警告（覆われていない部分の荷重はその実部材に
  載らない）。
- 所属先がない小梁のエラーは、片持ち小梁（取付き線の支持辺から荷重を受ける）と実部材化済み
  の小梁を除く。
- 従来の「行き先不明」「循環」「節点非共有の交差」はそのまま。

### 入力・取り込み

- `squid-n-edit`: `SetSecondaryMemberEndSupport` を追加（端点対で対象を探し、所属先を問わず設定）。
- `squid-n-mcp`: `SetSecondaryMemberEndSupport` の解析を追加。`SecondaryMember` の
  `end_support` は JSON からそのまま解析できる。
- `squid-n-io`: ST-Bridge 取り込みで自由端を推定し、件数と対象を取り込み報告（notes）へ出す。
- `squid-n-app`: 床タブに「小梁（二次部材）」一覧を追加（所属・両端節点・断面・支持条件の編集）。
  小梁検定は片持ちの場合 `cantilever_extremes` を使う。
- `squid-n-job`: 取り付く床板も含めて全床板を逐次伝達へ通す形へ整理（`slab_beam_loads_with` の
  個別分配ループを削除）。

## PR #275 レビュー対応

- 分割候補に実梁を追加（`attachment_split_axes`）。単一の取り付く床板の内部を通り、取付き線から
  先端まで届く実梁（実片持ち梁）も分割境界となり、支持辺として床荷重を受ける。回帰テストを
  core（分割）と load（分割後の分配）へ追加。
- `axes_are_collinear` を方向余弦の閾値（`|dot| > 0.9`、約 25.8°）から、共有節点の反対側の端点と
  相手材軸直線の距離が材軸許容（10 mm）以内という判定へ変更。斜交する先端リブ（約 15°）でも
  片持ち小梁の先端を自由端に推定できる。小さい座標誤差の継ぎ目を連続とみなすテストも追加。
- `docs/calc_basis/01_荷重/03_床荷重の分配.md`・`docs/preparation/README.md`・ADR 0016・0017 の
  分割境界の記述を「小梁または実梁」へ更新。
