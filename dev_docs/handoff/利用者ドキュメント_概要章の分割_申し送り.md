# 利用者ドキュメント「概要」章の分割 — 申し送り

対象: `docs/`（mdBook）、`book.toml`、`CONTRIBUTING.md`

## 背景と経緯

利用者ドキュメントの「計算根拠」章（`docs/calc_basis/`）は、章ディレクトリ＋小項目ページ
（`README.md` ＋ `NN_項目.md`）の構成で、サイドバーに小項目まで並ぶため一覧性が高かった。

一方、「概要」章のうち次の 4 ページは、1 ファイルに全内容が入った長大なページのままで、
サイドバーには章名しか現れず、目的の節へ到達するにはページ内スクロールが必要だった。

| 旧ファイル | 行数 |
| --- | --- |
| `docs/model_io.md` | 271 |
| `docs/mcp_server.md` | 281 |
| `docs/preparation.md` | 206 |
| `docs/result_view.md` | 393 |

本変更で、これら 4 ページを計算根拠章と同じ構成へ分割した。内容は移設のみで、
記述している仕様（計算根拠・表示仕様）そのものは変更していない。

## 章トップ（`README.md`）リンクの 404 修正

分割の検証中に、**分割前から存在していた不具合**として、章トップへのリンクが
すべて 404 になっていたことが判明した。

- mdBook は章トップの `README.md` を `index.html` として出力する。
- 一方、目次（`SUMMARY.md`）・本文中の `README.md` へのリンクは `README.html` の
  ままに解決される（mdBook 0.4.52／0.5.4 の双方で確認）。
- 結果として、`book/calc_basis/README.html` などの出力が存在せず、サイドバーの
  「計算根拠について」「1. 荷重・外力」等をクリックすると 404 になっていた。

`book.toml` に `[output.html.redirect]` を追加し、各章の `README.html` を同ディレクトリの
`index.html` へリダイレクトすることで解消した（mdBook が生成するリダイレクトページは
フラグメント `#...` も引き継ぐ）。章ディレクトリを追加したときは、ここへ 1 行追加する必要が
あるため、`CONTRIBUTING.md`「ドキュメントサイト（mdBook）」にも注記した。

なお、章トップを `index.md` へ改名しても解消するが、GitHub 上でディレクトリを開いたときに
本文が表示される利点を優先し、`README.md` のままリダイレクトで受ける方針とした。
