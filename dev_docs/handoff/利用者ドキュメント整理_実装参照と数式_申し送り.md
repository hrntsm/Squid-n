## 背景と経緯

GUI 利用者の視点で整理しました。対象は、実装参照の共通表示、Rust API（開発者向け情報）の分離、
記号・単位、数式、ページ構成です。

  表示スタイルは新設した `theme/impl-ref.css`（`book.toml` の `additional-css`）で全ページ共通とし、
  `CONTRIBUTING.md` の記載規約も更新。

## 追記: 記号・単位表の内部 SI 統一

`docs/calc_basis/**` の `**記号・単位**` 表を、内部計算に合わせた内部 SI 単位へ統一しました。
`docs/calc_basis/README.md` にも「各ページの記号・単位表は内部 SI（N・mm・N/mm² 等）で統一し、
画面に表示する単位は換算表で対応を示す」旨を明記しています。

- 表示単位（`kN`・`kN·m`・`kN/mm`・`kN/m²`・`cm`・`cm²`・`cm³`・`cm⁴`・`m`・`m²`・`mm/s²`・`°` 等）を
  内部 SI（`N`・`N·mm`・`N/mm`・`N/mm²`・`mm²`・`mm³`・`mm⁴`・`mm`・`mm/s²`・`rad` 等）へ置換しました。
- 単位が `-`（無次元）のもの、`回` など無次元として扱うものは対象外としました。質量は N と
  mm/s² に整合する `t` を維持しています。
- 統一後の走査で、`docs/calc_basis/**` の 63 表の単位欄に表示単位は残っていません（全件を機械確認）。

## 今後の判断・残課題

- `docs/calc_basis/02_材料/02_部材履歴則.md` のせん断寄与 `\theta_s = M/K_s` と鉄筋抜出し `\theta_p` は、
  参照実装 `squid_n_skeleton::deformation::{ShearContribution::rotation, PulloutContribution::rotation}`
  が返す値が `[mm]` の次元のまま部材端回転角 `[rad]` に加算されます（`K_s = G \cdot A_w` は `[N]`、
  `M/K_s` は `[mm]`。抜出しの `\sigma_s \cdot d_b/(E_s \cdot \xi)` も `[mm]`）。式の見直し要否を含めた
  実装調査が必要です。この経路は参照実装専用で、本番の非線形解析経路
  （`squid_n_element::frame::fiber`）はこの値を使いません。
  利用者向けページの記号・単位表は、この戻り値の次元に合わせて `\theta_s`・`\theta_p` を `[mm]` と
  表記し、意図する物理量は `[rad]` である旨を注記しました。
- `crates/squid-n-core/src/rc_capacity.rs` の `p_t`（引張鉄筋比）は、荒川 mean 式 `rc_qsu_simple` が `%`、
  菅野式 `rc_alpha_y_sugano` が小数を引数に取り、API 単位が不統一です。呼び出し側が取り違えると
  `\alpha_y` が 100 倍ずれるため、引数名へ単位を埋め込む（`pt_percent` と `pt_ratio`）か一方へ統一するかの
  判断が必要です。
- light/dark テーマでの表示は目視未実施です。
- ページ構成（概要 → GUI との関係 → 根拠 → 算定式 → 記号・単位 → 適用条件 → 実装参照）の
  全ページ統一は未実施です。`calc_basis/01_荷重/08`・`09`、`04_要素剛性/06` は
  節別の実装参照とページ末尾の `## 実装参照` 節が併存したままです。
- 実装参照には private / `pub(crate)` の項目を含みます（公開 API に限定するなら再エクスポートが
  必要です）。
- MathJax の最終描画はブラウザ確認が必要です（機械検査は HTML ソース上の混入確認までです）。
