# 利用者ドキュメント整理（実装参照と数式） — 申し送り

作成日: 2026-09-17

対象: `docs/`（mdBook）、`theme/impl-ref.css`、`book.toml`、`CONTRIBUTING.md`

## 背景と経緯

GitHub Issue #280（GUI 利用者向けドキュメント整理）として、利用者向けドキュメント（`docs/`）を
GUI 利用者の視点で整理しました。対象は、実装参照の共通表示、Rust API（開発者向け情報）の分離、
記号・単位、数式、ページ構成です。

## 変更内容

- `**実装**` 平文を `<div class="impl-ref">` の共通表示へ統一（382 件、106 ファイル）。
  表示スタイルは新設した `theme/impl-ref.css`（`book.toml` の `additional-css`）で全ページ共通とし、
  `CONTRIBUTING.md` の記載規約も更新。
- `.scz`・ST-Bridge・波形ライブラリの Rust コード例を、`## 開発者向け: ライブラリ API（Rust）` の
  `<details>` へ分離。
- 数式と Markdown の干渉を解消（77 ファイル）。数式内の `_`→`\_` 2980 件、`\,`→`\\,` 147 件、
  `%`→`\\%` 3 件、プライム `'`→`\'` 109 件、複数行ディスプレイ数式のリスト化 1 件。
- `docs/calc_basis/06_一次設計/02_RC_断面検定.md` の開口周比 `r_0` を `\cdot` 明示に修正。
- `docs/calc_basis/README.md` を GUI 利用者向けに再構成し、開発者向けリンクを `<details>` へ分離。
- `docs/calc_basis/` の各ページに主要記号・単位表を補完（49 ファイル、63 表）。
  表中の数式で未エスケープだった下付き `_` 44 箇所（11 ファイル・34 行）を `\_` へ書式修正。

## 検証

- `mdbook build`（mdbook 0.5.4）が警告・エラーなく成功。
- 生成 HTML の数式区間（`\(...\)`・`\[...\]`。全 141 ページ・5816 区間）に `<em>` の混入が
  0 件であることを機械確認。
- 代表ページ（`calc_basis/01_荷重/01_地震力`・`calc_basis/06_一次設計/02_RC_断面検定`）で、
  記号・単位表が `<table>` として出力され、数式が `\( ... \)` として壊れていないことを確認。
- 記号・単位表の書式検査: `**記号・単位**` の直後に `| 記号 | 意味 | 単位 |` があること、
  各行 3 列であること、表の重複がないことを確認。

## 影響・注意事項

- 利用者から見える計算根拠の記述は変えていません。実装参照の表示方法、開発者向け情報の
  折りたたみ、記号表・数式の書式のみを変更しています。

## 今後の判断・残課題

- light/dark テーマでの表示は目視未実施です。
- ページ構成（概要 → GUI との関係 → 根拠 → 算定式 → 記号・単位 → 適用条件 → 実装参照）の
  全ページ統一は未実施です。`calc_basis/01_荷重/08`・`09`、`04_要素剛性/06`、`10_数量積算/01` は
  節別の実装参照とページ末尾の `## 実装参照` 節が併存したままです。
- 実装参照には private / `pub(crate)` の項目を含みます（公開 API に限定するなら再エクスポートが
  必要です）。
- MathJax の最終描画はブラウザ確認が必要です（機械検査は HTML ソース上の混入確認までです）。
