# 柱自重の節点伝達（Issue #340）

- 作成日: 2026-09-22
- 残課題: —

## 概要

Issue #340「柱自重の節点伝達を基準資料に合わせる」。従来、柱の自重（付加線重量・
仕上げを含む）は鉄骨梁と同じく部材の等分布荷重として与え、柱脚に下階柱がない場合は
梁最大せい `Dmax` 分を自重算定長へ加算して全長へ均していた。基準資料の伝達規則に
合わせ、柱自重を節点荷重として扱い、下階柱なしの RC/SRC 柱の `Dmax` 分は下端節点だけへ
加算する形へ改めた。

対象は柱（2 節点の鉛直 `ElementKind::Beam`）。`ElementKind::Brace` は軸材として
従来どおり部材等分布のままとする。

## 決定

- 柱の全自重 `W = w·L`（`w` は単位長さ当り重量、`L` は柱の全長＝節点間距離）を
  上下節点へ 1/2 ずつ加算する。
- 下階に柱が接続しない RC/SRC 柱（一般には最下階）では、下端節点に取り付く
  非鉛直 `Beam` の最大せい `Dmax` に相当する柱重量 `Wextra = w·Dmax` を**下端節点だけ**
  へ加算する。S 柱・下階柱ありは `Wextra = 0`。柱の総重量は `w·(L+Dmax)` で保存する。
- 下階の柱判定は鉛直 `ElementKind::Beam` のみを柱とみなす（`Brace` は柱とみなさない）。
- 長期応力用（DL）・地震用重量（建物重量）で同じ規則を用いる。DL では柱を節点荷重、
  梁・ブレースを部材等分布荷重とする。
- 補正質点方式の質量控除（`node_self_weight`）は通常分 `W` のみを上下 1/2 ずつ控除し、
  `Wextra` は控除しない（下端節点の質点質量として残す）。
- ADR は作らない。スキーマ・後方互換は変更しない。

### 実装の要点

- `SelfWeightItem::Line` を `total`（通常自重）と `extra_bottom`（下端のみ加算）・
  `is_column` に分けた。
- `enumerate_self_weight` は単位長さ当り重量 `per_length` を求めてから
  `total = per_length·eff_len`・`extra_bottom = per_length·max_depth` に分ける。
  `eff_len` は柱では節点間長、RC/SRC 梁ではフェース控除後（従来どおり）。
- 地震用重量 `node_weight` の集計で柱だけ別扱いにし、上端 `total/2`・下端
  `total/2 + extra_bottom`（下端は `ci[2] <= cj[2]` の側）を加算する。
  `node_self_weight` は `distribute_line_panel` の Line 分岐（`total` を 1/2 ずつ）のまま。
- `self_weight_case_content`（DL）で柱は節点荷重、梁・ブレースは等分布部材荷重。

  - `prep.total_seismic_weight` 5.270e4 → 5.185e4。差 850 N は、2 本の RC 柱脚の
    `Wextra = w·400` が従来は上端節点へ 1/2 だけ算入されていた分。基準資料どおり
    下端節点（基部）へ全量加算となり、基部階は建物重量（層データ）に含まれないため。
  - `eigen.T`・DL/EX 壁応力・保有水平耐力の微小変化。同じ伝達経路の変更による。

## 残課題

なし。柱以外（梁自重・仕上げ重量の入力方法、床荷重、壁など）へは変更を広げていない。
