# 応力図の同単位共有スケール 申し送り

作成日: 2026-08-12

## 背景

応力図で複数成分を同時表示すると、張り出し・コンター・凡例が**成分ごとの独立 max**
で正規化されていた。同じ単位（例: \\( M_y \\) と \\( M_z \\)）でも見た目の大きさが揃い、
大小を見間違える。

## 変更内容

- 対象: `crates/squid-n-app/src/viewer/diagram.rs`（応力図のみ。CMQ・変形倍率は対象外）
- 純関数 `display_scales_for_selection`: 表示中かつ `is_significant` な同単位成分の
  max を共有し、張り出し振幅・コンター色・凡例 max・数値ラベル 1% 間引きに共通利用
- 単位グループ: 力 kN（\\( N, Q_y, Q_z \\)）／モーメント kN·m（\\( M_x, M_y, M_z \\)）
- 単独成分表示時はその成分自身の max（画面を使い切る）
- 利用者向け: `docs/result_view/03_応力図への変形の重ね表示.md`

## 凡例の注意

凡例の `max=` は**描画に使う共有スケール**であり、その成分固有のピークとは限らない
（例: \\( M_y \\)=100・\\( M_z \\)=20 同時表示では両行とも `max=100`）。成分固有ピークは
併記しない方針。
