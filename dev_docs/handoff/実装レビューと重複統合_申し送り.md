# 実装レビューと重複統合 — 申し送り

作成日: 2026-08-03

ワークスペース全体（15 クレート・約 176k 行）を 4 領域（GUI／ソルバ・要素／設計・荷重系／
基盤・IO 系）に分けてコードレビューし、実害の大きい不整合の修正と重複統合を行った。
本書は「本ブランチで修正した内容」と「レビューで確認したが未着手の残課題（優先度付き）」を記録する。

## 1. 本ブランチで修正した内容

### 1.1 編集コマンドの ID 参照整合（データ破壊の修正）

ID＝配列添字の不変条件を保つ「削除時の ID 繰り上げ」から、以下の参照が漏れていた。
ST-Bridge を取り込んだモデル（二次部材あり）で節点・断面・材料を削除すると、二次部材が
別の対象へ張り付き、保存時の `validate()` まで発覚しなかった。

- `squid-n-edit::shift_node_ids` / `shift_section_ids` / `shift_material_ids` に
  `Model::secondary_members`（小梁・間柱）の参照を追加。
- `section_in_use`・`DeleteMaterial` の使用中ガードに二次部材の参照を追加
  （`material_in_use` を新設）。
- `Model::shift_elem_attr_refs`（core）に一本部材指定 `beam_groups` を追加し、
  `panel_gen.rs` 側の手動繰り上げを削除（単一情報源化）。従来は部材削除後に
  グループが**無関係な部材のモーメントを検定に合成**していた（validate も通らず
  サイレントに誤る、最悪の失敗様式）。
- `DeleteMember` が beam_groups から当該部材を連動削除し、undo で位置ごと復元
  するように変更（`InsertMember::beam_group_refs`）。
- `Model::validate()` に beam_groups のダングリング検査を追加。
- `Model::eq_ignoring_dofmap` に `secondary_members`・`axes` を追加
  （undo・SCZ 往復テストの検査対象から漏れていた）。
- 回帰テスト 5 件を `squid-n-edit/src/tests.rs` に追加。

### 1.2 整合質量行列の全体系変換漏れ（数値計算の修正）

`ElementBehavior::mass_matrix` の整合質量（Consistent）が要素局所系のまま全体自由度へ
散布されていた。整合質量は軸方向（m/3 系）と曲げ方向（156m/420 系）で係数が異なり
回転不変ではないため、**鉛直柱・斜材で質量が誤った全体軸へ配分**され、固有周期が
部材の向きに依存していた（片持ち梁の検証で水平材と鉛直材の固有周期が約 29% 乖離）。
固有値解析・全時刻歴解析は常に Consistent を使うため影響範囲が広い。

- `BeamElement`／`TrussElement`／`FiberBeam` の Consistent 分岐に
  `M_global = Rᵀ M_local R` の変換を追加（集中質量は並進 3 成分等価の対角行列で
  回転不変のため変換不要）。
- `FiberBeam::mass_matrix` は曲げブロックの DOF 添字も誤っていた（連番書き込みで
  ねじり Rx と連成・節点 j の並進質量欠落）ため、beam と同じインデックス配列方式へ
  修正（現状この実装は線形ファクトリ経由では到達不能だが、誤ったまま残すと危険）。
- トレイト doc に「質量行列は全体系で返す契約」を明記。
- 回帰テスト（水平材と鉛直柱の固有周期一致）を eigen テストへ追加。
- 利用者向け docs（固有値解析）に座標変換の記述を追記。

### 1.3 design-jp の RC/SRC/CFT 重複統合（非保守側の旧仕様残存の修正を含む）

RC 側で修正済みのバグが、コピーされた SRC 側に残っていた。重複の典型的な帰結のため、
修正と同時に単一情報源化した。

- **せん断スパン比 α の退化時規約**: RC の `shear_alpha` は「Q≈0 は下限 1.0
  （割増なし）」へ修正済みだったが、SRC の複製 `shear_alpha_src` は旧仕様の
  「上限 max_alpha（割増を最大化する非保守側）」のままだった。SRC 側の複製を
  削除し `crate::rc::shear_alpha` に統合（**設計結果が保守側へ変わる**）。
  docs（RC 断面検定・SRC/CFT 断面検定）に退化時規約を明記。
- 断面諸元ヘルパ 6 個（`one_bar_area`/`bar_set_area`/`tension_dt`/`pw_ratio`/
  `AxisProps`/`rect_axis_props`）の SRC 側複製を削除し、`crate::rc::section_props`
  へ統合（複製理由だった「rc 側が private」は既に解消済みだった）。
- N-M 相関曲線の補間 `interp_ma`（25 行、バイト単位で同一の複製）を rc 側へ統合。
- `ratio_or_large`（SRC・CFT に同一実装）を `crate::ratio_or_large` へ統合。
- QD 決定分岐（Qd1/Qd2/Min、RC と SRC で同一）を `QdMethod::resolve` へ統合。

### 1.4 GUI の解析結果表示の不整合修正

- `apply_pushover_result`／`apply_time_history_result` が `staleness.last_run` の
  更新のみで `mark_fresh()` を呼ばず、モデル編集後に増分解析・時刻歴だけを実行しても
  「⚠ モデルが編集されています」バナー・時刻歴アニメーション・部材クリックが
  無効のまま復帰しなかった。静的解析と同じく `mark_fresh()` へ統一。
- `apply_static_case_result`／`apply_combo_result`／`apply_static_all_result` が
  `last_static`・`bundle.member_forces` を新結果へ差し替える一方、`current_static` が
  優先する `nav.focus_result` を据え置いていたため、**変位図（旧結果）と応力図・
  断面検定（新結果）が食い違う**表示になっていた。apply 時に `focus_result` も
  新結果へ切り替えるよう修正。
- 回帰テスト 2 件を `squid-n-app/src/app/tests.rs` に追加。

### 1.5 追補: 残課題のうち対応済みの項目（第 2 弾）

初版で「未着手」とした残課題のうち、以下は対応済み。
§1.5〜1.8 の項目名に付す括弧内の項番（2.1-1 等）は**初版レビュー時の
残課題一覧の番号**であり、§2 は消化に伴い再編済みのため現在の §2 の
項番とは対応しない（当時の優先度の記録として残す）。

- **2.1-1（集中ばね梁の非線形部材応力欠落）**: `state_member_forces` を実装し、
  非線形時刻歴の開始時点に欠落ガード（`ensure_line_member_forces_nonlinear`）を追加。
- **2.1-2（プッシュオーバー非収束のサイレント打ち切り）**: `PushoverResult::termination`
  （目標到達／λ 上限／スケジュール完了／非収束／特異化）を追加し、目標未到達の
  打ち切りは結果画面・ログで警告。docs にも記載。
- **2.1-3（invert_small の特異時無音回避）**: 部分ピボッティング＋`Option` 化。
  静縮約は補正項省略（全体求解の特異検出へ委譲）、要素内 Newton は反復打ち切り。
- **2.1-4（precheck の対象拡大）**: 線材・面材全種別の断面/材料未割当と
  シェルの板厚なし断面を precheck でエラー化。fiber/shell の「もっともらしい
  既定値」（E=205000・100×200・t=100）はゼロ剛性へ変更（架空断面を作らない）。
  非線形入力チェックにも断面必須を追加。
- **2.1-6（gpu の誤答スタブ）**: `PcgGpu::solve` を明示エラー化
  （空行列を解いて誤答を返す構造を撤去）。`squid-n-ml` の扱いは未決のまま。
- **2.2 GUI 先頭（start_*_job 共通化）**: `begin_analysis` / `begin_analysis_job` /
  `spawn_analysis_job` / `run_compute` へ共通化し、増分・時刻歴・固有値も
  `ensure_preparation`（剛域＋仕口パネル＋荷重同期）を通るように統一。
  固有値解析をバックグラウンドジョブ化（UI 無応答の解消）。
- **2.2 IO（ResultStore の Result 化）**: `ResultWriter`/`ResultStore` を
  `io::Result` 化し、fs_store の panic（expect/assert/unimplemented）を伝播へ
  置換。`persist_job_outcome` は書き込み失敗を `Err` で返し、MCP ジョブは
  `Failed` へ遷移する（`Running` のまま永久に終端しない・「結果 0 行」を
  `Done` と報告しない）。

### 1.6 追補: 残課題のうち対応済みの項目（第 3 弾）

- **チェックポイント欠落**: `IsolatorElement` / `HystereticDamperElement` に
  serialize/deserialize_checkpoint を実装（レジュームで履歴が初期化される問題を解消）。
- **ID 参照走査の単一情報源化**: `Model::visit_{node,section,material,elem}_ids` を
  core へ集約し、edit の shift_* は委譲のみに（1.1 の再発防止の本丸）。
- **UndoStack の Noop 握りつぶし**: 適用失敗（逆コマンドが Noop）を履歴へ積まず、
  redo 履歴も保持する。`run` は適用有無を bool で返す。
  `EditCommand::apply` の `Result` 化はなお未着手（呼び出し側が失敗理由を
  表示できるようにするには型の変更が必要）。
- **ST-Bridge 往復**: 壁専用の厚さ断面が StbSecRaw と StbSecWall_RC の二重出力で
  往復ごとに増殖する問題と、BOX 形鋼のライブラリ名に corner_r が含まれず
  同寸別 r の断面が同一名に潰れる問題を修正（冪等性テスト付き）。
  corner_r=0 の便宜値 r=t 出力はスキーマ制約（r 正値必須）による既存仕様のまま。
- **ソルバ**: 部材変形角（`member_rp_angle`/`member_drift_angle` の完全重複）を
  統合。線形時刻歴の `use_kg`（P-Δ）の無言破棄を明示エラーへ変更。

### 1.8 追補: 残課題のうち対応済みの項目（第 5 弾）

- **SRC 柱・SRC 耐震壁の部材種別（実務判断の回答: 実装する）**: 技術基準解説書

  app の `compute_holding_capacity` に SRC 矩形柱の分岐と、周辺柱が SRC の壁を
  WA/WC で判定する分岐（`wall_has_src_boundary_column`: 壁と節点を共有する
  鉛直線材の `member_structure_kind == Src`）を配線。SRC 梁は原典に種別表が
  ないため対象外（層の選択ランクへフォールバック）。docs 7.3.2 に表・略算式・

- **鋼材単位重量の分野別仕様化（2.2 設計・実務判断の回答: 分野別の慣用値を仕様化）**:

- **鋼材せん断有効断面積の梁側定義への統一（2.2 設計・実務判断の回答: 梁側定義へ統一）**:

  強軸 τ=Qy/Ay（H形はウェブ内法 tw·(H−2tf)、角形は角部円弧考慮）、円形・その他は
  合成 √(Qy²+Qz²)/Ay。同一 H 形断面で柱と梁の τ が食い違う不整合を解消

  幅厚比表の対象外形状（溝形・T形・山形等）に効いていた仮しきい値

- **CMQ 図の毎フレーム床荷重分配のキャッシュ（2.2 GUI）**: CMQ 表示中に毎フレーム

### 1.9 追補: 敵対的レビュー（4 領域並列）で検出した問題の修正

ブランチ完成後に設計計算・ソルバ/要素・GUI/IO・ドキュメント整合の 4 領域で
敵対的レビューを実施し、確認された実バグを修正した。

- **SRC 耐震壁の WC 判定が恒偽（危険側）**: せん断降伏イベント
  （`po.shear_yields`）は 2 節点線材のみが対象で、4 節点の壁要素の ID は
  決して入らないため `src_wall_type(contains(...))` が常に WA を返していた。
  壁の非線形要素が面内せん断を Qu で頭打ちにする弾完全塑性であることを
  利用し、「終局時負担水平力 ≥ 0.99·Qu」でせん断破壊と判定するよう修正
  （Qu 算定不能・終局時応答なしは判定不能としてスキップ）。docs 7.3.2 も更新。
- **`wall_has_src_boundary_column` の過剰検出**: 片側 1 節点の共有まで許すと
  壁上辺の隅節点から立ち上がる上階の SRC 柱にも反応し、SRC 階→RC 階切替部で
  RC 側の壁を SRC 壁と誤判定するため、側柱の定義（両端とも壁の節点）に修正。
- **beam_loads キャッシュのバイパス書き込み**: `sync_gravity_load_cases_action`
  が `beam_loads` を直接上書きする際にキャッシュキー `beam_loads_hash` を
  無効化せず、編集→同期→undo の後に旧分配が CMQ 図へ残り続けた。
  直接書き込み時にキーを無効化（回帰テスト追加）。
- **load_model が実行中ジョブを破棄しない**: 旧モデルで計算中の解析ジョブが
  完了時に新モデルへ「最新結果」として適用され stale 警告も出なかった。
  `load_model` で `job`・`pending_save_recording` を破棄。
- **Other 形状のせん断有効断面積の軸取り違え（既存）**: `shear_area_2d` の
  Other が断面レイヤの as_y（弱軸・フランジ）を強軸 Qy の分母にしていた。
  要素剛性側（construct.rs）と同じクロス対応（Ay ← as_z）へ修正。
- **ST-Bridge export の断面参照ダングリング（限定的）**: 厚さ専用断面を
  壁要素と二次部材が共有すると、Raw 出力から除外された断面 id を
  StbBeam/StbPost が参照した。壁専用判定に Shell を含め、二次部材の参照を
  「壁専用でない」側に数えるよう修正。

### 1.10 追補: 残課題のうち対応済みの項目（第 6 弾・PR #164 マージ後）

- **SRC 柱のせん断降伏 Qy の累加式化（§2.3・実務判断の回答: 累加式）**:
  剛性等価換算せん断断面積 × 0.7√Fc の根拠のないフォールバックを廃止し、
