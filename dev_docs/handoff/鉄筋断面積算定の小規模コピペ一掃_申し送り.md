# 鉄筋断面積算定の小規模コピペ一掃 — 申し送り

作成日: 2026-08-12
対象コード:
`crates/squid-n-core/src/section_shape/types.rs`、
`crates/squid-n-core/src/rc_rebar_geom.rs`、
`crates/squid-n-design-jp`（`rc`・`ultimate`・`joint_wiring`・`quantity`）、
`crates/squid-n-solver/src/nonlinear/pushover/tests.rs`

## 背景

主筋 1 本の断面積（πr²）とせん断補強筋 1 組の断面積が、
`PI / 4 · dia²` の手書きとして複数クレートに残っていた。
`bar_set_area` はすでに core にあったが、1 本分や帯筋組分の入口が揃っていなかった。

## 変更内容

`squid_n_core::section_shape` に次を置いた。

- `one_bar_area(dia)` — 1 本の断面積
- `shear_legs_area(shear)` — せん断補強筋 1 組（`legs` 本）の断面積

`bar_set_area` と `pw_ratio` はこれらへ委譲する。
design-jp の `section_props::one_bar_area` は core の再エクスポートに変え、
手書きしていた箇所（付着・終局せん断・壁接合・数量積算・MN ファイバ・solver テスト）を差し替えた。
追加で漏れていた本番コード（壁接合の `pw`、終局の `hoop_area`、積算単位質量、
`mn_surface` の主筋ファイバ断面積）も同じヘルパへ寄せた。

数値は同じ式への寄せなので、意図した挙動変更はない。

## 意図的にやらないこと

- 保有・床・周期の job 化、MCP の厚み揃え
- 薄い再エクスポート削除、`viewer` / `panels` 分割、`floor_grillage` 所属移動
- テスト内の手計算期待値（検算用の `π/4 · dia²` 展開）の機械的置換
