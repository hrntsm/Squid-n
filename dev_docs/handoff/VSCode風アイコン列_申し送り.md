# VSCode 風アイコン列 — 申し送り

作成日: 2026-08-13
対象コード: `crates/squid-n-app/src/app/panels/activity_bar.rs`、
`status_bar.rs`、`analysis.rs`、`mod.rs`、`app/mod.rs`
関連文書: `../specs/UI設計.md` §1、`TONMANUAL.md`（アクティビティバー）

## 1. 目的

左右・下ドックの切替がすべて下部ステータスバーに載っていたため、どのアイコンが
どの領域を開くのかが横一列では読み取りにくかった。VSCode の Activity Bar に合わせ、
左ドックの切替は左端、右ドックの切替は右端、下ドックの切替だけステータスバーに残す。

あわせて、右ドックの「② 解析」1 枚に静的・固有値・増分・時刻歴を積んでいたのをやめ、
種類ごとに独立したパネル（＝右アイコン）へ分ける。

## 2. 変更内容

### 2.1 常時表示の左右アイコン列

`panels/activity_bar.rs` を新設した。egui パネルの呼び出し順は次のとおり。

top（ツールバー）→ bottom（ステータスバー）→ left（アイコン列）→ right（アイコン列）→
left（ドック）→ right（ドック）→ bottom（下ドック）→ central

アイコン列は `resizable(false)` で、ドックが閉じても残る。幅はアイコン本体 24px＋上下余白
10px にアクセント線 3px（`ACTIVITY_ACCENT_WIDTH`）を足す。アイコンは
`crates/squid-n-app/assets/icons/` の SVG を `egui_extras` の SVG ローダで描く
（絵文字は本文サイズだと小さく無彩色になるため使わない）。

クリックは既存の `toggle_dock_icon`（`panels/mod.rs` へ移設）と同じ。
対象ドックが開いていて対象パネルがアクティブなら閉じ、それ以外は開いて切替する。

### 2.2 アイコンの配置

- 左（上から）: ナビゲータ（階層）、作成パレット（鉛筆）
- 右（上から）: インスペクタ（虫眼鏡）、① 準備計算（チェック付き帳票）、
  静的解析（門形フレーム）、固有値（波形）、増分解析（性能曲線）、時刻歴応答（時計）
- 線色は gray-900（`#1A2332`）で統一。機能の区別は形とツールチップ。
- ステータスバー: 📜 ログ、📋 モデル表、⚡ 荷重表、🛠 準備計算結果、⚠ 診断（ドック内タブ行も残す）

選択中は `BLUE_300` 背景＋外側（左列は左端、右列は右端）の `BLUE_500` アクセント。
ホバーも `BLUE_300`。通常ボタンの青塗り＋白文字は使わない。

### 2.3 右ドックの解析 4 分割

`RightPanel::Analysis` を削除し、`Static` / `Eigen` / `Pushover` / `TimeHistory` を追加した。
各パネルは見出し（番号なし）＋共通の最終実行／stale ヘッダ＋従来の実行 UI。
折りたたみヘッダと、準備計算／解析パネル先頭の `right_panel_switcher` は削除した。
① の番号は準備計算の見出しにだけ残す。

工程タブ「解析」のプリセットは、従来どおり右ドックを ① 準備計算で開く。

結果タブ側の増分解析ビューは、解析パネル名と衝突しないよう `pushover_results_panel` に改名した
（描画内容は変えていない）。

## 3. 残課題

- ステータスバーの下ドック切替は絵文字のまま。環境によってグリフが出ない場合の
  テキストラベル化は [Zed風レイアウト §5](Zed風レイアウト改修.md) と同じ未着手。
- 右アイコン列は 6 個ある。極端に低いウィンドウでは下側の解析アイコンが見切れる。
- ドックのドラッグ入替・中央のタブ分割（`egui_dock`）は対象外。
