# M 図の曲線補間 申し送り

作成日: 2026-07-27
対象ブランチ: `claude/moment-distribution-curve-interpolation-roblzs`
対象コード: `crates/squid-n-app/src/viewer/diagram.rs`

利用者向け説明は `docs/result_view/08_応力図の曲線補間.md`（新規）に記載した。

## 1. 何が問題だったか

3D ビューアの M 図が「端部と中央を直線で結んだ折れ線」になっており、
等分布荷重を受ける梁でも放物線に見えなかった。

原因は**解析側ではなく描画側**にある。断面力の値そのものは
`梁内部の変位応力内挿_申し送り.md` の対応（`superpose_member_loads` の共有化）
以降、各評価断面で正しい（等分布荷重で中央 \(wL^2/24\)・端部 \(-wL^2/12\)）。
一方、評価断面（`eval_sections`）は既定で節点芯・柱フェース・部材中央の
3〜5 点しかなく、`draw_force_diagram` はこの数点を直線で結んでいた。結果、
放物線の中間部が失われ、ξ=0.25 では理論値 \(+wL^2/96\) に対し直線補間で
\(-wL^2/48\) と符号まで逆になっていた（反曲点も \(\xi\approx0.211\) ではなく
\(\xi=1/3\) にずれる）。

## 2. 対応方針の検討

以下を比較し、(C) を採った。

- **(A) 評価断面を増やす**: `eval_sections` は断面検定位置と同一情報源
  （`design_check` は `mf.at` の全位置を検定する）のため、増やすと検定出力が
  増える。表示のために設計側の挙動を変えるのは筋が悪い。
- **(B) ソルバに表示用の稠密サンプルを別途持たせる**: `MemberForces` の
  肥大化（荷重ケース × 組合せ × 部材 × 断面）と serde 互換の追加が必要。
  効果に対してコストが大きい。
- **(C) ビューア側で補間する（採用）**: 断面力が満たす \(dM_z/dx = Q_y\) を
  使い、評価断面の値と勾配から 3 次エルミート補間する。データ構造・解析結果は
  一切変えず、線形・非線形（プッシュオーバー等）どの結果でも同じ経路で効く。

## 3. 実装

`viewer/diagram.rs` に純粋関数 `moment_curve_samples(samples, length, div)` を
追加した。`samples` は `(ξ, Mz, Qy)`、戻り値は `(ξ, Mz)` の稠密列。

- 正規化座標での勾配は \(dM_z/d\xi = Q_y L\)。区間両端の値と勾配から 3 次
  エルミート（`H00/H10/H01/H11`）で `MOMENT_CURVE_DIV = 8` 分割する。
- M が 3 次以下になる区間（無載荷 1 次・等分布 2 次・等変分布 3 次）では
  **厳密解に一致**する。評価断面の値は補間後も不変（＝図は必ず断面検定の値を
  通る）。

### 3.1 集中荷重が評価断面上にある場合の補正

`member_load::fixed_internal_local` のせん断は \(\int_{[0,x)}w\,ds\)（半開区間）
で組み立てるため、集中荷重が載る断面の \(Q_y\) は**左側極限**になる。この値を
右側区間の左端勾配に使うと、本来折れ線である M 図に架空のふくらみが出る
（中央集中荷重の両端固定梁で、ξ=0.75 に理論値 0 に対し \(PL/16\) が出る＝
ピークの 50%）。

対策として、区間が 2 次であると仮定した左端勾配
\(S_k^{*} = 2(M_{k+1}-M_k)/h - S_{k+1}\) を求め、実測の左端勾配と符号が
食い違う場合は \(S_k^{*}\) を採る。このとき補間は 2 次へ縮退し、中央集中荷重の
折れ線を厳密に再現する。等分布荷重では \(S_k^{*}\) は実測値と厳密に一致する
ため、この分岐は発火しない（誤検出しない）。区間の右端勾配は常に区間内側から
の極限なので補正不要。

### 3.2 適用範囲

- **M 図のみ**。N は一定、Q は等分布下で 1 次のため直線で厳密。Q の 2 次分布
  （等変分布荷重下）は \(dQ/dx = -w\) の情報が結果側にないため補間しない。
- 要素は `ElementKind::{Beam, Fiber, MultiSpring}` のみ。これらは
  `member_forces_from_end_forces` 由来で \(dM/dx = Q\) が成り立つ。軸材
  （トラス）・ばね・面要素は曲げ分布を持たないため対象外（ばねは両端同値なので
  補間しても直線だが、関係が保証されない要素は最初から除外する方針）。
- 勾配に使う部材長は変形倍率の影響を受けない**未変形の節点間距離**
  （`app.model.nodes` から算定）。`coords3` は変形重ね時に増幅済みのため使わない。

### 3.3 コンター細分との関係

コンター表示は各サンプル区間を `CONTOUR_SUBDIV = 8` 分割して着色していたが、
曲線補間済みの M 図は既に 8 分割されているため `subdiv = 1` とした。塗り
ポリゴン数は従来と同等（区間あたり 8）に保たれる。

## 4. テスト

`diagram.rs` の `#[cfg(test)]` に純粋関数の単体テストを追加。

- `moment_curve_samples_reproduces_udl_parabola`: 両端固定梁 UDL の理論解
  \(M(\xi)=wL^2(6\xi-6\xi^2-1)/12\) に全補間点が一致（ξ=0.25 で 0）。
- `moment_curve_samples_keeps_linear_field_straight`: 中間荷重なし＝直線のまま。
- `moment_curve_samples_midspan_point_load_stays_piecewise_linear`: 3.1 の補正が
  効き、折れ線を保つ。
- `moment_curve_samples_preserves_sample_values`: 評価断面の値と ξ 昇順を保つ。
- `moment_curve_samples_passes_through_short_input`: サンプル 2 点未満の縮退。

## 5. 残課題

- **区間内部に集中荷重がある場合**（評価断面と一致しない位置）は、真の M が
  区間内で折れるため補間は近似になる。評価断面に集中荷重位置を含めれば厳密に
  なるが、それは `eval_sections`＝検定位置の変更（上記 (A)）にあたるため
  見送った。危険断面として妥当かどうかは設計側の論点なので、必要なら
  `eval_sections_of` へ集中荷重位置を追加する形で別途検討する。
- **等変分布荷重の折れ点**（台形分布の \(a,\,b\)）が評価断面にない区間は、
  区間内で M の多項式次数が切り替わるため厳密にはならない（両端の値と勾配は
  合うので 3 次精度の近似）。
- Q 図の曲線化は未対応（上記 3.2）。必要なら分布荷重強度 \(w\) を結果側へ
  持たせる必要がある。
