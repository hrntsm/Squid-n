# 増分解析の終了目標拡張・表記変更 申し送り

作成日: 2026-07-27
対象ブランチ: `claude/pushover-improvements-vzm9sq`
関連文書: `../v_and_v/増分解析_ヒンジ形成と剛性低下_検証_2026-07.md`、
`../v_and_v/材端集中ばね梁_定式化レビュー_2026-07.md` §1.3

## 1. 何を実装したか（要約）

1. **UI 表記の変更**: プッシュオーバー解析のユーザー可視表記（解析タブの
   セクション名・結果タブ・ジョブラベル・エラーメッセージ・各ビューの見出し）を
   「増分解析」へ統一した。Rust の識別子（`push_*`・`ResultsView::Pushover` 等）と
   解析手法の説明コメントは変更していない（「増分解析（プッシュオーバー）」併記）。
2. **終了目標の拡張**: ソルバに `PushoverTarget`（`pushover/types.rs`）を新設し、
   終了判定を「目標変位 [mm]」「目標最大層間変形角（1/n）」の 2 本立てにした。
   それぞれ独立にトグルでき、有効な目標の**いずれかに最初に達した時点**で打ち切る。
   **既定は層間変形角 1/150 のみ有効**（GUI `AnalysisSettings`・MCP `JobParams` とも）。
   - 旧既定（目標変位 500 mm 固定）から**既定挙動が変わる**点に注意。
   - `pushover_analysis`（旧 API）は `max_disp: f64` のまま
     `PushoverTarget::from_max_disp` へ変換する互換ラッパー。
   - 従来の荷重制御中の早期終了判定（`roof >= max_disp`）は attempt ループしか
     抜けておらず機能していなかったため、`target_reached` フラグで是正した。
   - 層間変形角の階高は階標高の隣接差分（最下層は `base_elevation`＝生成マスターを
     除く最下端節点標高との差）。`statics::analysis::base_elevation` を公開化した。
3. **MCP**: `analysis_run` に `max_drift_denom`（層間変形角分母）を追加。
   `max_disp`・`max_drift_denom` とも未指定なら GUI 既定と同じ 1/150 のみで判定する
   （`JobParams::pushover_target` に集約）。
4. **材端集中ばね梁の定式化是正**: 検証の過程で「ヒンジイベントは出るが剛性が
   一切低下しない／降伏近傍で発散する」定式化欠陥を発見し是正した
   （詳細は関連文書参照。可撓端回転を内部自由度化し、ばね履歴を相対回転で評価、
   復元力を経路整合化。チェックポイント形式 `ConcentratedSpringCheckpoint` に
   可撓端回転 4 値を追加したため**旧チェックポイントとは非互換**）。
5. **ファイバー要素の塑性増分ヒンジ再定式化**: 塑性化域考慮モデルを
   「全可撓長の弾性梁＋端部塑性増分ヒンジ」の直列モデルへ再定式化し、
   降伏後の実剛性低下・全塑性崩壊荷重の頭打ちが表現されるようにした
   （残課題欄と `../v_and_v/増分解析_ヒンジ形成と剛性低下_検証_2026-07.md` §2.2 参照。
   `FiberBeamCheckpoint` にヒンジ状態 8 値を追加、旧形式はゼロ初期化で読込可）。
6. **耐震壁の軸・曲げのファイバー化（既定）**: 壁柱を塑性増分ヒンジ付き
   ファイバー要素へ差し替え、細長壁の曲げ降伏・N-M 相関を表現できるようにした
   （同 §2.4。せん断 Qu 頭打ちは維持し直列構成。`WallPanelCheckpoint` を新設、
   旧形式（変位のみ）は読込可）。

## 2. 残課題

- ~~**変位法ファイバー要素の剛性低下がほぼ生じない**~~ → **是正済み（2026-07-27）**。
  塑性化域考慮モデルを「全可撓長の弾性梁＋端部の塑性増分ヒンジ」の直列モデルへ
  再定式化し、弾性状態は弾性 Timoshenko 梁に厳密一致、降伏後は端部ヒンジへ塑性回転が
  局所化して要素剛性が実際に低下するようにした（単柱検証: k0=189.8→kt=33.8 N/mm、
  Qu=2712N が全塑性崩壊荷重 Vp=2750N の 98.6%）。MS 要素も実体が同じ
  `build_plastic_zone` のため同様に是正される。テストは
  `squid-n-solver` の `pushover/tests.rs::test_pushover_fiber_hinge_softens_at_drift_target`
  および `squid-n-element` の `fiber/tests.rs`（既存全テスト）。詳細は
  `../v_and_v/増分解析_ヒンジ形成と剛性低下_検証_2026-07.md` §2.2 を参照。
- 荷重制御中に崩壊機構が形成されると `NotPositiveDefinite` で解析全体が
  エラー終了する（同 §2.3）。
- 材端集中ばね梁の `state_member_forces` は未実装のまま（是正により実装可能になった）。
- 梁降伏型崩壊機構での Qu 手計算照合・武田型履歴での再 V&V。
