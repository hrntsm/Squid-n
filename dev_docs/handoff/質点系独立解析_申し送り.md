# 質点系を独立解析へ — 申し送り

作成日: 2026-08-14
対象コード: `crates/squid-n-solver/src/dynamic/lumped_mass/`、
`crates/squid-n-job/src/lumped_mass.rs`、`crates/squid-n-app`（右バー・結果タブ・3D）
関連文書: `docs/calc_basis/05_構造解析/10_質点系解析.md`

## 1. 目的

立体 FEM の固有値と質点系固有値を次数同士で比べると 1 次以外が合わない。主因は、
質点系が 1 方向せん断串であることに加え、変形モードを見る導線がなかったこと。
質点系を右バーの独立解析にし、2 次元／3 次元、線形／非線形、球・ばねの可視化を足した。

## 2. 変更内容

- 3 次元質点（各階 Ux, Uy, θz）。層 3×3 剛性は質量重心座標。ねじり KR は常に線形。
- 線形剛性は地震静的 EX/EY。定義は層 Q/δ（既定）または柱 ki。
- 非線形は増分解析のトリリニア。3 次元非線形は X・Y 両方の増分が必須。
- 増分結果は X/Y 別スロット（先行実装）。質点系は表示中の方向ではなく両スロットを読む。
- 右バー「質点系」（時刻歴の次）。実行はバックグラウンドジョブ。
- 結果タブ「質点系」は表・グラフのみ。3D は「質点モード」「質点時刻歴」。
- 時刻歴の層間・せん断・塑性率は X / Y / 45° / 最大の 4 欄（45° は 135° を含む斜め包絡。μ の最大は max(μX, μY)）。
- 結果見出しの剛性定義は線形時だけ出す。J・KR の単位は表見出しに出す。刺激係数・有効質量は出さない。
- 波形・減衰・モード数は立体時刻歴／立体固有値と独立。`.scz` に設定と結果を同梱。
- 質点モード・質点時刻歴では立体の支点記号を出さない。ほかの表示はツールバー「支点」（既定 ON）。

## 3. 立体固有値との周期差（2026-08-15）

4 層セットバックの実モデルで、立体 FEM と 3 次元質点の 1〜3 次を比べた。

- 層 Q/δ が全面的に短周期：層せん断を「当該層の柱せん断」としたあと、さらに上の層まで累積していた。柱せん断はすでに層せん断なので、再累積は剛性を過大にする。
- 3 次元の層 Q/δ は剛心位置の剛床層間を使う。代表節点差だとセットバックで平面位置がずれ、PH の K が落ちる。剛床なら Q/δ_剛心 は Σki と一致する。
- 柱 ki の 1・2 次は立体と合うが 3 次ねじれが短い：並進質量は地震用重量 W/g、J は CorrectedLumped のマスター RZ（部材密度控除後）だけだった。回転半径を保って J を W/g に拡げる。

## 4. 残課題

- MCP からの質点系実行は未配線。
- 曲げ系（等価曲げせん断・曲げせん断分離）は型として残るが UI からは外した。
- 3 次元時刻歴の密ガウス消去は層数が大きいと遅い（実務の層数では足りる想定）。
- 右アイコンが 7 個になり、低窓で下側が見切れる問題は残る。
- セットバック多層の 3×3 は各階 COM が鉛直に乗らない。並進 1・2 次は質量が下層に集中すれば実用上足りるが、塔屋が重い建物のねじれは未検証。
