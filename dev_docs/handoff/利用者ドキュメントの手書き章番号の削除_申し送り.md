# 利用者ドキュメントの手書き章番号の削除 — 申し送り

作成日: 2026-09-11

対象: `docs/`（mdBook）、`docs/SUMMARY.md`、`CONTRIBUTING.md`、`dev_docs/specs/`、コードコメントの参照

## 背景と経緯

mdBook はサイドバーの章番号を `docs/SUMMARY.md` の並びから自動採番します。
一方 `docs/calc_basis/` は見出し・SUMMARY・章内目次に手書きの番号を持っており、
サイドバーで「8. 1. 荷重・外力」「8.1. 1.1 地震力」のように自動番号と重なっていました。

手書き番号は既に不整合もありました（`1.3 床荷重の分配` のページ内の小見出しが `1.4.1`・`1.4.2`
になっている等）。ページを増減するたびに全番号と参照を追随させる必要があるため、
手書き番号を全廃し、番号は mdBook の自動採番に一本化しました。

## 変更内容

- `docs/calc_basis/` の手書き番号を削除（見出し 171、SUMMARY 74、章 `README.md` の目次 62）。
- 本文中の番号参照（`4.5 節`、`（4.1.2）`、`5.5.1〜5.5.2` 等）を、参照先の見出しタイトルの
  リンクへ置換し、リンクのアンカーを新しい見出し ID へ更新。
- `docs/calc_basis/README.md` の目次表から「#」列（1〜10）を削除。
- 現行ドキュメントの参照を更新:
  - `dev_docs/specs/数量積算.md`・`P5_非線形.md`・`P6_動的.md`
  - コードコメント（`crates/squid-n-element/src/factory/tests.rs`・
    `crates/squid-n-core/src/model/element.rs`・`crates/squid-n-app/src/section_editor.rs`）
- `CONTRIBUTING.md`「ドキュメントサイト（mdBook）」に、番号を手書きしない規約を追記。

## 影響・注意事項

- ページの URL は変わりません（ファイル名・ディレクトリ名は従来どおり）。
- `dev_docs/` の日付入り V&V・handoff にある旧番号の参照は、当時の記録としてそのままにしています。
- 本文から他の節を参照するときは番号ではなく見出しタイトルのリンクを使ってください。
  節タイトルを変更すると参照リンクのアンカーも変わるため、`mdbook build` 後のリンク確認を推奨します。

## 検証

- `mdbook build`（CI と同じ 0.4.52）が警告なく完了。
- `docs/` 内の内部リンクのうちアンカー付き 131 件が、ビルド後の HTML の見出し ID に解決することを確認しました。
