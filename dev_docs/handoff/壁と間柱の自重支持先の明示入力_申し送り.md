# 壁と間柱の自重支持先の明示入力

作成日: 2026-09-11

利用者の指定により、壁版の自重支持辺・鉛直な間柱の端部負担率を明示入力化した。地震用重量も同じ指定に従って主架構へ伝え、DL と密度直接集計の不一致を修正した。未指定や支持欠落では解析前エラーとする。壁の部分支持を全長支持とみなす不具合も修正した。支持梁が同じ辺で重なる場合は、重量の重複計上を防ぐため支持不備として診断する。

画面はモデルの壁版表に支持辺の負担率と間柱の端部配分を追加。MCP は `SetWallPlateAttrs.self_weight_shares` と `SetPostGravityEndShares` で編集できる。Undo と `.scz` の往復に対応。SCZ のデータ項目を追加するが、スキーマ番号は 1 のままとする。後方互換性は維持しない。ST-Bridge には指定値を書き出せないため、取り込み後に指定が必要。

[検証記録](../v_and_v/壁版の支持範囲判定_2026-09.md)を参照。負担率を支持剛性から自動算定する機能や間柱の断面検定は含まない。実験・実測による妥当性照合は未実施で、既存の未検証一覧で管理する。

壁剛性監査で剛体回転時の不要な内力を再現し、利用者の「面外回転はピン」の指定に基づき修正した。壁柱の面外曲げ抵抗は考慮しない。詳細は[耐震壁の検証記録](../v_and_v/耐震壁_敵対的レビュー_2026-07.md)を参照。

非線形時刻歴で壁柱断面力が欠落する未実装メソッドも接続した。降伏後の出力は現在状態に基づき、全変位へ弾性剛性を乗じて復元しない。

壁質量行列にも自重と同じ内法係数を適用した。内法係数はcoreへ共通化した。

壁の節点順で面積が相殺される経路を防ぐため、上下辺の対応付けをcoreで共有し、剛性・自重・質量の幾何を統一した。

上下辺に水平ずれのある壁で左右対応が逆転する不具合も修正した。上辺は下辺軸への符号付き射影の順に対応付ける。

未使用で矩形極限に誤りのある旧せん断形状係数APIも削除した。実計算で使う積分式へ一本化した。

現行κ式の積分を区分多項式の解析積分へ変更した。同じ理論式を評価し、数値積分の分割数・境界調整値を削除した。

壁自重を支持柱の軸方向部材荷重とする経路の監査で、固定端スパン軸力の符号・分布の誤りを修正した。詳細と回帰結果は耐震壁の検証記録の「壁自重を受ける柱の軸力復元」を参照。

側柱の断面形状未定義は入力エラーとすることが利用者により確定した。解析前診断を追加した。側柱断面統一の方針確認待ちはなく、実装を継続する。

側柱の任意角度の端部解放を壁法線の方向に合わせ、既存の静縮約へ共通化した。断面積分の統一は未完了。

区分一定幅の非対称断面の共通積分処理を追加し、既存の対称I形κへ接続した。重複控除後の壁・左右柱形状の接続は未完了。

左右別寸法の矩形柱と壁の和集合断面を求める補助処理を追加した。材料評価の方針は承認済み。壁要素本体への接続は未実施。

2026-09-13: 材料ごとのE・Gを反映する方針で再開した。区間内単一材料の断面積分を実装し、既存の均質断面積分もこの処理へ共通化した。SRC/CFTと任意角度形状の接続は継続課題。

2026-09-13: 平行・直交配置の矩形RC側柱の重複控除・材料定数付きせん断剛性を壁要素へ接続した。他形状・幅方向異材は未対応として暫定的に入力エラーにしており、ユーザー要件を満たすには引き続き実装が必要。耐力側の平均柱せい等の統一も残る。

2026-09-13: 再開後のレビューで、長期軸力無効化が側柱の `shape` を削除して壁断面算定を停止させる不具合を確認。モデルを複製して断面を変更する処理を削除し、要素生成後の軸剛性用断面積だけを低減する方式に変更した。引張専用ブレースの非有効状態も同じ生成関数を使用する。SRC柱の曲げ・せん断・ねじり剛性と質量を保持する回帰検証を追加。

SRC/CFTの材料別E・G反映と、鋼材・コンクリートの完全付着は利用者が承認した。界面すべりが生じる場合には変形を過小評価しうる危険側の近似であり、計算根拠にも明記する。完全付着の承認は、幅方向異材を単純平均したり、任意角度の断面を外接矩形に置換する承認ではない。PRは全要件の実装・レビュー・検証後に作成するよう依頼を受けている。

## 2026-09-13 最終実装・レビュー

一次元せん断流モデルの幅方向共通ひずみを利用者が承認し、全定義形状の材料領域を壁のせん断計算へ接続した。SRC/CFTの材料差・円弧・任意角度・中空部分を扱う。左右別のRC壁終局耐力と正負別履歴ばね、符号付き壁せん断力による保有耐力判定も接続した。詳細は[検証記録](../v_and_v/壁断面統一と正負別せん断耐力_2026-09.md)を参照。

SRC/CFT側柱を持つRC壁の終局耐力式は既存の未対応範囲であり、弾性剛性の対応とは分離した。主筋が取得できない側柱をRC式で無理に計算しない。形状未定義は入力エラー、SCZ番号は1を維持する。

### 自重支持入力の実装経緯

利用者の指示により、要素にならない囲まれた壁版の支持辺を `self_weight_shares` で、鉛直な間柱の上下端を `gravity_end_shares` で明示指定する方式へ変更した。未指定・不正指定では解析を止め、支持不能な辺の荷重を別の辺へ振り替えない。間柱自重も同じ端部負担率で配る。地震用重量も同じ指定を使う方針が利用者から指定されたため、密度直接集計を逐次伝達へ接続し、DL 経由との階重量一致を端部負担率 0・0.25・1 で確認する統合テストを追加した。

GUI と MCP の編集コマンド、Undo、SCZ 保存へ接続した。SCZ のデータ項目を追加するが、スキーマ番号は 1 のままとする。後方互換性は維持しない。ST-Bridge は指定値を持たず、取り込み後の指定が必要。自重負担率を明示した囲まれた壁版は取り付く壁版へ自動変換しない。

計算根拠2ページの自重分配の矛盾を解消し、間柱の端部配分の残課題を除いた。「すべて安全側」としていた記録を訂正した。負担率は利用者が支持条件から決める入力であり、妥当性をプログラムが判定するものではない。実験・実測との照合は未実施。


### 壁断面と解析経路の実装経緯

- 2026-09-11: 面外回転ピンの指定を受け、弾性・ファイバーの静縮約と断面力復元を共通化。状態断面力の欠落を是正し、荷重と質量の内法面積、節点列挙順を統一した。上下辺の対応には符号付き射影を使用した。未使用の旧κ関数を削除した。
- 2026-09-12: せん断エネルギーの区間積分を解析積分へ置き換えた。κの断面と剛性分子の面積が不一致で、側柱の左右差・向きが失われることを確認。重複控除と左右個別断面への統一、形状未定義の入力エラー化を利用者へ確認した。柱軸力の部材荷重復元も是正した。
- 2026-09-12〜13: 任意方向の側柱回転解放、非対称幅の共通積分、矩形の和集合、材料定数付き積分の順に準備した。矩形RC側柱だけを接続した途中段階では、全形状対応は未完了だった。これは適用形状を制限する確定判断ではなく、未実装形状に旧式を適用しないための途中状態である。
- 2026-09-13: 長期軸力無効化で側柱形状が消える不具合を是正した。完全付着に加え、幅方向共通ひずみの一次元モデルの承認を受けて全定義形状を接続。正負別耐力の指定に従い、壁ばね・応答側へ両方向の値を接続した。

判断の正本はADR 0018・0019、数値的な証拠は[追加回帰検証](../v_and_v/耐震壁_敵対的レビュー_2026-07.md#2026-09-追加回帰検証)と[断面・耐力検証](../v_and_v/壁断面統一と正負別せん断耐力_2026-09.md)に分離した。
