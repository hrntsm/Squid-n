# app `actions` の解析種別分割 — 申し送り

作成日: 2026-08-13
対象コード: `crates/squid-n-app/src/app/actions/`

この申し送りでは、解析ジョブの親モジュールを解析種別ごとに分けた経緯を記録します。

`actions/mod.rs` は 1436 行あり、ジョブの共通入口と、静的・固有値・増分・時刻歴の実行が同居していました。
解析の種類が違うと直す理由も違うため、1 ファイルのままではレビューの単位が読めません。

今回は `begin_analysis` と `spawn_analysis_job` と `poll_job` を親に残し、種別ごとの実行だけを兄弟ファイルへ移しました。
計算内容と実行の挙動は変えていません。

## 背景

前の波で、設計入口と入出力と荷重同期はすでに切ってあります。
詳細は [`app_actions設計塊分割_申し送り.md`](app_actions設計塊分割_申し送り.md) を参照してください。
`panels` と `viewer` も、画面と描画の境界で分けてあります。

残っていたのは、解析ジョブそのものです。
相互呼び出しが多いため、設計塊の分割では親へ残していました。
画面側の分割が終わったいま、種別の境界だけを切り出します。

束ね方は `design/` と同じ型です。
共有基盤は親、各解析は兄弟ファイルです。
`static` は Rust の予約語のため、線形静的のファイル名は `linear_static.rs` にしています。

## 変更内容

`actions/mod.rs` から、次の兄弟ファイルへ実行を移しました。

```
actions/
  mod.rs            — ジョブ基盤、診断、通り芯・階・組合せの生成
  linear_static.rs  — 荷重ケース・組合せ・一括・地震静的、結果の表示切替
  eigen.rs          — 固有値解析
  pushover.rs       — 増分解析
  time_history.rs   — 時刻歴応答解析
```

`mod.rs` は 1436 行から 616 行になりました。
残しているのは、エラー通知、解析前処理、ジョブの起動と完了待ち、診断、通り芯と階と標準組合せの生成です。
これらは解析種別をまたぐ入口だからです。

地震静的は線形静的の結果キーへ格納するため、`linear_static.rs` に置いています。
波形ライブラリは、すでに `wave_library.rs` があるため混ぜていません。

`poll_job` は親に残しています。
完了したジョブの結果適用だけは、各種別の `apply_*_result` へ委譲します。
親から呼ぶため、これらの関数は `pub(super)` に上げました。
計算内容は変えていません。
`begin_analysis` と `spawn_analysis_job` と `run_compute` は、親の非公開のままです。
子モジュールからは親の非公開アイテムが見えるためです。

公開メソッドのパスは変えていません。
`App::run_linear_static` などは、別ファイルの `impl App` に移しただけです。

## 設計判断

- **ジョブ基盤は親に残す。** 前処理と起動と完了待ちを種別へ複製すると、抜けが再発する
- **地震静的は線形静的へ寄せる。** 結果の格納先が `StaticCaseKey::Seismic` であり、固有値とは別物
- **波形ライブラリは切らない。** 保管と選択の責務は、時刻歴の求解とは違う
- **通り芯・階・標準組合せは親に残す。** モデル操作であり、解析ジョブではない

増分解析のファイル名を `incremental` に揃える案もあります。
ですが、型とジョブ結果はすでに `Pushover` なので、コード上の名前に合わせました。

## 意図的にやらないこと（残課題）

本波（GUI のファイル分割）の対象だった 3 点は、これで揃いました。

本波の対象外は、次のとおりです。

- `AppCore` / `UiState` への型分離（専用ブランチ）
- app／MCP の設計入口を `squid-n-job` へ寄せること（機能統合）
- 巨大テストファイルの分割
- 薄い再エクスポートの削除、`floor_grillage` の所属移動

## まとめ

解析の入口は親に残し、種別ごとの実行は兄弟ファイルへ出しています。
GUI のファイル分割は、画面・描画・解析ジョブの 3 点で一通り終わります。
次に切る単位は、型の分離か、設計入口の job 寄せです。
