# スチールブルー配色 — 申し送り

作成日: 2026-08-13
対象コード: `crates/squid-n-app/src/theme.rs`、`app/mod.rs`、
`app/panels/status_bar.rs`、`assets/icons/*.svg`
関連文書: `TONMANUAL.md`（現行仕様）、`../specs/UI設計.md` §1

## 1. 目的

画面クロームを工学系デスクトップらしいスチールブルーへ寄せる。トークン名
（`BLUE_200` など）は維持し、HEX と使い分けだけを変える。検定・グラフの
セマンティック色（赤／黄／緑／紫／アンバー／ティール）は据え置く。

## 2. 変更内容

- `theme.rs` のパレットをスチールブルー／青みグレーへ更新した。
- ホバーは `BLUE_300`＋暗い文字。淡い青の上に白文字は置かない。
- 入力欄・通常ボタンは白背景。
- 淡色パネル上の注意ラベルは `WARN_TEXT`（`#D97706`）。グラフ用の `BEST_YELLOW` は文字に使わない。
- 上部ツールバーは `toolbar_frame`（`BLUE_200`）。下部ステータスバーは
  `status_bar_frame`（`BLUE_400`）。バー上の文字は白（実行中・stale・エラー・注意）。
  エラー行クリックは `open_log_dock` でログタブへ切替える。
- 左右ドックは `content_panel_frame`（`GRAY_100`、ツールバーより淡い）。
  中央キャンバスと下ドックは `central_panel_frame` / `VIEW_BG`（白）。
- アクティビティバーの SVG のうち、トークンに紐づく 5 色を焼き直した
  （ナビ／インスペクタ／作成／準備／静的）。

現行の HEX とコントラスト規約は `TONMANUAL.md` を正とする。本書は経緯のみ。

## 3. 残課題

なし。
