# 計算根拠の単位表記は法令・規準の単位に従う

Status: accepted

`docs/calc_basis/` の記号・単位表および算定式は、法令・告示・学会規準が用いる単位で記載する。内部実装の単位系（N-mm-s。[ADR 0001](0001-internal-units.md)）はドキュメントの記載基準にしない。内部値と表示値の換算は画面表示の都合であり、換算表で示す。

内部単位が法令の式と食い違う量（建物高さ h、地下階の深さ H など）でも、ドキュメントは法令の単位（m）で書き、実装は境界で換算する。表を内部単位に合わせると表と法令の式が矛盾し、実装都合の換算がドキュメントへ漏れるためである。
