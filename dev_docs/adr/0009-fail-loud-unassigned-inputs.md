# 未設定の材料・断面を既定値で埋めない

Status: accepted

解析に必要な材料・断面が未設定のとき、もっともらしい既定値で補わず解析前チェックで止める。物性ゼロの断面（`Section::zero`）は 0 のまま解析へ進ませて不備を顕在化させる。無音の既定値は危険側の結果を招くため、規準上の最小値であることを説明できる安全側の既定（例: 壁横筋 295 N/mm²）を除いて行わない。到達可能なまま残る既定値（形状未設定断面の鋼材 σy など）は V&V の残課題として追跡する（`dev_docs/v_and_v/未入力材料強度の危険側フォールバック_2026-07.md` §5.2・§5.4）。
