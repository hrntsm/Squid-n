# 階と剛床を分離し、階は床レベル基準の利用者定義とする

階（層間変形・層せん断力・剛性率・偏心率の基盤）と剛床（面内剛体拘束）を別概念とし、剛床は拘束が保持する。階は床レベル基準で利用者が定義し（階のレベルはその階が代表する床のレベル。既定の階名は `{n}F` で、最上階も屋根と決めつけず数字で通す）、法規上の層は階の対から導出する。1 つの階が剛床を持たないこと・複数の剛床を持つことを許す代わりに、階への帰属は区間、剛床への帰属は床面のレベル一致という別々の規則で決める。
