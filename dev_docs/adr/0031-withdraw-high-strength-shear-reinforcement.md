# 高強度せん断補強筋の製品別対応を撤回する

Status: accepted

## 決定

高強度せん断補強筋の製品別対応（製品別の pw 上限・σwy・w_ft、終局せん断強度の σwy/ν0/pw 上限、耐震壁 Qu と SRC 非充腹梁の κ=0.068、MK785/SPR785/SPR685 の QL=Q0 読み替え）を実装・docs から削除する。

せん断補強筋として対応するのは普通強度の `SR235`・`SR295`・`SD295`（`SD295A`・`SD295B` を含む）・`SD345`・`SD390`・`SD490` に限る。これら以外のグレード（高強度品の製品名・未知名）を割り当てたモデルは fail loud で停止する（[ADR 0009](0009-fail-loud-unassigned-inputs.md) と整合）。

- RC・SRC の許容応力度検定: `CheckOutcome::Skipped`（検定不能・理由付き）
- RC 終局検定: `collect_rc_ultimate_checks` が `Err`
- 解析（増分・時刻歴）: 解析前チェック（`member_strength_issue`・耐震壁の `wall_shear_capacity_issue`）がエラー
- 壁エレメントのせん断耐力: 算定不能（`shear_capacity_of` は 0）

対応グレードの材料を割り当てているのに `f_y` が未設定または 0 以下の場合も同じく入力不備として停止する。無言で既定 295 N/mm² を用いると、`SR235`（`f_y = 235`）で σwy を 235 から 295 へ増やす危険側の評価になるためである。既定 295 N/mm² は材料未割当（`None`）のときだけ用いる。

判定とエラー文言は `squid_n_core::material_grade::shear_rebar_material_issue` に集約し、未対応グレードの判定・文言（`is_supported_shear_rebar_grade`・`unsupported_shear_rebar_message`）を内部で用いる。

## 背景と理由

製品別の pw 上限・σwy・w_ft は各製品の大臣認定・技術評定に依存する（Category B）。原典資料（技術評定書）が未整備のまま、参照実装マニュアルの記載から転記した暫定値を実装していた。原典で照合できない係数を本ソフトの計算根拠として残せない。

さらに、名称が `SD*`・`SR*` でなければ高強度とみなす一般判定（`is_high_strength_shear_grade`）は、未知名を高強度品として扱う。未知名に高強度の σwy・pw 上限を適用すると、実際の材質より大きい降伏強度で耐力を評価しうる**危険側**の一般化だった。

当面、高強度せん断補強筋を用いるモデルは不要である。

## 影響

- 高強度せん断補強筋を用いた既存モデルは、検定・解析が停止する（後方互換は維持しない。[ADR 0014](0014-schema-compatibility.md)）。
- 普通強度の σwy は、割り当てた材料の `f_y` から解決する。材料未割当のときのみ 295 N/mm²（SD295 相当の代表値）を既定とし、対応グレードで `f_y` 未設定なら入力不備として停止する。旧実装は材料名から `rebar_grade_f_value` で推定しており、`f_y` を用いていなかった。高強度専用だった「製品別の上限」は用いない。
- 再実装は、対象製品の技術評定書（pw 上限・σwy・ν0・w_ft の原典）を揃え、製品別式の安全側／危険側を判定してから行う。
