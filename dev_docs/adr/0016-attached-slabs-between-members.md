# 取り付く床板は支持部材の間ごとに表す

Status: accepted

取り付く床板（片持ち・バルコニー）は、下の小梁などの支持部材で区切られた1枚ごとに 1 つの `SlabShape::Attached` とし、取付き線は部分区間 `span` で表す。床板の分割・統合は床領域の付け直し（`rebuild_floor_regions`）で毎回行い、取り込み・準備計算・荷重同期のどの経路でも同じ表現になるようにする。

床板は小梁の間にあり、小梁を横切る 1 枚の床板では表さない。「既存の取り付く床板は残す」という現行の例外をなくす。支持部材を消せば同じ版仕様の床板は統合する。

分割の境界にするのは、取付き線に直交し、取付き線から先端まで届く小梁だけとする。直交しない・途中で終わる小梁は境界にせず、診断（警告）で知らせる。分割と支持辺への分配は取付き線へ分布（`LoadTransfer::Anchor`）の床板に適用し、両端の柱へ集中（`Columns`）と点（出隅）は従来どおりとする。
