# 仕口パネル解析要素と柱梁接合部の断面算定を分離する

Status: accepted

## 背景

仕口パネルは接合部のせん断変形を解析モデルへ組み込む解析要素であり、柱梁接合部は断面算定の対象である。両者を同一視すると、仕口パネルをモデル化しないことを理由に接合部の断面算定まで省略するおそれがある。

この境界は解析モデルと断面算定の双方に及ぶため後から覆すコストが高く、モデル化範囲と検定範囲を単純に一致させる運用とのトレードオフがある。剛節点モデルでも部材端力から接合部を検定できる点は、仕口パネルの有無と検定の有無を分ける判断として意外性がある。

## 決定

仕口パネル解析要素は S 造のみでモデル化し、CFT ではモデル化しない。仕口パネルをモデル化しない接合部でも、柱・梁の端部応力から柱梁接合部の断面算定を行う。解析上の剛節点モデルであっても、部材端力から接合部を検定できるためである。断面算定の対象範囲は既存の設計仕様に従い、CFT の断面算定は行う。

## 結果

仕口パネル解析要素のモデル化と柱梁接合部の断面算定を独立して扱う。これにより、解析モデルの選択によらず必要な接合部検定を維持し、用語と実装上の責務を混同しない。
