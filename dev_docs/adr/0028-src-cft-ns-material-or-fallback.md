# SRC/CFT の等価断面剛性は材料由来 ns を通常とし、算定不能時は N_S_EQ=15 へフォールバックして通知する

Status: accepted

## 決定

SRC/CFT の要素剛性の通常経路は、要素材料（SRC はコンクリート、CFT は鋼管）のヤング係数から \\( n\_s = E\_{\text{steel}}/E\_c \\)（CFT は鋼基準）を算定する。SRC 規準の \\( n = E\_s/E\_c \\) に一致する。

材料由来の値を使えないとき（主材料の `fc` 未設定、ヤング係数が 0 以下）は、SRC は `N_S_EQ = 15`、CFT は充填コンクリートを無視した鋼管のみへフォールバックする。`Section` が形状だけから生成する `iy`・`iz`・`as_y`・`as_z` は材料を知らないための暫定値であり、SRC は `N_S_EQ = 15` で鉄骨を等価換算し、CFT は充填コンクリートを含めず鋼管のみとする。材料由来の値が使えるときは要素剛性側で上書きする。

フォールバック時は利用者へ通知する。解析前チェック／診断タブは警告を出し、準備計算「部材剛性」表はフォールバック行を例外として載せ、断面名に SRC は「（既定値 15）」、CFT は「（鋼管のみ）」を付ける。

## 背景と理由

docs は `N_S_EQ = 15` を ns の既定として説明していたが、実装の通常経路は材料由来の値を算定しており、位置付けが一致していなかった（Issue #306）。15 は形状だけから断面諸量を生成する場合と、材料由来の値が無い場合の暫定値であり、通常経路ではない。

フォールバックを黙って行うと、利用者が `fc` 未設定のまま剛性を過大評価した結果に気づけない。診断と準備表で通知する。

## 影響

- `N_S_EQ = 15` は原典照合待ちの暫定値であり、典型的な材料由来値より大きい。剛性を過大評価する方向に働き、全体変位には非保守・着目部材の応力には保守となって一方向に定まらないため、安全側とは言い切れない。
- フォールバック行は、割増しも等価換算もない部材でも準備計算の部材剛性表に載る例外となる。
