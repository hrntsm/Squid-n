# 同じ位置に支持部材が重なる場合は同種をエラー、異種は主架構優先とする

Status: accepted

同じ境界辺の位置に支持部材が重なるとき、**同種どうし**（主架構どうし＝大梁・柱、二次部材どうし＝小梁・間柱）が同一材軸上で正の長さにわたって重なる場合は、どちらが荷重を受けるか一意に決まらないため解析前チェックのエラーとする。**異種**（主架構と二次部材）の重なりは主架構を採用し、割当領域の支持部材を主架構とする。平行に並ぶだけ（材軸が一致しない）の部材は、材軸が一致して区間が重なるものではないため、重なり検出と主架構優先の対象にしない（別の辺の支持部材や、領域を分割する間柱にはなり得る）。

面走査は同じ向きの辺のうち先に挿入された辺を採用するため、主架構を常に先に渡すことで主架構優先を規則として保証する。重なりの検出（`Model::same_kind_support_overlaps`）は面走査へ入れる支持部材だけを対象に、要素順・安定 ID 順に依存しない形で行う。同種の重なりを自動で一意化して続行する案は、利用者が重複に気づけないまま荷重経路が決まるため採らない。
