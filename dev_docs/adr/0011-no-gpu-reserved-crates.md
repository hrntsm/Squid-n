# GPU は実装せず、ML は着手時にクレートを新設する

GPU 高速化は恒久的に実装せず、GPU・ML の予約クレートや `gpu`／`ml` feature を置かない（実装の入らない空スタブを残さない）。GPU 経路の f32 概算モードは持たず、大規模向けの解は CPU で確定する（反復ソルバ PCG の f32 演算は GPU とは別の既存経路）。ML 断面提案は方針を維持するが、クレートは着手時に P11 仕様に従って新設する。
