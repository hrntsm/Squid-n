# 壁の材料別実断面と正負別せん断耐力を採用する

Status: accepted

壁と左右側柱の重複を控除し、個別の形状・向き・材料を反映した断面を用いる。形状未定義は入力エラーとする。SRC・CFTは完全付着とし、各位置の材料別実幅からE・Gを積分する一次元せん断流モデルを採用する。完全付着だけでは幅方向のせん断ひずみ一定を保証できず、局所変形を過小評価しうる危険側の近似だが、ユーザーが説明を受けて明示的に選択した。

RC壁の正負耐力は左右の引張側主筋と圧縮側柱を入れ替えて求め、壁ばね・応答による耐力選択へ別々に渡す。小さい共通耐力への置換は応力再配分を変えるため採用しない。弾性断面の対応範囲と耐力式の適用範囲を区別し、未対応のSRC・CFT側柱付きRC壁の非線形解析を代替式で続行しない。

壁柱の面外回転は弾性・ファイバーとも両端ピンとし、内部自由度として静縮約する。面外曲げ抵抗を期待しないことはユーザーの明示指定である。ADR 0013の壁エレメント置換モデルを具体化する。
