# スキーマ互換は初回リリースまで維持しない

Status: accepted

モデル保存（.scz）のスキーマ互換は初回リリースまで維持しない。`CURRENT_SCHEMA_VERSION` を 1 のまま破壊的変更を直接行い、版間のマイグレーションは実装しない。リリースは git タグで判定し、タグ以降のスキーマ変更は版を上げてマイグレーションを実装する。開発中のファイルを互換の制約にせず、リリース後の利用者データだけを移行対象にするためである。
