# 壁エレメントは壁版から都度生成する派生物とする

Status: accepted

壁の入力の正は壁版とし、解析要素（壁エレメント）は解析・剛域算定・診断の直前に壁版から決定的に生成して、モデルへ保存しない。要素になるのは壁領域全体を覆う 4 節点で断面が割り当てられた囲まれた壁版だけで、それ以外は壁エレメントにならない壁版として荷重を運ぶ。要素 ID が入力でなくなる代償として、要素 ID を参照する経路はすべて壁版起点へ張り替え、幾何と厚さの二重管理を排除する。
