# コンクリートの許容圧縮・せん断応力度は基準資料（表2.1.1-2）を正とする

Status: accepted

## 決定

普通コンクリートの許容圧縮応力度は長期 \\( F\_c/3 \\)、短期は長期の 2 倍とする。許容せん断応力度は長期 \\( \min(F\_c/30,\ 0.5 + F\_c/100) \\)、短期は長期の 1.5 倍とする。

軽量コンクリート 1 種・2 種は、許容圧縮応力度を普通コンクリートと同じ値とし、許容せん断応力度のみ普通コンクリートの 0.9 倍とする（長期・短期とも）。付着許容応力度と鉄筋・鋼材の算定式は変更しない。

## 背景と理由

一般に流通する RC 規準の許容せん断応力度は \\( \min(F\_c/30,\ 0.49 + F\_c/100) \\) と表記されることが多く、本実装も 0.49 を採っていた。基準資料 2.1.1 表2.1.1-2 は 0.5 を採っており、本プログラムは基準資料を正とするため 0.5 とする。

0.5 は 0.49 より大きい。許容せん断応力度をわずかに大きく評価する（せん断検定比を小さくする）方向に働くが、差は 0.01 N/mm² であり、基準資料への一致を優先する。付着の式が 0.9 や 1.35 であるのに対しせん断のみ 0.5 となる点は、基準資料の表記どおりである。

軽量コンクリートの 0.9 低減について、実装は許容圧縮・許容せん断の双方へ適用していたが、基準資料 表2.1.1-2 は許容せん断応力度のみに 0.9 を適用し、許容圧縮応力度は普通コンクリートと同じとしている。これに合わせ、許容圧縮応力度はコンクリート種類に依存しない関数へ統一し、せん断のみ種類別係数を掛ける。

## 影響

- 許容圧縮応力度がコンクリート種類に依存しなくなるため、種類別関数 `concrete_allowable_compression_class` を削除し、呼び出し側は `concrete_allowable_compression` に統一する。`concrete_class_factor` は `concrete_allowable_shear_class` 専用となる。
- 軽量コンクリートの許容圧縮応力度が 0.9 倍から普通コンクリートと同値になり、圧縮の検定比が小さくなる。
- 0.49 → 0.5 により、せん断の許容応力度がわずかに増える。
- RC 耐震壁（`rc::wall`）・RC 柱梁接合部（`rc::joint`）・SRC パネルゾーン（`srrc::panel_zone`）の入力に `ConcreteClass` を追加し、これらの許容せん断応力度にも種類別係数 `concrete_allowable_shear_class` を通す。従来これらは種類係数なしの `concrete_allowable_shear` を用いており、軽量コンクリートでも 0.9 低減が効いていなかった（軽量の壁・接合部・パネルゾーンのせん断耐力を危険側に過大評価していた）。この配線により、当該部位の軽量コンクリートの許容せん断力は従来より 0.9 倍になる。
