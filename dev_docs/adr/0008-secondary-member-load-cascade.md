# 二次部材の荷重は支持相手へ逐次伝達し、交点は常にピンとする

二次部材が受けた荷重は単純梁の両端反力として支持相手へ渡し、支持相手が二次部材なら同じ操作を主架構へ届くまで繰り返す。交点は常にピン・架けとし、剛接十字は扱わない。水平投影が 0 でない部材は材軸上の按分（単純梁の反力）と厳密に一致し、一律ピン扱いの影響は架け側のモーメント・たわみを安全側に見る点に限られる。水平投影が 0 になる鉛直な間柱だけはつり合いが退化して不静定であり、両端へ 1/2 ずつの仮定が残る（残課題）。
