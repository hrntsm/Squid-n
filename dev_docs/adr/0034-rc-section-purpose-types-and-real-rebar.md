# RC 断面を用途別に型分離し、実配筋モデルへ移行する

Status: accepted

## 背景と決定

旧 `RcRebar`（方向別の総本数＋段数）は、RC 梁の上端筋・下端筋それぞれの段別本数を保持できず、主筋総量を上下半分と仮定する箇所（`bar_set_area(...)/2`）や、ST-Bridge の段別本数を合算して失う処理が複数あった。これを解消するため、RC 断面を **RC 矩形梁・RC 矩形柱・RC 円形柱** に型分離し、配筋を用途に応じた段別本数の列で保持する実配筋モデルへ移行する。RC 円形梁はサポート対象から削除する。SRC 梁・柱の RC 部分も同じ実配筋モデルを再利用し、SRC 専用の配筋型は持たない。

## 段の定義

- 梁: 上端筋・下端筋それぞれ、かぶり側から内側へ数えた列。1 段は 1 本の配筋線。
- 矩形柱: X 方向・Y 方向それぞれ、断面中心対称な 2 本の配筋線を 1 段とし、本数は片側 1 線あたり。X/Y の交点は 1 本として重複計上しない。
- 段間中心距離は既存 `rc_rebar_geom` の規約（`clear = max(25mm, 1.5・dia)`）を単一情報源とする。
- 主筋径は断面内で共通とする。

## 帰結

- 上下同量の暗黙仮定を廃止し、実配筋から面積・重心・有効せい・`pw`・ファイバー・数量を算定する。
- ST-Bridge は対応できる情報のみ正確に往復し、内部段数が出力仕様（1〜3 段）を超える場合は黙って切り捨てず警告で可視化する。
- `.scz` の後方互換は取らない（[ADR-0014](0014-schema-compatibility.md) 準拠。`CURRENT_SCHEMA_VERSION` は 1 のまま）。
- 実鉄筋座標は派生値とし、モデルへ二重保存しない。

## 検討した代替案

- 同一 `RcRect` に用途フラグを追加する案は、配筋の意味が型に現れず計算側の読み替えが残るため不採用。
- 矩形柱の段を片側 1 線で数え総本数を別に倍する案は、ST-Bridge の `N_main_X_1st` と意味がずれ、検証規則が複雑になるため不採用。
