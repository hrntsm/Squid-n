# 耐震スリット指定が辺へ反映できない場合は警告する

Status: accepted

耐震スリットは境界が 4 節点の囲まれた壁版にのみ適用できる。境界が 4 節点でない場合、および境界が 4 節点でも境界頂点のモデル節点を引けない等で辺を柱際・梁際へ対応付けられない場合、指定は反映されない。このときは解析を止めず、準備計算の診断で警告する。

指定の反映可否の判定は荷重モジュールの `wall_plate_load::slit_specification_is_reflected` に 1 か所だけ置き、荷重分配と診断が同じ答えを見る。指定を無視したまま縁を切ったつもりで進むことを防ぐ一方、指定が効かないこと自体は自重の行き先を失わせないため、エラーで解析を止める扱いにはしない。
