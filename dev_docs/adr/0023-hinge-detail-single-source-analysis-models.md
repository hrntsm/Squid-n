# ヒンジ詳細の表示は解析要素と同じ非線形モデルを単一情報源とする

Status: accepted

ヒンジ詳細の背景曲線は、解析が使用していない `squid_n_section::mn_surface` の表示用モデルで描かれていた。表示と解析が別の骨格・曲面を見るため、応答経路が背景曲線に一致しない・はみ出すことがあり、画面上で区別できなかった。

表示は、解析要素と同じパラメータ解決とファイバ生成を通る読み取り専用 API `squid_n_element::factory::build_hinge_view` を単一情報源とする。GUI に解析の式・既定値・ファイバ配置を複製しない。材端集中ばねは解析用材料骨格（初期載荷の包絡線）と強軸（Mz）のみの線形 N-M 相関を表示し、ファイバー／マルチスプリングは解析と同じ入力から全塑性曲面を再算定して表示する。解析本体はファイバー積分で応答を決めるため曲面はその可視化であり、全塑性挙動そのものではない（硬化を無視するぶん初期耐力としては安全側。劣化は考慮しないため、劣化後の耐力はこの曲面より低下しうる）。固定骨格を持たないファイバー系の M-θ は応答経路のみを表示する。

現行 `mn_surface` の 3 モデル比較表示をヒンジ詳細に残す案は、解析結果の検証に使えない値を引き続き見せるため採用しない。解析要素の実材料へ単調載荷するソルバを新設して包絡線を得る案は、履歴則と荷重履歴に依存する応答を別実装で再現することになり、解析との乖離を再発させるため採用しない。

これにより表示と解析の再乖離を防ぐ。再算定が重い曲面は断面・材料・履歴則の指紋と結果世代をキーにキャッシュし、断面・材料・履歴則の編集や同一ステップ数の再解析に追随する。

## 関連する結果スキーマの変更

本方針に伴い、解析結果のスキーマを次のとおり変更した。いずれも解析の数値・収束結果は不変である。

- `ElementBehavior::end_spring_rotations()`（材端集中ばねのばね変形を返す読み取り専用アクセサ）を追加し、`MemberStepState::spring_rz_i`／`spring_rz_j`（必須の `f32`。端ばねを持たない要素は 0）を追加した。M-θ 応答経路の横軸を、解析が端ばねに対して実際に使う端ばね変形へ統一するためである。旧結果は両フィールドを欠くためデシリアライズに失敗し、再解析を要する。
- `MemberStepState::n` を符号付き圧縮正（引張は負値）へ是正した。従来は引張を 0 にクランプした圧縮マグニチュードを記録しており、材端集中ばねの N-M 線形相関が引張部材で耐力を過大に見せる危険側の表示となっていた。解析が用いる軸力に対する `MnInteraction::moment_limit` は絶対値を使うため、解析の数値・収束結果は変えずに表示だけを解析と一致させた。なお、引張を 0 にクランプした値は `PushoverMemberResponse::axial` とせん断降伏判定の軸力項が引き続き用いる（`axial_compression` は残す）。
