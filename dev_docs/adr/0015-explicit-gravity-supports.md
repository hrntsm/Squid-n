# 壁自重の支持辺と鉛直二次部材の端部負担率を明示する

Status: accepted

二次部材の荷重は支持相手へ逐次伝達し、交点はピンとする。水平投影が10 mmを超える部材は単純梁反力を用い、それ以下は利用者が両端の負担率を明示する。壁エレメントにならない囲まれた壁版も、境界辺への自重負担率を明示する。未指定・不正値・指定先で支持できない場合は入力エラーとし、別の辺へ振り替えない。地震用重量も同じ支持先と端部負担率で配分する。

幾何だけから左右支持や上下等分を推定すると、下梁で受ける壁の梁応力を過小評価しうる。ユーザーは支持先の明示入力と地震用重量への共通適用を選択した。単純梁のピン条件が実際の支持と異なる場合も、安全側になるとは限らない。

ADR 0008の逐次伝達を継承し、鉛直部材の上下等分と一律安全側という判断を置き換える。保存スキーマはADR 0014に従い版1を維持する。
