# 片持ち小梁は支持条件で表し、基端モーメントは伝達しない

Status: accepted

二次部材の端部に支持条件（支持／自由）を持たせ、片端が自由の小梁（片持ち小梁）を表せるようにする。支持条件は `SecondaryMember` の `end_support: [Supported / Free; 2]`（`nodes` と同じ順、既定は両端 Supported）で表す。両端 Free は不安定として扱う。片持ち小梁が受け持った荷重は基端（支持端）の鉛直反力として主架構へ伝達し、基端に生じる曲げモーメントは伝達しない。基端の曲げを主架構の応力へ反映する必要がある場合は、片持ち梁を実部材（梁要素）としてモデル化する。

片持ち小梁の自由端に他の二次部材が載る場合（先端リブなど）は、その自由端を支持として扱い、荷重を基端へ伝える。幾何的には支持がある端に Free が指定された場合は指定を優先して診断の警告を出し、Supported の端に幾何的な支持がない場合は従来どおり行き先不明のエラーとする。

基端モーメントを節点モーメントとして渡す案（`NodalLoad` の 6 成分で実現できる）もあったが、逐次伝達は鉛直反力のみを扱う枠組み（[ADR 0008](0008-secondary-member-load-cascade.md)）を保つ。利用者向けの計算根拠には、曲げが考慮されないため適切に考慮する必要がある旨を記載する。
