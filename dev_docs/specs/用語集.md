# 用語集

実装に登場する概念とその呼び名を集約する。**新しい概念に名前を付ける前にここを見る**。
既存の用語で表現できるなら、新しい言い換えを作らずそれを使う。

新しく実装した概念には、その都度この用語集へ追記する。「誤用に気づいたら直す」だけでは
気づくまで誤用したままになる。用語集を常に現状の全用語を映した状態に保つことで、次に
同じ概念へ名前を付けようとしたときに既存の用語が見つかり、重複や混同を防げる。

## 床

| 用語 | 意味 |
|---|---|
| 床領域／区画 | 大梁が囲む 1 スパンの区画そのもの。名前・境界・所属小梁・所属床板一覧・手入力小梁ラインを持つ。`FloorRegion` |
| 床板 | 区画内の版。大梁または小梁で囲まれる、または主架構に取り付く。断面・仕上荷重・室用途・分配方法を持つ。`Slab` |
| 取り付く床板 | 片持ち・バルコニー・出隅。主架構に囲まれず、取付き線または点と張り出し量で決まる。`SlabShape::Attached` |
| 取付き先 | 取り付き領域（床・壁とも）が取り付く相手。線（節点対＋区間）／点（節点）／床領域（節点対＋所属先の床領域 ID）の 3 つを取る。床板（`Slab`）は線・点のみを使う（床領域アンカーは床板では常に不正）。壁の取り付き領域（`WallPlate` の `Attached` 形）は自立壁で床領域アンカーを使う。床領域アンカーの節点対は壁自体の長さ（自重の算定）に使い、荷重は節点ではなく所属先の床領域へ渡して等価な面荷重へならす（D17: 壁が床領域内のどこにあるかという位置情報だけを捨てる。長さは捨てない）。`RegionAnchor` |
| 版 | 床板の仕様（断面・仕上荷重・室用途・分配方法・一方向）そのもの。`SlabPlate` |
| 二次部材 | 小梁・間柱。解析要素ではなく、床荷重・自重は主架構への集中荷重（CMQ）として伝わる。`SecondaryMember` |
| 交差小梁の格子解析 | 手入力の小梁ライン（`FloorRegion.joists`）による二方向の床格子サブモデル。`JoistLine`、`squid_n_job::floor_grillage` |
| 負担幅（トリビュタリ幅） | 小梁 1 本が受け持つ面荷重の幅（`spacing`）。実荷重は `w × spacing` の等分布荷重として小梁の支持点へ伝わる。二次部材の小梁検定では、境界に載る小梁は床板境界の幾何（`squid_n_load::secondary::joist_edge_tributary_width`）、床板内部を通る小梁は平行小梁の間隔から求める |

## 壁

| 用語 | 意味 |
|---|---|
| 壁領域 | 柱・梁が囲む鉛直構面内の閉領域そのもの（D1）。版の仕様は持たない（壁版〔`WallPlate`〕が持つ）。`id`・`name`・`boundary`・`wall_plate_ids`・`post_ids` を持つ（床領域 `FloorRegion` と同型）。主架構から再構成される派生的な入力の持ち主（D10）で、利用者は表示名（`SetWallRegionName`）と間柱コマンド（`SetWallRegionPostIds`）を持つが、間柱所属は準備計算の D7 で入れ直される。`region_gen::wall` の境界から組み立てる `wall_region_rebuild` は結線済み。壁版の ST-Bridge 取り込み・要素生成・参照張り替えは未結線。利用者による領域の追加削除はできない。`squid_n_core::model::WallRegion` |
| 構面 | 柱・梁のうち、XY 平面上の同一直線の真上（`MEMBER_AXIS_TOL_MM` の許容差以内）に乗るものの集合。壁領域の境界検出は構面ごとに面走査を行う（床の「同じレベル」に相当する絞り込み単位）。通り芯（`AxisGroup`。表示専用）には依存しない新規の幾何判定。`squid_n_core::region_gen::wall` |
| 壁領域の境界 | 構面内で柱・梁が囲む閉領域そのもの（面走査の結果）。`WallRegion` 本体（版・二次部材を持つ利用者向けの型）とは別で、`wall_region_rebuild` がこれを入力に `WallRegion` を組み立てる。面積はニューエルの公式による 3 次元面積（理想平面への投影を経由しない）。`squid_n_core::region_gen::wall::WallRegionBoundary` |
| 壁版 | 版の仕様（断面・開口）を持つ実体。1 つの壁領域は間柱で分割されていれば複数の壁版を持ちうる（E5。床側の `Slab` と同じ関係）。パラペット・腰壁・垂れ壁・自立壁はどの壁領域からも参照されない独立した壁版として存在する（`OutOfFrameMiscWall` の後継）。自重は必ず断面（厚さ・主材料）参照から求め、`OutOfFrameMiscWall` が持っていた直接入力（面重量・厚さ）の経路は持たない。柱・梁が囲む壁版（`Enclosed` 形）は `wall_region_rebuild` が所属先の `WallRegion` へ自動で割り当てる。利用者による壁版の追加削除（床板の `AddSlab` 相当）はまだない。`squid_n_core::model::WallPlate`（**未結線**。ST-Bridge 取り込み・要素生成・旧型〔`WallAttr`/`OutOfFrameMiscWall`〕の廃止は未着手） |
| 壁エレメント | 耐震壁の要素モデル（RC規準の耐震壁）。壁柱を上下の剛梁で挟む 4 節点 24 自由度要素。`ElementKind::Wall`、実装は `squid_n_element::wall::wall_element::WallElement` |
| フレーム内雑壁 | 腰壁・垂壁・袖壁。壁エレメントとしてではなく、周辺の柱・梁の断面性能へ合成する（独立した解析要素ではない）。`squid_n_element::wall::misc_wall::InFrameMiscWallGeometry`（`pub(crate)`） |
| フレーム外雑壁 | 部材としてモデル化しない壁。始点・終点の絶対座標に高さ・面重量を持ち、0.5m 分割規則で近傍の節点へ重量を集計する（フレーム内雑壁とは異なり、周辺部材への剛性合成はしない）。`squid_n_core::model::OutOfFrameMiscWall`（公開型）。Step 7+8 で節点参照（線／点／床領域のアンカー）へ作り替え予定 |
| 側柱 | 耐震壁の左右の鉛直辺。面内両端ピン化して壁エレメントとのせん断二重計上を避ける。`side_column` |

「雑壁」は構造計算上、フレーム内雑壁・フレーム外雑壁のどちらも指しうる語である。**「雑壁を直して」
のように型名を伴わずに話すときは、上表の 2 行のどちらを指すか（既存の壁エレメントが降格した
ものか、最初からモデル化しない壁か）を先に確認すること。** 2026-08-26 以前は両者の Rust 型名が
`MiscWall` で衝突していたため（`squid_n_element` 側を `InFrameMiscWallGeometry` へ、
`squid_n_core` 側を `OutOfFrameMiscWall` へ改名して解消）、このすれ違いはコード上でも
起こりやすかった。

## 柱梁接合部

| 用語 | 意味 |
|---|---|
| 仕口パネル | 柱梁接合部。S造（CFTを除く）にせん断変形角の自由度を持つ要素として設ける。`ElementKind::PanelZone` |
| 剛域 | 部材端の剛体アーム長。柱・梁のフェース距離（取り付く壁の張り出しを含む）から算定する。`RigidZone` |

## 禁止語

| 用語 | 意味 |
|---|---|
| パネル | **禁止**。建築構造では柱梁接合部（仕口パネル）を指す確立した語のため、床の区画・床板・構面の意味では使わない。UI のドックパネル等、画面部品の意味でのみ許可する |
