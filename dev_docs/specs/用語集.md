# 用語集

誤用・混同が実際に起きた語を集約する。命名（型・関数・UI 文言・コメント）に迷ったら確認する。

| 用語 | 意味 |
|---|---|
| パネル | **禁止語**。建築構造では柱梁接合部（仕口パネル）を指す確立した語のため、床の区画・床板・構面の意味では使わない。UI のドックパネル等、画面部品の意味でのみ許可する |
| 仕口パネル | 柱梁接合部。`PanelZone`（`crates/squid-n-element` の `springs/panel.rs`・`panel_gen.rs`）が実装するせん断パネル要素 |
| 床の区画／床領域 | 大梁で囲まれた 1 スパン。`FloorRegion` |
| 床板 | 区画内の版（大梁または小梁で囲まれる、または取り付く）。`Slab` |
| 構面 | ブレース等が入る架構の面。「パネル」の代わりに使う。対応する型はなく、概念のみ |
| 壁エレメント | 耐震壁の要素モデル（RC規準の耐震壁）。`ElementKind::Wall`。実装は `squid_n_element::wall::wall_element::WallElement`。旧称「壁パネル」（`WallPanelElement` 等）は誤用のため改名済み |
