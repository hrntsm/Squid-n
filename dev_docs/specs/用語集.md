# 用語集

実装に登場する概念とその呼び名を集約する。**新しい概念に名前を付ける前にここを見る**。
既存の用語で表現できるなら、新しい言い換えを作らずそれを使う。

新しく実装した概念には、その都度この用語集へ追記する。「誤用に気づいたら直す」だけでは
気づくまで誤用したままになる。用語集を常に現状の全用語を映した状態に保つことで、次に
同じ概念へ名前を付けようとしたときに既存の用語が見つかり、重複や混同を防げる。

## 床

| 用語 | 意味 |
|---|---|
| 床領域 | 大梁が囲む 1 スパンの閉領域そのもの。名前・境界・所属小梁・所属床板一覧を持つ。**「区画」は別名ではない**（禁止語の節を参照）。`FloorRegion` |
| 床板 | 床領域内の版。大梁または小梁で囲まれる、または主架構に取り付く。断面・仕上荷重・室用途・分配方法を持つ。GUI はモデルタブ「床板」（`tables/slabs.rs`）。MCP は `squid-n-mcp` の `model_edit`（§5.36）で編集可能。`Slab` |
| 取り付く床板 | 片持ち・バルコニー・出隅。主架構に囲まれず、取付き線または点と張り出し量で決まる。`SlabShape::Attached` |
| 取付き先 | 取り付き領域（床・壁とも）が取り付く相手。線（節点対＋区間）／点（節点）／床領域（節点対のみ）の 3 つを取る。床板（`Slab`）は線・点のみを使う（床領域アンカーは床板では常に不正）。壁の取り付き領域（`WallPlate` の `Attached` 形）は自立壁で床領域アンカーを使う。床領域アンカーの節点対は壁自体の長さ（自重の算定）に使い、荷重は節点ではなく壁が載っている床領域へ渡して等価な面荷重へならす（D17: 壁が床領域内のどこにあるかという位置情報だけを捨てる。長さは捨てない。またぎは ∫|立ち上がり高さ| の比（符号反転は高さ 0 で折る）。**荷重を渡す床領域は保存しない**（`FloorRegionId` は床領域の作り直しのたびに面走査順で振り直されるため、保存すると別の床領域を指しうる）。`Model::self_standing_wall_coverage` が壁の位置から都度解決する。内包は辺上 1 mm 以内を内側とみなさない。未覆いが全重量の 0.1% を超えると解析前チェックがエラーにする。`RegionAnchor` |
| 伝達規則 | 取付き先が「線」の取り付き領域（床板・取り付く壁版）が、自らの荷重（面荷重・自重）を主架構のどちらへ渡すかの2択（D16。取付き先が「点」「床領域」は渡し方が一意なので選べない）。`Anchor`（**分布**、既定）は取付き線の区間 `span`（全長なら `[0, 1]`）へ分布荷重として載せ、梁の曲げを生じさせる（片持ちスラブ・梁に載るパラペットの実際の伝わり方。部分区間を梁全長へ薄めない。取り付く壁版で張り出し高さが両端等しいときは等分布、台形のときは高さに比例する線形変化）。`Columns`（**集中**）は梁の曲げを無視し、荷重合力を取付き線上の作用点（矩形は区間中点 `t_mid`、取り付く壁版の台形は面積重心）による単純梁反力按分で両端の柱2本へ集中荷重として渡す（出隅・雑壁の柱伝達と同じ操作）。`squid_n_core::model::LoadTransfer` |
| 線形変化分布 | 材軸に沿って荷重強度が始端 `w_i` から終端 `w_j` へ線形に変わる分布。取り付く壁版の台形（張り出し高さが両端で異なる）の自重に使う。両端で高さが符号反転するときは高さ 0 で 2 本に分割する。床の 45° 分配が出す対称台形（両端立上り＋中央等高。`LoadShape::Trapezoid`）とは別物。`LoadShape::Linear` |
| 版 | 床板の仕様（断面・仕上荷重・室用途・分配方法・一方向）そのもの。`SlabPlate` |
| 二次部材 | 小梁・間柱。解析要素ではなく、床荷重・自重は主架構への集中荷重（CMQ）として伝わる（二次部材の反力の逐次伝達）。実体は床領域の `secondary_joists`、壁領域の `posts`、または未割当リスト。走査は `Model::joists()` / `Model::posts()`。グローバル ID はない。**小梁を表す型は 1 つだけである**（手入力小梁ライン `JoistLine` は廃止した）。`SecondaryMember` |
| 二次部材の反力の逐次伝達 | 二次部材（小梁・間柱）が受け持った荷重を単純梁の両端反力に変えて支持相手へ渡し、**支持相手が別の二次部材のときはその集中荷重として渡して、主架構へ行き着くまで同じ操作を繰り返す**仕組み。交点は常にピン受け・架けとする（剛接十字は扱わない。一律ピン扱いは架け側のモーメント・たわみを過大に見る安全側）。両端ピンなら各段が静定になるため、逐次伝達は近似ではなく厳密解である。受け側・架け側は幾何で決まる（端点が相手の内法に載るほうが架け側）。鉛直荷重に対する鉛直反力は支点まわりのモーメントのつり合いで決まり、てこの腕は水平投影の距離なので、**水平投影が 0 でなければ材軸上の按分（単純梁の反力）と一致する**（傾斜材も同じ）。水平投影が 0 になる部材（鉛直な間柱）だけがつり合いの退化により不静定で、両端 1/2 ずつとする（仮定。§3.4 F8 の残課題）。部材の種別では場合分けしないため、水平な小梁も鉛直な間柱も同じ規則で扱える。荷重同期（`squid-n-job::auto_loads`）と断面検定（分配 Span 検定）はこの経路を共有する（面荷重強度は用途ごとに違うため、荷重の値そのものは一致しない）。`squid_n_load::cascade` |
| 荷重だけを持つ壁版 | 壁エレメントにならない壁版（間柱で分割された壁版・腰壁・垂れ壁・パラペット・自立壁・5節点以上の壁領域内の壁版）。自重は境界の辺へ配り（`squid_n_load::wall_plate_load`）、剛性はフレーム内雑壁として周辺の柱梁の断面性能へ算入する。異常な状態ではないので診断しない（§3.5 G3） |
| 壁版の自重の一方向分配 | 荷重だけを持つ壁版の自重を境界の辺へ配る規則。壁版の自重は版の**面内**（真下向き）に作用し版の曲げが関与しないため、床の45度分配（版に直交する荷重が前提）は使わない。支持部材のある鉛直な辺がちょうど2つあれば半分ずつ、なければ支持部材のある水平な辺のうちもっとも低いものへ全量。支持部材の判定は主架構を優先する。どの辺にも支持部材が無い壁版は解析前チェックのエラー。誤りうる向きは、実際は下の梁で受けている壁を鉛直材受けとみなす場合で、鉛直材は安全側だが**下の梁は曲げを過小に見る（危険側）**。壁エレメントの自重を四隅へ配る既存の扱いと同じ性質で、梁が全量を受ける形は取り付く壁版で表明する。「この間柱がこの壁を受ける」ことは壁版を間柱の位置で分割して表明する（床側で床板の境界辺が小梁の材軸に載ることで表明するのと同じ規約。§3.5 G1・G5）。`squid_n_load::wall_plate_load` |
| 未割当小梁 | どの床領域にも入らなかった小梁。**存在は許さない**（解析前チェックのエラー。所属が決まらないと荷重の行き先も検定の可否も決められないため。§3.5 G8）。型は ST-Bridge 取り込みがリビルド前の中間状態として使う。`Model.unassigned_joists` |
| 未割当間柱 | どの壁領域にも入らなかった間柱。**存在は許さない**（未割当小梁と同じ。§3.5 G8）。`Model.unassigned_posts` |
| 分配 Span 検定 | 二次部材小梁の断面検定。床領域分配の辺荷重（`LoadTarget::Span`）を材軸へ投影して単純梁として重ね合わせ、自重の等分布と**架け側の二次部材から渡された集中荷重**（二次部材の反力の逐次伝達）を足す。結果キーは端点節点対（`JoistCheckTarget::SecondaryJoist`）。断面なし・非鋼・荷重なし、期待床板の欠落、または載荷区間がスパンの半分未満（`JOIST_COVER_MIN_RATIO`＝0.5）は表に「未」。**曲げ・せん断・たわみだけを見て軸力を見ない**ため、適用条件として「床領域の境界節点がすべて同一の剛床に属すること」（`Model::floor_region_on_single_diaphragm`）を課す。間柱（軸力・面外曲げが未対応）と剛床でない床の小梁は対象外で、表には「未」の行として残す（§3.5 G7） |
| 期待床板 | 二次部材小梁の材軸に境界が載り、かつその床板の分配がその辺へ `Span` を出す囲まれ床板。内法で 1 枚でも寄与が無ければ検定しない |

## 壁

| 用語 | 意味 |
|---|---|
| 壁領域 | 柱・梁が囲む鉛直構面内の閉領域そのもの（D1）。版の仕様は持たない（壁版〔`WallPlate`〕が持つ）。`id`・`name`・`boundary`・`wall_plate_ids`・`posts` を持つ（床領域 `FloorRegion` と同型）。主架構から再構成される派生的な入力の持ち主（D10）で、利用者は表示名（`SetWallRegionName`）と間柱コマンド（`SetWallRegionPosts`）を持つが、間柱所属は準備計算の D7 で入れ直される。`region_gen::wall` の境界から組み立てる `wall_region_rebuild` は結線済み。壁版の ST-Bridge 取り込み・要素生成・参照張り替え（自重算定・保有水平耐力・ST-Bridge 出力）も結線済み（§5.14）。利用者による領域の追加削除はできない。`squid_n_core::model::WallRegion` |
| 構面 | 柱・梁のうち、XY 平面上の同一直線の真上（`MEMBER_AXIS_TOL_MM` の許容差以内）に乗るものの集合。壁領域の境界検出は構面ごとに面走査を行う（床の「同じレベル」に相当する絞り込み単位）。通り芯（`AxisGroup`。表示専用）には依存しない新規の幾何判定。`squid_n_core::region_gen::wall` |
| 壁領域の境界 | 構面内で柱・梁が囲む閉領域そのもの（面走査の結果）。`WallRegion` 本体（版・二次部材を持つ利用者向けの型）とは別で、`wall_region_rebuild` がこれを入力に `WallRegion` を組み立てる。面積はニューエルの公式による 3 次元面積（理想平面への投影を経由しない）。`squid_n_core::region_gen::wall::WallRegionBoundary` |
| 壁版 | 版の仕様（断面・開口）を持つ実体。1 つの壁領域は間柱で分割されていれば複数の壁版を持ちうる（E5。床側の `Slab` と同じ関係）。パラペット・構面外の腰壁・垂れ壁・自立壁はどの壁領域からも参照されない独立した壁版として存在する。層の構面内に重心が入る腰壁・垂れ壁は `Enclosed` のまま壁領域へ帰属する。躯体の自重は必ず断面（厚さ・主材料）参照から求め、面重量・厚さを直接入力する経路は持たない。仕上げ・増打ちは `loads`（`Vec<AreaLoad>`。床板の `SlabPlate::loads` と同型）が面荷重として持ち、躯体と同じ正味面積（開口控除後）へ乗じる（§5.48）。増打ちは構造厚に含めないため剛性・耐力・数量のコンクリート体積には入らない。断面が未割当でも `loads` は計上する（断面の有無で入力した重さを落とさない）。柱・梁が囲む壁版（`Enclosed` 形）は `wall_region_rebuild` が所属先の `WallRegion` へ自動で割り当てる。どの壁領域にも収まらず、水平な辺がちょうど 1 つ大梁に全長載り自由端が 1〜2 点の壁版は、`wall_region_rebuild` が取り付く壁版（`Attached`／`Line` アンカー）へ自動変換する（床側 D20 相当。§5.18。自由端は取付き辺上にない頂点。同じ高さでも辺から外れた頂点は数える。§5.22）。取り付く壁版は解析要素にしない。自重の自動分配（取り付く壁版の自重配分）と数量拾いへの算入は行う。**取り付く壁版の立ち上がり高さ `extent` は `Option<[f64; 2]>` で、`None` は「階高いっぱい」を表す**（`Model::wall_plate_extent` が壁の下端から直上の階レベルまでの高さへ解決する。§5.48）。階高は設計中に何度も変わるため、全高の壁を絶対寸法で書くと変更に追随せず上階との隙間が黙って残る。`None` を許すのは自立壁（`FloorRegion` アンカー）だけで、`Model::validate` が線アンカーの `None` を弾く（線アンカーで許すと `attached_geometry` の `other_missing` 経路により階高分の腰壁せいが取付き先の梁 1 本へ丸ごと算入され、剛性を過大に見る危険側になる。全高の壁は `Enclosed` で表す）。直上に階レベルが無い（最上階の床に立つ）壁は高さが決まらず、解析前チェックがエラーで止める。ST-Bridge 取り込みは `RawWall`（`StbWall`）を `WallPlate` として組み立てる（§5.14。旧版は `ElementKind::Wall` を直接生成していた）。利用者による壁版の追加削除は `squid-n-edit` の `AddEnclosedWallPlate`/`AddAttachedWallPlate`/`DeleteWallPlate`/`InsertWallPlate`（床板の `AddSlab`/`AddAttachedSlab`/`DeleteSlab`/`InsertSlab` 相当。§5.18・§5.30）で可能。GUI はモデルタブ「壁版」（`tables/wall_plates.rs`。§5.27・§5.30）が一覧・断面割当・取付き先／立ち上がり高さ・開口／柱際スリット・囲まれた壁版／取り付く壁版の追加削除を担う（取付き先種別の作成後切替は意図的に無し。床板と同様削除＋再作成。§5.30 dig）。MCP 配線は `squid-n-mcp` の `model_edit`（§5.35）で可能。**壁エレメントになるのは壁領域全体を覆う 4 節点で、かつ断面が割り当たった壁版だけである**（`Model::wall_plate_becomes_element`。§3.5 G2・§5.46）。壁版の境界節点集合が所属する壁領域の境界節点集合と一致し節点数がちょうど 4 であること（`Model::wall_plate_covers_region`）に加え、断面があることを要する。生成の可否を問うときは必ず `wall_plate_becomes_element` を使う（`covers_region` だけで判断すると、断面未割当の壁版が要素でも荷重だけの壁版でもない扱いに落ちる）。壁エレメントは下辺2節点・上辺2節点を剛梁で結ぶ4節点24自由度の定式化なので、壁領域の境界が5節点以上（大梁が中間節点で分割されている等）や、間柱で壁版が分割されている場合は前提が崩れる。要素にならない壁版は「荷重だけを持つ壁版」であり正常な状態なので診断しない。`squid_n_core::model::WallPlate` |
| 取り付く壁版の自重配分 | 取り付く壁版（`WallPlate` の `Attached` 形）の自重を、伝達規則（`LoadTransfer`）に沿って地震用重量・長期応力解析のDL・数量拾いへ算入する仕組み。「線」アンカーは取付き線（`LoadTarget::Span`。区間 `span` を梁全長へ薄めず正確に扱う。矩形は等分布、台形は `LoadShape::Linear`）または取付き線両端の柱（`LoadTarget::Node`。台形は面積重心按分）へ、「床領域」アンカー（自立壁）は**壁が載っている床領域**の床板へ等価面荷重（D17）として上乗せする（強度の分母は床の分配と同じ XY 投影面積）。床の取り付く床板と同じ幾何解決パイプライン（`squid-n-job::auto_loads::slab_load_case_content`）へ合流させることで、部分区間の精度を床側と揃える（危険側の近似を避ける。`AGENTS.md`「実装方針」参照）。DL が無く密度から地震用重量を直接算入する経路では、総重量を取付き線両端の節点へ集中させて算入する（`accumulate_attached_wall_seismic_weight`。台形は面積重心）。数量拾いには雑壁のカテゴリ（`MemberCategory::MiscWall`）で算入する。`squid_n_load::wall_attached` |
| 壁展開・壁展開モデル・壁展開インデックス | 壁の解析要素（`ElementKind::Wall`）は入力の正である `Model` には存在しない生成物（D4・D5）であり、`WallRegion`/`WallPlate` から都度組み立てる。**壁展開**はこの組み立て操作、**壁展開モデル**はその結果（生成要素を追加した `Model` の一時的な複製。呼び出し元のモデルへは書き戻さない）、**壁展開インデックス**は壁展開モデル中の生成要素 `ElemId` から由来する `WallPlateId` を逆引きする対応表を指す。壁展開モデルには由来する壁版の開口・柱際スリットを写した `WallAttr` も合成して積む（既存の壁消費者を無改修で動かすための移行期の内部表現。`Model.wall_attrs` そのものの恒久存続を意味しない）。都度計算でキャッシュしない（生成は決定的なため複数回呼んでも同じ `ElemId` になる）。二重展開（壁展開モデルへさらに壁展開を適用すること）は自重・剛性の二重計上を招くため禁止で、`debug_assert!` で検査する。`squid_n_load::wall_expand::expand_wall_elements` |
| 壁エレメント | 耐震壁の要素モデル（RC規準の耐震壁）。壁柱を上下の剛梁で挟む 4 節点 24 自由度要素。`ElementKind::Wall`、実装は `squid_n_element::wall::wall_element::WallElement`。剛域算定・自重・解析・診断の直前に壁展開モデルとしてのみ現れ、`Model.elements` には保存されない。ST-Bridge の書き出しは壁版から行い、壁エレメントは出さない |
| フレーム内雑壁 | 腰壁・垂壁・袖壁。壁エレメントとしてではなく、周辺の柱・梁の断面性能へ合成する（独立した解析要素ではない）。対象はコンクリート系部材のみ。**幾何の情報源は壁版であって壁エレメントではない**（§3.5 G4。要素を幾何の入れ物として使い剛性を 1e-9 倍で潰す構造をやめた）。耐震壁として成立しない壁版すべてが対象で、取り付く壁版も含める（同じ腰壁が入力の形で剛性に効いたり効かなかったりしないため。取付き線が梁の全長を覆う場合に限る）。`squid_n_element::wall::misc_wall::InFrameMiscWallGeometry`（`pub(crate)`） |
| フレーム外雑壁 | 柱・梁に囲まれない壁。取り付く壁版（`WallPlate` の `Attached` 形）が表す。自重は取り付く壁版の自重配分が担い、剛性は自立壁だけが n 倍法で偏心率へ寄与する（下行）。**自由座標入力の専用型（旧 `OutOfFrameMiscWall`）は §5.48 で削除した。** 節点参照のアンカー（線／床領域）を必須とする壁版へ一本化し、`Model.misc_walls`・`MiscWallTransfer`・`AddMiscWall`/`SetMiscWall`/`DeleteMiscWall`・モデルタブ「雑壁」も同時に無くした |
| 雑壁剛性の n 倍法 | 柱・梁に囲まれない壁を等価剛性要素（`Kw' = n·Aw'·ΣKc/ΣAc`）へ換算し、偏心率の剛心・ねじり剛性へ寄与させる方法（RC 規準）。係数 n は `StressAnalysisCfg::misc_wall_n`（既定 `None` ＝考慮しない）。**対象は自立壁だけである**（§5.48）。腰壁・垂れ壁・パラペットはフロア間で壁がつながっておらず層剛性に効かないうえ、周辺の柱梁の断面性能へフレーム内雑壁として既に算入されているため、ここでも数えると二重計上（剛性の過大評価＝偏心率の過小評価）になる。自立壁も**立ち上がりが直上の階レベルに達しているものだけ**を対象とし（床上の腰高パーティションを層剛性に算入しない）、`Aw'` の厚さは断面の板厚（構造厚。増打ちを含まない）から引く。複数層にまたがる自立壁は下端が載る床の直上の層 1 つにだけ寄与する（分割は未対応）。`squid_n_design_jp::secondary::eccentricity::misc_wall` |
| 側柱 | 耐震壁の左右の鉛直辺。面内両端ピン化して壁エレメントとのせん断二重計上を避ける。`side_column` |
| 耐震スリット | 壁版と周辺の柱・梁との縁を切ったことを表す入力（`WallSlit`。`WallPlate::slit`）。**スリットは辺ごとに入れるものなので、4 辺それぞれについて独立に持つ**（`column_face: [bool; 2]` は柱際の左右、`beam_face: [bool; 2]` は 0 が下辺・1 が上辺）。三方スリットは柱際 2 辺＋上下いずれか 1 辺、完全スリットは 4 辺として表す。**三方スリット壁と垂れ壁は別物である**: 垂れ壁は上の梁からぶら下がる短い壁で下端に壁そのものが無く（`Attached`）、下辺にスリットを入れた壁は構面いっぱいの全高の壁で下の梁と接してはいるが縁が切れている。規則は 2 つ。**剛性は切れていない辺の部材にだけ算入し**（柱際が切れていればその柱へ袖壁として算入せず〔`wing_length` が 0 を返す〕、梁際が切れていればその梁へ腰壁・垂れ壁として算入しない〔`strip_height` が 0 を返す〕。反対側の梁際が切れていれば残った梁が全高を負担する）、**自重は切れていない辺へ伝える**（上下とも一体なら四隅へ等分、片側だけ切れていれば反対側の 2 節点へ全量。柱際は自重の行き先を変えない）。剛域の張り出しも同じ規則に従う。**4 辺すべてが躯体と一体でなければ耐震壁として成立しない**（`misc_wall::wall_is_seismic`）。上下の梁際をともに切ると自重の伝達先が無くなるため、解析前チェックがエラーで止める（`WallSlit::both_beam_faces`）。柱際の添字は `WallPlate::column_face_nodes`（境界のうち標高の低い 2 節点を境界の並び順に取ったもの）が唯一の対応規則。境界が 4 節点の囲まれた壁版でのみ意味を持ち、取り付く壁版は参照しない。**旧 `three_side_slit`（真偽値 1 つ）の後継**で、旧フィールドは自重（上辺と一体）と剛性（四周絶縁）で矛盾した挙動を持っていた（§5.46・§5.47）。`WallAttr::slit` は壁展開時に写した同じ値 |
| 荷重のみの壁版 | 解析要素にならず、フレーム内雑壁としての剛性算入もされない壁版。板厚を引けない壁版などが該当し、自重だけが荷重へ流れる。モデル化図の分類 `ModelClass::WallPlateLoadOnly`（凡例「荷重のみ(剛性に算入しない)」）に対応する。剛性算入されるか否かは剛性算入が実際に見ている収集結果（`misc_wall::misc_stiffness_wall_plates`）から引き、図と解析が食い違わないようにする（§5.46） |

「雑壁」は構造計算上、フレーム内雑壁・フレーム外雑壁のどちらも指しうる語である。**「雑壁を直して」
のように型名を伴わずに話すときは、上表のどちらを指すか（周辺の柱梁へ剛性算入する壁か、柱・梁に
囲まれない壁か）を先に確認すること。** 2026-08-26 以前は両者の Rust 型名が `MiscWall` で
衝突していたため（`squid_n_element` 側を `InFrameMiscWallGeometry` へ、`squid_n_core` 側を
`OutOfFrameMiscWall` へ改名して解消）、このすれ違いはコード上でも起こりやすかった。
`OutOfFrameMiscWall` 自体は §5.48 で削除され、フレーム外雑壁は取り付く壁版が表す。

同じ壁が「自重」と「剛性」で別の経路を通る点にも注意する。腰壁・垂れ壁は自重を取り付く壁版の
自重配分が運び、剛性はフレーム内雑壁として周辺の柱梁の断面性能へ入る。自立壁は自重を床領域の
床板へ等価面荷重として渡し、剛性は n 倍法で偏心率へ入る。**どちらか一方の経路だけを見て
「この壁は効いていない」と判断しないこと。**

## 柱梁接合部

| 用語 | 意味 |
|---|---|
| 仕口パネル | 柱梁接合部。S造（CFTを除く）にせん断変形角の自由度を持つ要素として設ける。`ElementKind::PanelZone` |
| 剛域 | 部材端の剛体アーム長。柱・梁のフェース距離（取り付く壁の張り出しを含む）から算定する。`RigidZone` |

## 禁止語

| 用語 | 意味 |
|---|---|
| パネル | **禁止**。建築構造では柱梁接合部（仕口パネル）を指す確立した語のため、床の床領域・床板・構面の意味では使わない。UI のドックパネル等、画面部品の意味でのみ許可する |
| 区画 | **補語なしでの使用を禁止**。何に囲まれた区画かを必ず示すこと（「大梁の区画」＝床領域、「柱・梁の区画」＝壁領域、「通り芯の区画」＝架構ウィザードが床を作る升目）。裸の「区画」はこの 3 つのどれとも読めてしまう。単に床領域・壁領域を指すだけなら、補語を付けるのではなく型名（床領域・壁領域）を使う。囲む部材を説明する必要がある文脈でのみ補語付きで使う |
