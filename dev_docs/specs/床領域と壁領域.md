# 床領域と壁領域

> 床領域（`FloorRegion`）は大梁が囲む 1 スパン床領域ごとに 1 つ。版の仕様は持たない。
> 床板（`Slab`）は大梁または小梁で囲まれた版、または主架構への取り付き（片持ち・バルコニー・
> 出隅）ごとに 1 つ。1 つの床領域は複数の床板を持ちうる（床領域内が小梁でさらに細かい
> 打設単位に分かれている場合）。二次部材の実体は領域が保持する（D6 実装済み）。
> 現在有効な設計判断の正本は [`../adr/`](../adr/) の ADR 0006・0007・0015〜0020。決定と段取りの経緯は
> [`handoff/床領域・壁領域の再設計_申し送り.md`](../handoff/床領域・壁領域の再設計_申し送り.md)
> （§3.1 に、当初 D3 が採った「領域＝版」設計を上記へ修正した経緯を記す）。

本書は **いまの実装** を説明する。壁領域の作り替え・壁版・壁展開・可視化・MCP は
Step 7〜9 まで実装済みである。壁領域が解析要素 ID を直接持つ旧設計は廃止済み。

## 現在の実装状況

| 項目 | 状態 |
|---|---|
| `FloorRegion`（大梁の区画。名前・境界・所属小梁・所属 `Slab` 一覧） | 実装済み |
| `Slab`（囲まれ / 取り付き、版は任意） | 実装済み |
| 面走査 `region_gen`（水平大梁の閉路） | 実装済み（床のみ。壁は `region_gen::wall`） |
| 取り込み・準備計算での入れ直し `rebuild_floor_regions` | 実装済み（Step 3・4） |
| 取り付き床板の編集コマンド・床タブ | 実装済み（Step 2b・4） |
| 小梁の所属（中点の厳密内包＋レベル一致） | 入れ直し時に付与。実体は `FloorRegion.secondary_joists` |
| 間柱の所属 | 入れ直し時に付与。実体は `WallRegion.posts` |
| 荷重分配を床板単位で再分割（小梁で再分割 → 三角形・台形分配） | 実装済み（Step 4。`squid_n_load::floor::distribute_region`） |
| 小梁設計を分配結果から出す | 実装済み（二次部材。Step 5・§5.39・§5.40） |
| 二次部材の反力の逐次伝達（`squid_n_load::cascade`） | 実装済み（Step 5・§5.44）。荷重同期と断面検定が同じ経路を通る |
| 壁領域の作り替え・要素生成 | 実装済み（Step 7+8・§5.14）。可視化・GUI・MCP は Step 9 |

ST-Bridge の `StbSlab` は小片のまま `Slab` として取り込まれる。取り込み・準備計算のたびに
大梁と両端支持の小梁から床板割当領域（`rebuild_floor_assignment_regions`）を再構築し、
`rebuild_floor_regions` が大梁の閉路ごとに `FloorRegion` を作り直し、各 `Slab` を、割り当てられた
割当領域の境界多角形の重心・レベルで所属先の `FloorRegion` へ結び付ける（`FloorRegion.slab_ids`）。
重心が複数の床領域に入る（中庭の入れ子）ときは面積が最小の床領域へ付ける。どの床領域にも入らず、
水平大梁にちょうど 1 辺が全長載り自由端が 1〜2 点の `Slab` は ST-Bridge の取り込みで取り付き床板へ
変換する。それ以外の未所属の `Slab` と所属の付かない小梁は警告し、モデルから落とさない。

## 型の構成（床）

| 型 | フィールド | 内容 |
|---|---|---|
| `FloorRegion.boundary` | `Vec<NodeId>` | 大梁の閉路（反時計回り）。版の仕様は持たない |
| `FloorRegion.slab_ids` | `Vec<SlabId>` | 床領域内の床板一覧。空も可（版なし床領域） |
| `FloorRegion.secondary_joists` | `Vec<SecondaryMember>` | 所属小梁の実体（`Joist` のみ） |
| `Model.unassigned_joists` | `Vec<SecondaryMember>` | どの床領域にも入らなかった小梁（`rebuild_floor_regions` 後） |
| `Model.unassigned_posts` | `Vec<SecondaryMember>` | どの壁領域にも入らなかった間柱（`rebuild_wall_regions` 後） |
| `Slab.shape` | `Enclosed` / `Attached { anchor, extent }` | 囲まれは大梁または小梁で囲まれた領域で、境界は床板自身ではなく床板割当領域が保持する。取り付きは線または点。取り付く版はどの `FloorRegion` からも参照されない |
| `Slab.plate` | `SlabPlate`（必須） | 断面・仕上荷重・室用途・分配方法・一方向。版なしは `section: None` で表す |

壁領域は `WallRegion.posts` に間柱の実体を持つ（D6 実装済み）。解析要素は壁展開の生成物であり、
`WallRegion` は壁エレメント ID を持たない。

壁版の形も床板と同じ構成で、`WallPlate.shape` は `Enclosed`（単位 variant。境界は壁版自身ではなく
壁版割当領域が保持する）と `Attached { anchor, extent }` の 2 値である。

## 二次部材の走査

小梁・間柱の実体は領域内または未割当リストに分散している。走査は `Model::joists()` /
`Model::posts()` を使う（未割当 → 領域内の順）。

割当領域の面走査へ入れる二次部材は、両端が支持された `SecondaryMemberEnds::Supported`
だけとする。片持ち（`Cantilever`）の自由端は閉領域の辺にならず、未解決（`Detached`）は
荷重の伝達経路を持たないため、境界に使わない。

`SecondaryMember` は安定した `id` を持ち、両端は取付き位置の `ends`（`SecondaryMemberEnds`）で
表す。`Model::validate` が ID の一意性・断面参照・端点アンカーを確認する。

## 支持部材の重なりの扱い

同じ境界辺の位置に支持部材が重なる場合の扱いを定める（ADR 0021）。**同じ種類どうし**
（主架構どうし＝大梁・柱、二次部材どうし＝小梁・間柱）が同一材軸上で正の長さにわたって
重なる場合は、どちらが荷重を受けるか一意に決まらないため解析前エラーの対象とする。
**異種**（主架構と二次部材）が重なる場合は主架構を採用し、割当領域の支持部材は主架構と
する。平行に並ぶだけ（材軸が一致しない）の部材は、同じ位置に重なったものではないため重なり検出と主架構優先の対象にしない（別の辺の支持部材や、領域を分割する間柱にはなり得る）。

重なりの検出は面走査へ入れる支持部材だけを対象に、要素順・安定 ID 順に依存しない形で
`Model::same_kind_support_overlaps` が行う。主架構優先は、面走査が同じ向きの辺のうち
先に挿入された辺を採用する性質によるため、面走査へ主架構を常に先に渡す。

## 親領域と支持端の整合

小梁・間柱の配置と端部移動は、支持端が親領域（`SecondaryParent` が指す床領域・壁領域）の
内側または境界上にあることを要求する。内外判定は床領域・壁領域の多角形に対して行い、
境界からの許容差は `MEMBER_AXIS_TOL_MM` = 10 mm とする。外れる場合は
`PlaceSecondaryMember` / `SetSecondaryMemberEnds` が Noop となり、モデルを変更しない。
幾何から親領域を自動決定することはしない。

対象は取付き位置表現が `Supported` の 2 端と `Cantilever` の支持端で、`Detached` は従来どおり
配置・移動を拒否する。`SetSecondaryMemberEnds` は現在の所属領域を親として同じ判定を行う。
支持部材候補の絞り込みは入り口により異なる。2D フォームは `support_candidates()` が材軸の両端が
親領域の内側または境界上にある候補だけへ絞る。3D ビューは `pick_support_anchor()` が親領域で絞らず
に候補を返し、2 端点を選んだ後に両端点の中点が親領域の内側（境界を除く）にあるかを配置可否の判定に
使う。最終的な不変条件は編集コマンドが守る（GUI 任せにしない）。

## 検証の内容

`Model::validate` は、二次部材について次を確認します。

- `FloorRegion.secondary_joists` の各要素が `Joist`、`WallRegion.posts` の各要素が `Post`、
  `unassigned_joists` / `unassigned_posts` もそれぞれ `Joist` / `Post` であること
- 断面参照が実在すること
- 安定 `id` が全二次部材で重複しないこと
- `ends` の取付き位置が 0〜1 の範囲内であること
- 支持先が他の二次部材を指すとき、その安定 `id` が実在し、自分自身を参照しないこと
- 支持先が他の二次部材のとき、支持グラフに循環がないこと
- 割当領域の境界が参照する支持部材が実在し、主架構では `ElementKind::Beam`、二次部材では
  床＝小梁・壁＝間柱であり、材軸を解決でき、主架構では材端節点が 2 つであること。
  荷重の伝達経路を持たない `Detached` の二次部材は支持部材にしない

## 壁版と鉛直二次部材の自重支持契約

| 入力 | 対象・順序 | 有効値・未指定時 |
|---|---|---|
| `WallPlate.self_weight_shares: Vec<f64>` | 解析要素にならない囲まれた壁版。壁版割当領域が返す境界の辺順（最後の辺から最初の辺へ戻る） | 割当領域境界の辺数と同じ長さ、各値が有限・非負、総和1（許容差1e-9）。既定の空配列は未指定 |
| `SecondaryMember.gravity_end_shares: Option<[f64; 2]>` | 水平投影が10 mm以下の二次部材。`ends`（`SecondaryMemberEnds`）の端の順 | 各値が有限・非負、総和1（許容差1e-9）。既定の `None` は未指定。`EndSupport::Free` の端は0に限る |

自重を持つ対象壁版、または逐次伝達の対象となる鉛直二次部材の未指定・不正値は解析前エラーとする。囲まれた壁版の境界は壁版自身ではなく壁版割当領域が保持するため、負担率の長さは割当領域境界の辺数と一致することを要する（ADR 0020）。壁版では正の負担率を持つ辺がスリットで切れている場合もエラーとする。各辺の支持部材と材軸区間は割当領域の境界を正本としてそのまま使い（異種の重なりは主架構優先。同種の重なりはエラー。ADR 0021）、節点座標からの支持先再推定はしない。材軸照合の許容差は10 mm。支持できない荷重を他の辺・端へ振り替えない。負担率0の辺・端には荷重伝達先を要求しない。

境界辺の負担率は柱際（鉛直辺）へも指定でき、柱・間柱が受ける。上下の梁際をともに切った境界が 4 節点の囲まれた壁版は、その納まりを実際に想定しないため、負担率の指定内容や柱際の状態によらず解析前エラーとする（切れていない辺へ振り替えない）。境界が 4 節点でない壁版はスリット自体を扱わないため対象外とし、指定が残っていれば警告する。境界が 4 節点でも、境界頂点にモデル節点が無い等で辺を柱際・梁際へ対応付けられず指定が反映されない場合も警告する（ADR 0022）。

この契約の責務分担は次のとおり。荷重モジュール（`squid_n_load::wall_plate_load`）は明示された負担率に従って割当領域の境界どおり辺へ配分し、負担率の不備・割当領域境界の欠落・指定辺のスリット縁切りを判定する。上下の梁際をともに切った 4 節点の囲まれた壁版という納まりの可否は荷重モジュールでは判定せず、解析前チェック（`squid_n_solver::statics::analysis::precheck`）が入力方針として別途エラーにする。集計段階ではその壁版の自重が算定され得るが、解析前チェックで必ず止まるため解析には使われない。

間柱自重・壁からの自重・他の二次部材からの重力荷重に同じ端部負担率を適用する。水平投影が10 mmを超える部材は端部支持条件から反力を求め、この負担率を使用しない。DL経由と密度直接集計の地震用重量は、同じ支持先・端部負担率を用いて主架構へ伝達する。

編集コマンド `SetPostGravityEndShares` は安定 ID で対象を探し、指定した負担率を `ends` の端の順として受け取る。SCZは両入力を保持し、スキーマ番号は1とする。取り付く壁版は取付き先の伝達規則、壁エレメントは要素自重の配分を用いる。

契約の実装は `squid_n_core::model::{WallPlate::has_valid_self_weight_shares, SecondaryMember::valid_gravity_end_shares}`、荷重伝達は `squid_n_load::{wall_plate_load, cascade}`。判断理由は[ADR 0018](../adr/0018-explicit-gravity-supports.md)、利用者向け計算根拠は[自重の長期応力解析への接続](../../docs/calc_basis/01_荷重/06_自重の長期応力解析への接続.md)を参照。

## 既定値

- `FloorRegion.secondary_joists`: 空（`#[serde(default)]`）
- `Model.unassigned_joists` / `Model.unassigned_posts`: 空（`#[serde(default)]`）
- `Model.wall_regions`: 空（`#[serde(default)]`）
- レベル一致: `LEVEL_TOL_MM` = 1 mm
- 辺上を内部に含めない: `BOUNDARY_TOL_MM` = 1 mm
- 辺の全長被覆・材軸近さ: `MEMBER_AXIS_TOL_MM` = 10 mm
- 重心照合の面積相対差: `CENTROID_MATCH_AREA_REL` = 1e-3
- 片持ち変換後の取付き線: `span = [0, 1]`、`LoadTransfer::Anchor`（左が正）
- 二次部材小梁の曲げ・せん断サンプル分割: 64
- 二次部材小梁のたわみサンプル分割: 80
- 二次部材小梁の載荷カバー下限: 0.5（材軸長に対する載荷区間。期待床板の欠落とは別に見る）
- 逐次伝達で鉛直材とみなす水平投影の上限: `MEMBER_AXIS_TOL_MM` = 10 mm（`gravity_end_shares` による明示配分）

`SecondaryMember` の `id` は全二次部材で一意な安定 ID です。未リリースのため旧スキーマ（横断リスト +
`SecondaryMemberId`）との互換は取らず、読めない古いファイルは読込時にエラーとします。
