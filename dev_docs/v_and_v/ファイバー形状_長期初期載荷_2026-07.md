# ファイバー断面の形状対応と長期荷重初期載荷（2026-07）

**日付:** 2026-07-27
**発端:** ユーザー報告（ヒンジ詳細画面のスクリーンショット 4 件）。うちソルバ側 2 件を本記録に記す。
GUI 側（M-θ グラフの初期フィット・ファイバーマップの材料別色分け・N-M 相関図の 3D 化）は
同時に `squid-n-app` 側で対応した。

## 1. 【重大】ファイバー断面が形状によらず中実矩形格子だった

- **ファイル:** `crates/squid-n-element/src/frame/fiber/mod.rs`（`build_gauss_fibers`）、
  `crates/squid-n-section/src/mn_surface/fibers.rs`・`types.rs`。
- **不具合:** ファイバー断面は `SectionShape` によらず `rect_fiber_section(width, depth, 12, 20)`
  の**中実矩形格子**で生成されていた（RC の主筋分離のみ形状対応）。角形鋼管
  □-400×400×12 では断面積を約 8.6 倍（160,000 / 18,624 mm²）に過大評価し、
  曲げ剛性・全塑性耐力も同様に過大となる。**鋼管・H 形柱を含む建物の保有水平耐力を
  大幅に過大評価する危険側の欠陥**。RC 円形も d×d 矩形で 4/π ≒ 1.27 倍の過大。
  ユーザーは塑性化マップで「角型鋼管なのに中まで詰まった断面」として発見した。
- **修正:** MN 相関曲面用の形状別配置 `mn_surface::plastic_fibers` を
  (1) 材料領域区分 `FiberRegion`（Concrete/Rebar/Steel）を各ファイバに付与、
  (2) 目標ファイバ寸法と円環解像度を引数化した `plastic_fibers_at` に分離し、
  要素側 `build_gauss_fibers` がこれを共用する形に再構成した。
  要素側の解像度は最大寸法/16・円環周 24 分割（従来の 12×20 格子と同程度のファイバ数、
  MN 曲面の細分割 /40・周 48 より粗く増分解析の計算量を維持）。
  形状なし（壁エレメントの壁柱等）は従来どおり中実格子。
  旧 `add_rebar_fibers_rect/circle`（mn_surface と重複実装）は撤去。
- **材料区分タグ:** `Fiber::material`・`FiberStateSample::material` を
  0=コンクリート、1=主筋、2=鋼材と定義（塑性化マップの色分け用。
  旧結果ファイルは 0=母材格子・1=主筋のため、鋼断面の旧結果は 0 のまま表示され得る）。
- **検証:** `test_steel_box_fibers_are_hollow`（□-400×400×12 の ΣA が厳密一致・
  I が 2% 以内・管内側にファイバがない・全て区分 2）、
  `test_rc_circle_fibers_match_circle_area`（円面積が厳密一致・主筋 8 本が区分 1）。
  既存の element 203 件・solver 全件パス（単柱テスト等は形状なし断面のため影響なし）。

## 2. 長期荷重の初期載荷がなく、N-M 応答経路が N=0 から始まっていた

- **ファイル:** `crates/squid-n-solver/src/nonlinear/pushover/driver.rs`。
- **問題:** 増分解析は要素状態ゼロから水平力 λ·q のみを漸増しており、長期荷重
  （固定・積載）による初期応力（柱軸力・梁端モーメント）が反映されていなかった。
  ヒンジ詳細図の N-M 応答経路が N≒0 の一直線となったユーザー指摘で顕在化。
  軸力依存の耐力（柱 My・荒川式 Qy の軸力項・ファイバー N-M 相関）を誤る。
- **修正:** `pushover_analysis_recording` に `apply_long_term: bool` を追加（既定・
  推奨は有効。旧 API ラッパー `pushover_analysis` も有効で委譲）。有効時は
  `LoadCaseKind::is_long_term` の荷重ケースを `assemble_global_f`（節点＋部材荷重）で
  合算した f0 を 5 分割の Newton で先行載荷し、以降の全フェーズで外力を
  f_ext = f0 + λ·q として保持する（変位制御の λ 決定・弧長法の f_int も整合）。
  載荷完了状態は load_factor=0.0 の 1 ステップとして記録し、性能曲線・部材応答履歴
  （N-M 応答経路）の始点になる。収束しない場合はエラーで停止（無音の省略はしない）。
- **UI:** 解析タブに「長期荷重を初期載荷」チェックボックス（既定 ON）。
  段階的耐力喪失解析・MCP ジョブは常に有効。
- **検証:** `test_pushover_long_term_preload_sets_initial_axial_state`
  （最初の記録が λ=0・水平ベースシア ≒0・終局時柱軸力に長期軸力 P を保持・
  無効時は従来どおり）。既存テストは全件パス（長期ケースがないモデルでは no-op）。

## 3. 申し送り

- 長期応力解析の実務条件（長期軸力無効化 `stress_cfg` など、`statics/linear` の
  `apply_long_axial_cut`）は初期載荷には未適用。適用要否は要検討。
- SRC 内蔵鉄骨・CFT 鋼管の降伏強度は部材材料の fy（未設定時は鋼 235／主筋 345 の既定）
  を用いる。鋼種グレード名からの解決（`material_grade`）への接続は今後の課題。
- 旧結果ファイルの `FiberStateSample::material` は旧区分のまま表示される（再解析で解消）。
