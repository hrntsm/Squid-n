# 床領域を大梁パネルへ統合する（2026-08）

**対象**: ST-Bridge 取り込みと準備計算における床領域の作り直し（`rebuild_floor_regions`）
**区分**: データモデルの是正と、その影響の記録
**判定**: 🔶（パネル統合と小梁所属の一意化は実施済み。荷重分配の小梁再分割は Step 4、小梁設計を分配結果から出すのは Step 5）

---

## 対象

申し送り Step 3。入力の正は「大梁が囲む閉領域ごとに 1 つの床領域」である。
ST-Bridge の `StbSlab` は小梁で細分された小片として入ってくるため、取り込み直後と
準備計算の荷重同期前に、主架構の面走査結果へ版と小梁を入れ直す。

関数は `squid_n_core::region_rebuild::rebuild_floor_regions`。GUI の明示操作は持たない。

## 入力モデル

`crates/squid-n-app/tests/fixtures/model.stb`（4 層＋PH の S 造。取り込み後は
節点 166・解析要素 115・二次部材 56・床領域 26）。

## 構成の実測

| 項目 | 統合前（小片のまま） | 統合後 |
|---|---|---|
| 囲まれ領域 | 82 | **26**（レベル別 6 / 6 / 6 / 7 / 1） |
| 取り付き領域 | 0 | 0 |
| 版の断面・室用途が混在するパネル | — | **0** |
| 小梁の所属（中点の厳密内包＋レベル一致） | 一意にならない | **56 本すべて 1 領域** |
| 所属なし小梁 | — | 0 |
| 節点（取り込み直後） | 166 | **166**（このフィクスチャでは先端節点の削除 0） |

中庭は版なしの囲まれ領域として残す方針だが、本フィクスチャに中庭はない。
入れ子の所属は単体テストで確認する。重心が複数パネルに入るときは面積が最小のパネルへ付ける。
同面積なら検出順が先のパネルである。

診断（`unassigned_joist_count` / `floating_plate_count`）はモデルを書き換えず、
いまの床領域で件数を数える。準備計算は剛域より前に毎回 `rebuild_floor_regions` を呼ぶ。

## 代表スカラ（`snapshot_key_scalars`）

荷重分配は領域境界の三角形・台形分配のままである（小梁で再分割する経路は Step 4）。
小片をパネルへ畳むと境界が大梁だけになるため、辺荷重の行き先が変わり、応力・周期・検定が動く。

統合後の金（`crates/squid-n-app/tests/snapshots/full_model__snapshot_key_scalars.snap`）:

| 項目 | 値 |
|---|---|
| `model.floor_regions` | 26 |
| `prep.total_seismic_weight` | 3.187e6 |
| `prep.seismic.T` | 4.890e-1 |
| `eigen.T[0]` | 4.851e-1 |
| `static.DL.min_uz` [mm] | −9.289e-1 |
| `static.DL.sum_base_axial` | −3.135e6 |
| `design.slab_checks` | 25 |
| `design.joist_checks` | 56 |
| `design.joist_max_ratio` | 4.508e-1 |
| `design.max_ratio` | 6.133e-1 |

直前の記録（小梁帰属のレベル一致＋負担幅平均、`joist_max_ratio = 0.3097`、
辺荷重の幾何割付後の `static.DL.min_uz = −0.8642`）から、小梁最大検定比と DL 最小鉛直変位が動いている。
地震用重量の合計は版面積が保存される前提と整合する値として上記を固定した。

スナップショットは準備計算後（仕口パネル生成を含む）のモデルでも取るため、
`model.nodes` / `model.elements` は取り込み直後の 166 / 115 より多い。

## 残す限界

- 分配はまだ小梁の曲げを経由しない。パネル境界の大梁へ直接載る
- 小梁検定は領域形状から負担幅を再導出する（Step 5 まで残る）
- 出隅の自動 Point 変換、L 形の自動分割、取付き線の部分区間は未（部分区間は `validate` が弾く）
- 片持ち変換は被覆辺ちょうど 1・自由端 1〜2 点に限る
- D10 の照合キーは重心＋レベルのみ。面積相対差 \\( 10^{-3} \\) 未満を inherited と数える。通り芯移動での一斉不一致は残課題
