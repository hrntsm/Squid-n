# 未入力の材料強度に対する危険側フォールバックの是正（2026-07）

**監査日:** 2026-07-28
**対象:** 非線形解析（保有水平耐力計算＝プッシュオーバー、非線形時刻歴応答解析）に
おける、**入力不足時のフォールバック**。
**契機:** 利用者ドキュメント（5.7 増分解析）に「\( Q_u \) を算定できない壁
（コンクリート強度が未設定など）は線形弾性として扱います」と明記されていたこと。
弾性のまま解析することは**危険側**であり、仕様として容認してはならない。

---

## 1. 問題の構造

非線形解析は、部材の終局耐力で応力を頭打ちにすることで崩壊機構を形成する。
耐力を算定できない部材は「弾性のまま／降伏しないまま」扱われ、押し込むほど
際限なく応力を負担する。結果として崩壊機構が形成されず、保有水平耐力を
**過大評価**する（＝危険側）。

すなわち「入力不足 → 既定値・弾性へ無音フォールバック」は、単なる利便性では
なく**安全性に直結する欠陥**である。入力不足は代替値で埋めず、解析を停止して
利用者へ是正内容を示すのが正しい扱いとなる。

## 2. 是正前に存在した危険側フォールバック

## 3. 是正内容

### 3.1 解析前の入力チェックを新設し、両方の非線形解析から呼ぶ

`squid_n_element::factory::{nonlinear_input_issues, ensure_nonlinear_input}`
（`factory/input_check.rs`）を新設した。要素種別ごとに次を判定する。

- 耐震壁（`Wall`）: `WallPanelElement::wall_shear_capacity_issue`
- 線材（`Beam` / `Fiber` / `MultiSpring`）:
  - 材料が割り当てられていない
  - コンクリート系断面（`SectionShape::is_concrete_like`＝RC/SRC/CFT）で Fc 未設定または Fc ≤ 0
  - 上記以外の断面で fy も Fc も未設定
- 弾性としてモデル化することが仕様の要素（`Shell` / `PanelZone` / `NodalSpring`）と、
  特性を専用属性で持つ要素（`Isolator` / `Damper` / `Brace`）は対象外

呼び出し箇所は `pushover/driver.rs`（従来のインライン実装を置換）と
`dynamic/timehistory/nonlinear.rs`（新規、2.3 の是正）。エラーは是正内容を示す
日本語文を先頭 5 件まで列挙し、残りは件数で示す。

### 3.2 耐震壁の不備判定を網羅的にした

`wall_shear_capacity_issue` に、断面未設定・壁厚 ≤ 0・材料未設定・Fc ≤ 0・
壁エレメント構築不可（4 節点未満／退化）の各診断を追加した。さらに末尾へ
**総括判定**を置き、耐震壁として成立する壁で `shear_capacity_of` が 0 以下なら、
個別診断に当てはまらなくても不備として扱う。個別診断の追加漏れが無音の
弾性化に戻らないための不変条件（2.2 の再発防止）。

### 3.3 残るフォールバックには到達不能である旨を明記

2.4〜2.6 の各フォールバックは、3.1 のチェックにより非線形解析では到達しない。
削除はせず（線形解析・単体テストからの呼び出しがあるため）、到達しない根拠を
コメントで明記した。

## 5. 追補（2026-07-28。当初の残課題 5.1・5.3 を解消）

初版で「残課題」としていた 2 点は、指摘を受けて本編で解消した。

### 5.1 【解消】RC 主筋の σy 既定値 345 N/mm² → 断面（配筋）の材質として入力

主筋強度の入力経路がないことが据え置きの理由だったため、**入力経路そのものを
追加**した。

- `RcRebar` に `main_grade: Option<String>`（主筋の材質）を追加。せん断補強筋の
  材質は既存の `ShearBar::grade`。いずれも**断面（配筋）の属性**とする
  （部材材料はコンクリート `Fc` を表すため、鉄筋強度の置き場が他にない）。
  X/Y 主筋で材質を変える実務上の必要がないため、断面あたり 1 つとした。
- 断面編集 UI に「主筋 材質」「せん断補強筋 材質」のコンボボックス（直接入力可）と、
  呼び名サイズ（D10〜D41）の選択を追加した。
- 強度解決は `squid_n_core::material_grade::{rebar_grade_f_value,
  rebar_yield_strength, shear_rebar_yield_strength}` に集約した。異形鉄筋・丸鋼は
  接頭辞規則（`SD345`→345）、高強度認定品は名称末尾の数値（`KH785`→785、
  `SBPD1275`→1275）で解決する。
- 反映先: `pushover/hinge.rs`（My）、`pushover/shear_yield.rs`（σy・σwy）、
  `factory/springs.rs`（材端ばね My）、`frame/fiber/mod.rs`（主筋ファイバー）、
  `squid-n-app` の RC ランク算定、検定側（`rc/beam.rs`・`rc/column`・`srrc/*`・
  `rc/horizontal_joint.rs`）。検定側は**断面の材質 → 部材材料名**の順で解決し、
  材質未設定なら従来挙動（材料名を鉄筋グレード名とみなす）のまま。
- ST-Bridge は `strength_main` 属性として往復する。
- 主筋の材質も材料の `fy` もない RC 部材は、非線形解析を入力不備として停止する。

**副次的に見つかった危険側の不具合**: `ShearBar::grade` は従来「Some＝高強度品」の
前提で使われており（`high_strength_w_ft` を無条件に適用）、UI から普通強度
（`SD295A` 等）を指定できるようにすると w_ft が 590 N/mm² と評価され**危険側**に
なる。`is_high_strength_shear_grade`（`SD*`/`SR*` は普通強度）を追加し、普通強度は
令90条の表（`rebar_allowable_shear`）で評価するよう分岐を修正した。

### 5.2 鋼材 σy 既定値 235 N/mm²（断面形状未設定の部材）— 残課題

`hinge.rs` の複合断面・形状不明の分岐は `mat.fy.unwrap_or(235.0)` を用いる。
3.1 のチェックにより「fy も Fc もない」ケースは停止するが、「Fc のみ設定された
形状未設定の部材」では 235 が使われる。形状未設定断面（カタログ数値直入力）に
鋼種を持たせる入力経路の設計が前提。

### 5.3 【解消】有効せん断断面積 As = 0 → 入力エラー

初版では「せん断変形を考慮しないモデル化の意思表示とも解釈できる」として据え置いた
が、**せん断変形の無視は部材（梁）のモデル化として指定すべきことであり、断面の
As を 0 とする形で表現してはならない**（`build_dir_threshold` が Qy=+∞ となり、
入力不足が「せん断について無限に強い部材」として通ってしまう）。

線材（`Beam`/`Fiber`/`MultiSpring`）が参照する断面の `as_y`・`as_z` が 0 以下の
場合は、解析前チェック（`statics::analysis::precheck::precheck_model`）で
**全解析共通の入力エラー**とした。せん断変形を無視したい場合は十分大きな As を
与える（既存の `test_bernoulli_strict_1e9` が as=1e12 で行っている扱い）。

### 5.4 耐震壁の壁筋（縦筋 σy・横筋 σwh）— 残課題

`SectionShape::RcWall` は壁厚と壁筋比 ps のみを持ち、壁筋の材質を持たない。
壁柱ファイバーの縦筋は SD345 相当、Qu の σwh は SD295 相当の固定値である。
5.1 と同じく `RcWall` へ材質を追加する設計変更が前提。
