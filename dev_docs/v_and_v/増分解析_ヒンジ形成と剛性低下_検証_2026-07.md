# 増分解析のヒンジ形成・剛性低下の実挙動検証

作成日: 2026-07-27
対象コード: `crates/squid-n-solver/src/nonlinear/pushover/`、
`crates/squid-n-element/src/frame/{concentrated,fiber}/`

増分解析（プッシュオーバー）の終了目標拡張（目標変位に加え目標層間変形角、
既定 1/150）の実装に合わせ、「実際にヒンジが発生し、剛性低下が生じているか」を
実解析で確認した記録。**ヒンジイベント（部材端モーメントの閾値記録）と
要素の実塑性化は独立**であり、イベントが出ていても荷重−変位曲線が軟化して
いるとは限らない、というのが本検証の出発点である。

## 1. 検証方法

`pushover_analysis_recording` を小規模モデル（単柱・門形ラーメン）で実行し、
性能曲線（`capacity_curve`）の区間接線剛性 \\( k = \Delta Q / \Delta \delta \\) の推移と
ヒンジイベントを突合した。

## 2. 発見と対応

### 2.1 材端集中ばね梁: 剛性が一切低下しない／降伏近傍で発散（是正済み）

- 単柱（集中ばね、fy=30）で降伏荷重 \\( V_y = M_y/L \\) の **1.4 倍まで区間剛性が
  126.3 N/mm 一定**（完全弾性）のまま、ヒンジイベントだけが記録されることを実測。
  原因はばね変形量に節点回転を使っていたこと（固定柱脚では節点回転 0 のため
  ばねが降伏しない）。
- 門形ラーメン（集中ばね）では接合部の節点回転による**偽降伏**で復元力
  （接線剛性 × 全変位）が不連続になり、最初の降伏近傍（層間変形角 ≈ 1/220）で
  **Newton が発散して解析が止まる**ことを実測。
- 是正内容・是正後の実測は
  [材端集中ばね梁_定式化レビュー_2026-07.md](材端集中ばね梁_定式化レビュー_2026-07.md) §1.3 を参照。
  是正後は単柱で弾性 126.3 → 降伏後 3.7 N/mm、門形で柱脚含む複数ヒンジ形成と
  接線剛性 1/2 未満への低下を回帰テストで担保している
  （`pushover/tests.rs::test_pushover_drift_angle_target_forms_hinge_with_stiffness_reduction`）。

### 2.2 変位法ファイバー要素: 降伏後も要素剛性がほとんど低下しない（是正済み・2026-07-27）

- 単柱（`ElementKind::Fiber`、fy=235）を頂部変位 300 mm（部材角 1/10）まで
  変位制御で押し込んでも、区間剛性は **190 → 180.5 N/mm（約 5% 減）** に
  とどまり、ベースシアは初降伏耐力の 4 倍超まで概ね線形に増加し続けることを実測。
  門形（fy=50）でも 4 部材すべてにヒンジイベントが出た状態で剛性低下は 6% だった。
- 原因は変位法（剛性法）1 要素の定式化上の限界。塑性化を担う端部ガウス点の
  積分重みが \\( 2L_p/L' \\)（標準的な断面せいでは全長の数 %）しかなく、端部断面が
  全塑性化しても要素剛性・内力への寄与がその重み分しか減らない。曲率場が
  3 次エルミート内挿に拘束されるため、ヒンジ状の曲率局所化を表現できない
  （弾性剛性も Timoshenko 厳密解と数 % 乖離していた）。
- **影響:** `ForceRegime::Auto` は柱（鉛直材）をファイバーへ振り分けるため、
  **柱ヒンジ形成による層剛性低下・崩壊機構が現状ほぼ表現できない**。
  変位制御で目標まで押し込むと、性能曲線が弾性に近い勾配のまま伸び
  \\( Q_u = \max(\text{base shear}) \\) を**危険側に過大評価**しうる。
  目標層間変形角の既定 1/150 の導入で従来既定（目標変位 500 mm）より
  過大評価の程度は抑えられるが、根本対策ではなかった。

**是正内容（2026-07-27）**

塑性化域考慮モデルを、「端部ガウス点の B 積分（重み \\( 2L_p/L' \\)）＋中央弾性剛性の
加算」から、「**全可撓長の弾性梁 \\( K_{el} \\) ＋ 端部の塑性増分ヒンジ**」の直列モデルへ
再定式化した。

- \\( K_{el} \\) は \\( B(\xi)^{\mathsf T}\,\mathrm{diag}(EA,EI_y,EI_z)\,B(\xi) \\) の 2 点 Gauss
  厳密積分＋一定せん断ひずみ場＋ねじりで組み、弾性状態の要素剛性は \\( K_{el} \\)
  （＝弾性 Timoshenko 梁）に厳密一致する（従来の数 % 過大は解消）。
- ヒンジは端部ファイバー断面（\\( \xi = \mp 1 \\)）の曲率 \\( \kappa \\)（両端×2 軸で最大 4）を
  内部未知数とし、各トライアルで内部平衡「弾性梁の端部モーメント
  \\( m_B = D_{\text{nom}}\cdot B(\xi_{\text{end}})\cdot\hat{\boldsymbol u} \\) ＝ 断面モーメント
  \\( m_{\text{sec}}(\varepsilon_0,\kappa) \\)」を要素内 Newton で解く。
  ヒンジ回転（節点回転と可撓端回転の差）は断面の弾性線を超える塑性超過分
  \\( \gamma = s\cdot L_p\cdot(\kappa - m_{\text{sec}}(\kappa)/EI_{\text{sec}}) \\) のみを持ち
  （\\( s \\) は端の向き: i 端 +1・j 端 −1）、弾性では \\( \gamma=0 \\) となる。
  可撓端回転 \\( \theta_b = \theta_n - \gamma \\) で置き換えた変位 \\( \hat{\boldsymbol u} \\) から
  \\( \boldsymbol f = K_{el}\hat{\boldsymbol u} \\) として復元力を評価し、整合接線
  \\( K^{*} = K_{el} - (K_{el}[:,\text{slots}]\cdot G)\cdot J^{-1}\cdot(D\cdot B\text{行}) \\)
  （内部変数消去のため非対称になり得るので対称化して使用）を用いる。
  軸ひずみは弾性のまま断面へ渡し、N–M 相関は断面のファイバー積分で自然に考慮する
  （軸方向の塑性変形は考慮しない）。ヒンジは剛接端（`EndCondition::Fixed`）のみ有効で、
  ピン・半剛端は従来どおり材端解放の内部自由度で扱う。
- MS（マルチスプリング）要素は実体が同じ `build_plastic_zone` のため同様に是正される。
- 実装: `crates/squid-n-element/src/frame/fiber/mod.rs` の `HingeState` /
  `solve_hinges` / `hinge_tangent` / `hinge_internal_force`。

**検証実測**（単柱・fy=30・地震重量 10kN・目標層間変形角 1/150）:
弾性割線剛性 \\( k_0 = 189.8 \\) N/mm → 降伏後接線 \\( k_t = 33.8 \\) N/mm（**82% 低下**）、
\\( Q_u = 2712 \\) N（手計算の全塑性崩壊荷重 \\( V_p = 1.1\cdot\sigma_y\cdot Z_p/L = 2750 \\) N の **98.6%**）。
回帰テストは `squid-n-solver` の
`pushover/tests.rs::test_pushover_fiber_hinge_softens_at_drift_target`
（既定目標到達までにヒンジが発生し、接線剛性が初期割線剛性の 1/2 未満へ低下し、
\\( Q_u \\) が \\( V_p \\) を大きく超えないことを確認）。既存の `squid-n-element` の
`fiber/tests.rs` の全テストも通過している。

### 2.3 荷重制御中の機構形成で解析全体がエラー終了する（未是正・小）

λ=1 のベースシア（0.2W）が保有水平耐力を上回るモデルでは、荷重制御フェーズの
途中で崩壊機構が形成され、剛性行列の Cholesky 分解が `NotPositiveDefinite` で
失敗して**解析全体が Err で終わる**（変位制御・弧長法へフォールバックしない）。
機構形成後の挙動を追う場合は弧長法（`use_arc_length`）の利用が前提だが、
荷重制御フェーズで分解失敗を検出した時点で確定済みステップを持って
変位制御へ移行する等の改善余地がある。

### 2.4 耐震壁の軸・曲げが常に弾性（是正済み・2026-07-27）

壁エレメントの壁柱（`WallPanelElement::column`）は弾性 `BeamElement` のままで、
非線形化されているのは面内せん断の Qu 頭打ちのみだった。曲げ支配の細長壁では
曲げ降伏が表現されず耐力を危険側に過大評価する（壁の曲げ終局式も
リポジトリに存在しなかった）。

**是正内容**: 非線形解析（保有水平耐力）の既定で、壁柱を §2.2 の塑性増分ヒンジ付き
ファイバー要素へ差し替えた（`WallPanelElement::with_fiber_flexure`、
factory の Wall 分岐で耐震壁のみ有効化）。断面はコンクリート格子（t×lw、NewRC）＋
壁筋比 ps を各層へ等価分散した縦筋鋼材ファイバー（既定 SD345・主筋割増適用）、
弾性剛性の諸元（rebar_factor・κ・開口低減）は従来の弾性壁柱と同一、
塑性化域長は 0.5·lw（可撓長 45% クランプ）。せん断の Qu 頭打ち（塑性すべり）は
維持し、すべりを差し引いた変位を壁柱へ与える直列構成とした（すべりと
ファイバー状態は update_state 内の固定点反復で整合させる）。

**検証実測**（細長壁 lw=1000・h=3000・t=150・Fc24・ps=0.0025、曲げ支配）:
弾性 k0=30.1 kN/mm → 目標 1/150 到達時の接線 kt≒−1.4 kN/mm
（コンクリートファイバーの軟化による負勾配＝曲げ降伏支配）、
Qu=151 kN（弾性外挿 602 kN の 25% で頭打ち）。回帰テストは
`pushover/tests.rs::test_pushover_wall_flexural_yield_softens`。
せん断支配の壁（lw=4000）の Qu 頭打ち挙動は従来テスト
（`test_pushover_drift_angle_target_runs_with_wall_panel`）で維持を確認。

## 3. 終了目標（目標層間変形角）の検証

- 既定 `PushoverTarget::default()` = 目標層間変形角 1/150 のみ有効・目標変位無効。
- 門形（集中ばね）で「最終ステップのみが 1/150 以上・それ以前のステップは
  1/150 未満」（初回到達での打ち切り）を回帰テストで担保。
- 目標変位（100 mm）と目標層間変形角（1/150）を両方有効にした場合、先に成立する
  層間変形角側で打ち切られることを `test_pushover_both_targets_stop_at_earlier_one`
  で担保。
- 従来実装の `roof >= max_disp` による荷重制御の早期終了は attempt ループしか
  抜けておらず機能していなかった（外側のステップループを止めていなかった）。
  今回の `target_reached` フラグ導入で是正済み。
- 要素種別ごとの動作確認: ファイバー柱（既存テスト群＋ §2.2 の実測）、
  材端集中ばね（§2.1）、MS 柱
  （`test_pushover_drift_angle_target_runs_with_multi_spring`）、
  耐震壁（壁エレメント、`test_pushover_drift_angle_target_runs_with_wall_panel`）で
  既定目標 1/150 の増分解析が完走し目標到達で打ち切られることを確認。
  耐震壁は Qu 頭打ち（弾完全塑性）による接線剛性の低下（初期の 1/2 未満）も
  併せて確認した。ファイバーは §2.2 の塑性増分ヒンジ再定式化（2026-07-27）後、
  `test_pushover_fiber_hinge_softens_at_drift_target` により
  降伏後の実剛性低下（初期割線剛性の 1/2 未満）を確認済みである。
  MS は実体が同じ `build_plastic_zone` のため同様に是正されるが、剛性低下を
  直接確認する回帰テストは終了判定の配線のみの確認にとどまる。
