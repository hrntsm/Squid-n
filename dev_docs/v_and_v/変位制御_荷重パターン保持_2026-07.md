# 変位制御フェーズの荷重パターン保持への再定式化（2026-07）

**日付:** 2026-07-27
**対象:** `crates/squid-n-solver/src/nonlinear/pushover/driver.rs`（変位制御フェーズ）、
`assembly.rs`（ペナルティ剛性引数の撤去）、`crates/squid-n-app/src/app/panels.rs`・
`summary.rs`（性能曲線の層別表示・CSV 層別列）。
**発端:** ユーザー報告。増分解析の性能曲線が「ヒンジ発生 0 件」のままベースシアの
低下→再上昇（V 字）を描く非物理的な挙動（GUI スクリーンショットによる指摘）。

## 1. 不具合: 変位制御が載荷パターンを「Ai 分布」から「頂部 1 点」へすり替えていた

- **症状:** 弾性のまま（ヒンジ 0 件・μmax=0）でも、性能曲線が λ=1（設計地震力レベル、
  C0=0.2）到達点をピークにベースシアが落ち込み、その後別勾配で伸び直す V 字を描く。
  スクリーンショットの Qu=637.4 kN は崩壊機構の耐力ではなく **0.2·ΣW（設計地震力
  レベル）そのもの**であり、Qu の過小評価（危険側の誤認ではなく過小側だが、
  崩壊機構に基づかない無意味な値）となっていた。
- **原因:** 変位制御フェーズ（ペナルティ法）の残差が
  `r = −f_int + penalty·(target − u_roof)·e_roof` で、荷重制御フェーズまで載荷していた
  Ai 分布の比例外力 `λ·q` が**残差から完全に脱落**していた。これはフェーズ切替時に
  「分布荷重を全て取り除き、頂部 1 自由度をばねで押す」別問題への不連続なすり替えを
  意味する。切替点で構造は分布荷重を失って弾性除荷し（ベースシア低下）、以降は
  頂部 1 点載荷の剛性勾配で再上昇する——これが V 字の正体で、ヒンジの有無と無関係に
  発生する。
- **既往レビューとの関係:** `保有水平耐力_プッシュオーバー_敵対的レビュー_2026-07.md`
  §1.1 はペナルティ法の**収束不能**（残差の桁落ち）を修正したが、載荷パターンの
  すり替え自体は見逃していた（収束するようになったことで、かえって非物理的な曲線が
  可視化された）。

## 2. 修正: 比例荷重パターンを保持する変位制御（Batoz–Dhatt 法）

外力を常に `λ·q`（q は Ai 分布参照外力）とし、荷重係数 λ を「頂部変位 = 目標値」の
拘束条件から決定する標準的な変位制御に再定式化した。各反復で

- 釣合い残差解 `δu_r = K⁻¹(λ·q − f_int)`
- 荷重パターン解 `δu_q = K⁻¹·q`
- `δλ = (target − u_roof − δu_r[roof]) / δu_q[roof]`、`δu = δu_r + δλ·δu_q`

収束は外力ノルム基準の相対残差（1e-6）と頂部変位の目標一致の AND。収束失敗時は
押込み増分を半減して再試行（荷重制御フェーズの λ 増分半減と同じ規則。従来は同一
目標のまま無意味に再試行していた）。機構形成で接線剛性が正定値性を失った場合は
factorize 失敗を検出してフェーズを打ち切る（エラーで解析全体を落とさない）。

付随して、

- λ を荷重制御→変位制御→弧長法で引き継ぐ状態変数とし、`PushoverStep::load_factor`
  に変位制御中も実際の λ を記録（従来は 1.0 固定）。弧長法の初期 λ も直前フェーズの
  確定値から継続（従来は 1.0 固定）。
- ペナルティ剛性が不要となったため `assemble_k` の `prescribed` 引数を撤去。

## 3. 検証

- **回帰テスト（新規）** `test_pushover_elastic_curve_monotonic_across_phase_switch`:
  降伏応力を非現実的に高くした弾性単柱で、(1) 荷重制御→変位制御の切替をまたいで
  ベースシアが単調非減少、(2) 全フェーズで `base_shear = λ·0.2W`（載荷パターン保持の
  直接検証）、(3) 最終 λ > 1、を検証。旧実装ではフェーズ切替点の低下により (1)(2) が
  失敗する。
- **既存テスト:** `squid-n-solver` 全 187 件パス。特に §1.1 の回帰テスト
  `test_pushover_displacement_control_reaches_target_and_exceeds_design_load`（目標変位
  到達・Vp 頭打ち）、機構形成テスト（`test_pushover_drift_angle_target_forms_hinge_
  with_stiffness_reduction` ほか）が新方式でもそのまま成立し、崩壊機構到達能力に
  後退が無いことを確認。
- **GUI:** 性能曲線を「横軸=層間変位・縦軸=層せん断力」の層別折れ線（凡例=階名）へ
  変更し、層別 Qu（capacity_curve 全点の層せん断ピーク、`actions.rs` の βu 分母と同じ
  規則）を数値表示。レポート CSV にも層別列を追加。`squid-n-app` 全 172 件パス。

## 4. 申し送り

- 変位制御の頂部変位刻みは従来どおり固定 10 分割。機構形成直前の急激な剛性変化を
  細かく追う適応刻みは未実装（増分半減の再試行で代用）。
- 弧長法フェーズ（既定 OFF）は修正 Newton のまま。λ 引き継ぎのみ整合させた。

## 5. 追記（2026-07-27）: 比較検証用「荷重増分のみ」モード

ユーザー要望（「変位制御との結果の違いを確認したい」）を受け、制御方式の選択肢
`PushoverControl` を追加した（既定 `Phased`＝段階制御、`LoadOnly`＝荷重増分のみ）。

- `LoadOnly` は変位制御・弧長法へ移行しない（`use_arc_length` は無視）。終了目標が
  有効な場合は λ=1 を超えて同じ刻み dλ のまま荷重増分を継続し、増分半減でも
  収束しない時点（＝耐力ピーク近傍）で打ち切る。安全上限は λ=10
  （Qun の λ 換算 5·Ds·Fes ≦ 5 を覆う）。終了目標が無効なら従来どおり λ=1 まで。
- `PushoverResult::control` に使用方式を記録（serde default で旧ファイル互換）。
  結果画面・CSV に方式を表示し、比較時の取り違えを防ぐ。
- 段階的耐力喪失解析（strength_loss）は機構形成域まで押し切る必要があるため
  常に `Phased` 固定。MCP ジョブも現状 `Phased` 固定（必要になれば引数化）。
- 検証: `test_pushover_load_only_extends_beyond_design_level`（λ>1 継続・目標到達・
  λ 単調非減少・Qu > 0.2W）、`test_pushover_load_only_without_target_stops_at_lambda_1`
  （目標無効時は λ=1 終了）。既存テストは全件パス（方式追加による既定挙動の変化なし）。
