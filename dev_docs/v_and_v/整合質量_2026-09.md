# Beam と Fiber の整合質量 — 2026-09

## 対象

等断面線材の整合質量、断面の材料領域質量、断面回転慣性、剛域質量、および Beam/Fiber 間の定式化一致を検証する。検証対象は端部解放を含む整合質量、剛域を含む質量変換、Beam/Fiber 共通化までである。

## 参照解と採用式

断面の単位長さ当たり質量と質量二次モーメントを材料領域から積分する。

\\[ \\mu = \\int_A \\rho\\,dA, \\qquad \\mu I_y = \\int_A \\rho z^2\\,dA, \\qquad \\mu I_z = \\int_A \\rho y^2\\,dA \\]

材軸まわりの回転慣性は `μIp = μIy + μIz` とする。Timoshenko の曲げ面形状関数と断面回転慣性を運動エネルギーへ積分し、剛域がある場合は可撓部の剛体アーム変換と剛域分布質量を加えて全長質量を保存する。端部解放では、初期弾性剛性から固定した `S=-Kbb^-1 Kba`, `R=[I;S]` で `M=Rᵀ Mbar R` とする。
