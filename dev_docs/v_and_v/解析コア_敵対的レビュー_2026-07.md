# 解析コア（静解析・固有値解析・増分解析）敵対的レビュー記録（2026-07）

静解析・固有値解析・増分解析の実装完了を受けて、`squid-n-solver` の該当コードを
網羅的・敵対的にレビューした記録。レビューは分野別の 3 系統（静解析＋共通基盤／
固有値解析＋減衰／増分解析＋耐力喪失）で独立に実施し、指摘は個別にコード上で
検証したうえで採否を決定した。

## 対象範囲

- 静解析: `statics/`（linear・analysis・construction）、共通基盤 `common/`（assemble・constraint）
- 固有値解析: `dynamic/eigen/`、`dynamic/damping.rs`
- 増分解析: `nonlinear/`（pushover 一式・arc_length・strength_loss）、`damage.rs`

## 修正した問題（検証済み）

### 静解析・共通基盤

1. **MPC／剛リンクのマスター DOF 拘束時の無言無視**（`common/constraint.rs`）
   マスター側の対象 DOF が拘束済み（非 active）の場合、スレーブ行が恒等写像のまま
   残りスレーブが独立自由度になっていた（拘束が無言で破れる）。剛床と同じ
   「空行＝スレーブも 0 に縮約」へ統一。回帰テスト追加。
2. **ダングリング NodeId 参照での panic**（`common/constraint.rs`・`statics/analysis/precheck.rs`）
   存在しない節点を指す拘束・剛床定義で `Reducer::build`／`precheck_model` が
   直接添字により panic していた。`Reducer::build` は範囲チェック付きで読み飛ばし
   （防御）、`precheck_model` は「存在しない節点への参照」の明示エラーに変更。
3. **部材荷重の非線材への誤適用**（`common/assemble.rs`・`statics/linear/mod.rs`）
   `MemberLoad` が壁・シェル等（4 節点）を指した場合、先頭 2 節点だけを材端と
   みなして荷重を配っていた。対象を 2 節点線材（Beam/Fiber/MultiSpring/Brace）に
   限定する共通ヘルパ `member_load_frame` を新設し、等価節点力側と固定端内力の
   重ね合わせ側で判定規則を共有。あわせて全要素×全荷重の総当り filter（O(E×L)）を
   要素 ID グルーピングに置換。
4. **階の並び順への暗黙依存**（`statics/analysis/seismic.rs`・`wind.rs`）
   `steel_height_ratio`（鉄骨造比 α）と風荷重の負担区間算定が `model.stories` の
   標高昇順を無検証で前提としていた。標高昇順ソートを追加（`construction.rs` と
   同じ防御）。
5. **その他の入力堅牢化**: 地震荷重の NaN 混入除外（`share == 0.0` は NaN を
   すり抜ける）、`main_system_weight` の負値クランプ、`construction.rs` の
   NaN 標高での sort panic 回避（明示エラー化）。

### 固有値解析・減衰

6. **Rayleigh 減衰係数の重根発散**（`dynamic/damping.rs::rayleigh_coeffs`）
   ω1≈ω2（対称建物の X/Y 並進モード縮退で普通に起きる）でゼロ除算により
   α_m/β_k が発散し、NaN/∞ が減衰行列に無警告で混入していた。単一振動数の
   対称分配（α=h₁ω₁、β=h₁/ω₁）へのフォールバックを追加。回帰テスト追加。
7. **負質量の無検証受理**（`dynamic/eigen/mod.rs`）
   節点質量の符号誤り等で M が半正定値でなくなると、一般化 Jacobi の判別式
   負値丸めにより誤った固有値が「正常終了」で返っていた。縮約後質量対角の
   負値を明示エラー化。回帰テスト追加。
8. **剛性特異時の英語エラー露出**（`solve_eigen`）: `NotPositiveDefinite` を
   日本語診断（拘束不足・機構の可能性）へ包み直し。
9. **軽微**: `compute_participation` の未使用引数削除、`partial_cmp().unwrap()` の
   全順序フォールバック化（NaN 混入時の panic 回避）、`StiffnessProportional` の
   ω≦0 ガード統一、モード数切り詰めの doc 明記。

### 増分解析

10. **固定 λ 刻みの収束失敗時の暗黙増分拡大**（`pushover/driver.rs`）
    非適応（均等刻みフォールバック）経路で収束失敗ステップを読み飛ばすと、
    スケジュール値と確定状態が乖離し実効増分が 2dλ・3dλ…と無言で拡大していた。
    スケジュールを確定済み λ 基点（λ→λ+dλ）へ変更し、増分半減で収束しない場合は
    制御方式によらず打ち切りへ統一。λ 上限は `lambda_cap`（段階制御=1、
    LoadOnly+目標有効=10）で明示。
11. **4 節点耐震壁への線材評価の誤適用**（`geom.rs`・`hinge.rs`・`shear_yield.rs`・
    `member_response.rs`）
    壁（節点配列 `[下辺a,下辺b,上辺a,上辺b]`）に対し nodes[0]→nodes[1]（壁脚の
    幅方向・水平）を材軸とする局所座標系でヒンジ・せん断降伏・部材応答を評価
    していた（壁要素本体の等価柱軸とほぼ直交）。`member_end_forces_at_face` と
    `track_shear_yield` を 2 節点線材専用にゲートし、`compute_member_response` は
    壁について βu 用の水平力（節点群合計、従来から正しい）のみ集計するよう変更。
12. **静的不静定次数の直交部材混入**（`mechanism.rs::compute_static_indeterminacy`）
    平面骨組の次数式 r=3m−3n+s に、加力直交方向の梁・壁・ばねまで無差別に
    算入していた（多方向スパンの 3D モデルで r が水増しされ、機構成立ゲート
    ≧r+1 が過大になり層崩壊機構を Partial と誤判定）。加力平面に関与する
    2 節点線材（直交水平成分 ≦0.707）とその接続節点に限定。回帰テスト追加
    （2 構面＋直交大梁の 3D モデルで X/Y 双方向 r=6 を確認）。
13. **弧長法フェーズのヒンジ追跡欠落**（`driver.rs`）
    荷重制御・変位制御と異なり弧長法フェーズだけ `track_hinges`／
    `track_shear_yield`／`update_ductility` が呼ばれておらず、耐力ピーク以降に
    形成されるヒンジが機構判定・詳細図から欠落していた。他フェーズと同じ追跡を追加。
14. **リファクタリング**: driver.rs の 4 フェーズにほぼ同一の Newton 反復・
    要素状態更新コードが重複していたため、`newton_converge`（長期載荷・荷重制御の
    共通反復）と `apply_du_to_behaviors`（δu の要素反映。全フェーズ共有）へ抽出
    （959 行 → 約 830 行。変位制御の Batoz–Dhatt 反復は 2 種の解を要するため独自のまま）。

## 検討のうえ見送った指摘（申し送り）

- **拘束連鎖のサイクル検出**（`Reducer::build`）: 循環 MPC 入力は `max_pass` で
  打ち切られるだけでエラーにならない。剛体的な循環（係数積=1）は実質正しい縮約に
  収束するため実害は限定的だが、係数積≠1 の病的入力は無言で不正な縮約になる。
  `Reducer::build` の呼び出しが 70 箇所超あり Result 化の影響が大きいため今回は
  見送り。将来 `build` の Result 化とセットで対応する。
- **ヒンジ記録の重複（毎ステップのスナップショット）**: `PushoverResult::hinges` は
  発生イベントではなく確定ステップごとの閾値超過スナップショットの連なりで、
  同一材端が重複する。UI（`aggregate_hinges`）が「全ステップ中の最大塑性率」を
  この重複記録から集約しているため、遷移時のみの記録へ変えると最大 μ が過小に
  なる。今回は型 doc への明記に留めた。改善するなら「遷移イベント＋材端別の
  最終 μ」を別フィールドで持つ設計変更が必要。
- **塑性率 μ の部材単位追跡**（`ductility.rs`）: μ は要素の危険断面（最大曲率
  ガウス点）単位で、i 端・j 端の `HingeLevel`（Yield/Ultimate）判定に同じ値を
  使い回している。材端別の塑性率が要る場合は `DuctilityProbe` の材端分離
  （要素 API 変更）が必要。機構判定は Yield/Ultimate を区別しないため影響しない。
- **`damage.rs::cumulative_damage_max_amplitude` の μmax→1+ 発散**: 式の分母
  (μmax−1) が 0 に近づくと D→∞ になる。原典（累積塑性変形倍率の D 算定式）との
  照合が必要（コメントに従い既に一度分母/分子の修正歴あり）。原典確認まで保留。
- **弧長法の Err 詳細の握りつぶし**（`driver.rs`）: 収束失敗と分解失敗を同じ
  break で扱う設計は「正定値性喪失＝耐力喪失の終了判定」として意図的だが、
  実装バグ由来の Err も同経路で沈黙する。ログ基盤導入時に Err 内容の記録を追加する。
- **`gevd_jacobi` の `squid-n-math` への切り出し**・**`MassOption::Lumped` の
  デッドコード**: 機能に影響しないため見送り。将来の座屈解析等で GEVD を再利用
  する際に切り出しを検討。
