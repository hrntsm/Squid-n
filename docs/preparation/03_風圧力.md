# 風圧力

風向によらない算定諸元（建物高さ \\( H \\)、基準風速 \\( V_0 \\)、地表面粗度区分、速度圧 \\( q \\)、
\\( E_r \\)・\\( G_f \\)・\\( E \\)）を示したうえで、X 方向・Y 方向それぞれについて基部せん断力と、
階ごとの負担高さ区間・見付幅・見付面積・\\( K_z \\)・風圧力・層水平力を示します。見付幅は
風向直交方向の座標範囲で決まるため、方向ごとに異なります。

平面的に一方向へ広がりがないモデル（平面架構など）では、その方向の見付幅が 0 に
なり、片方向だけしか算定できないため、算定できなかった風向とその理由を表示します。

風圧力の対象は地上一般階のみで、PH 階・地下階は含みません。

算定根拠は [1.2 風圧力](../calc_basis/01_荷重/02_風圧力.md)を参照してください。
