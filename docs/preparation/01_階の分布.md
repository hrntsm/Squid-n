# 階の分布

建物概要（節点数・部材数・支点数・階数・剛床数・地盤面 GL・建物高さ \\( h \\)・鉄骨造高さ比
\\( \alpha \\)・地震用重量の総和 \\( \Sigma W \\)・質量モデル）と、階ごとの一覧を上階から順に示します。

## 階と剛床

**階と剛床は別のものです**。階は法規上の層（層間変形角・層せん断力・剛性率・偏心率が
対象とする区画）であり、剛床は解析上の面内剛体拘束です。1 つの階が剛床を持たないことも、
段差床のように 1 つの階が複数の剛床を持つこともあります。

このため、節点が階と剛床のどちらに属するかは、別々の規則で決まります。

| 対象 | 帰属の規則 |
| --- | --- |
| 階 | **区間**。直下階の床レベルを超え、当該階の床レベル以下にある節点 |
| 剛床 | **床面**。当該階の床レベルから 1 mm 以内にある節点 |

最下階の区間の下端は**基部レベル**（剛床代表節点を除く全節点の最小標高）とし、下端は
含みません。したがって柱脚などの基部の節点はどの階にも属しません。

この違いは、柱を途中で分割した節点や、階高の途中に取り付く梁の節点に現れます。これらの
**中間高さの節点は階に属しますが、剛床には入りません**。階に属するため、その節点へ配分された
重量は階の地震用重量に算入されます。一方で面内剛体として拘束してよいのは同一床面の節点だけ
であり、中間節点まで剛床に含めると、存在しない水平剛性が生じてしまいます。

段差床（同じ階に複数の床レベルがある場合）は、区間の規則により全体が同一の階に属し、
剛床は床レベルごとに分かれます。複数の剛床を持つ階の水平力は、剛床ごとの重量比で
按分します（[1.1 地震力](../calc_basis/01_荷重/01_地震力.md)）。

## 階の定義と自動算定の分担

階の一覧のうち、**階名・床レベル・階種別（一般 / PH / 地下）・地震用重量の手入力**は
利用者が定めるデータで、準備計算は書き換えません。**所属節点・剛床・地震用重量の算定値・
主要構造種別**は、節点と部材が決まってはじめて定まる派生値で、準備計算のたびに算定し直します。

階が 1 つも定義されていないモデル（他形式からの取り込みなど）に限り、準備計算が節点の
標高をクラスタリング（許容差 1 mm）して階を初期化します。このとき最下レベルは基部と
みなして階にせず、階名は下から `2F`・`3F`… とします。

階名が `2F` から始まるのは、階名を**床基準**でそろえているためです。
Squid-n の階は床を代表し、床レベルがその階の標高になります。
最下レベルを基部（1FL）とみなす以上、その 1 つ上の床は 2FL であり、そこを代表する階の
名前も `2F` になります。ST-Bridge の階（`StbStory`）も床基準のため、取り込んだモデルと
アプリ内で作ったモデルで階名の意味が一致します。
階名は利用者が定めるデータであり、`2FL`・`R` のように付け替えれば、以後の準備計算でも
その名前が保たれます。

| 列 | 内容 |
| --- | --- |
| 床レベル | 階の標高 [mm]（モデル座標） |
| 階高 | 直下階との標高差 [mm]。最下階は地盤面 GL からの高さ |
| 節点数 | その階に属する節点の数 |
| 剛床数 | その階に定義された剛床（ダイアフラム）の数 |
| 地震用重量 \\( W_i \\) | 階の地震用重量 [kN]（固定荷重＋地震用積載） |
| 累積 \\( \Sigma W_j \\) | 当該階以上の地震用重量の合計 [kN] |
| 構造・種別 | 階の主要構造種別（RC / S / SRC）と階種別（一般 / PH / 地下） |

剛床数が 0 の階、地震用重量が 0 の階は強調表示します。剛床のない階にも水平力は載りますが、
載荷先が剛床代表節点ではなく階の各節点になる（[1.1 地震力](../calc_basis/01_荷重/01_地震力.md)）
ため、意図した床面のモデル化になっているかを確認してください。
剛床のない階は[モデル整合性チェック](./README.md#モデル整合性チェック)にも警告として並びます。
解析は止まりませんので、意図した入力であればそのまま進めてかまいません。

支点数には、階の生成が作る剛床代表節点（面外拘束を持つ仮想節点）は含めません。

主要構造種別は、その階に属する柱・梁の構造種別
（[2.5 構造種別の判定](../calc_basis/02_材料/05_構造種別の判定.md)）を集計して決めます。
RC を RC、S を S、鉄骨とコンクリートが一体で働く SRC・CFT を SRC とし、階に属する部材で
もっとも多い種別を採ります。部材の所属階は、材端節点のうちもっとも高い節点の所属階と
します（階 \\( i \\) の階高区間にある柱は上端が階 \\( i \\) に、階 \\( i \\) のレベルにある梁も
階 \\( i \\) に属します）。種別ごとの本数が同数の場合、および断面も材料も割り当てられていない
部材だけの階は RC とします。主要構造種別は略算周期の鉄骨造高さ比
\\( \alpha \\)（[1.1 地震力](../calc_basis/01_荷重/01_地震力.md)）にのみ効き、S の階が増えるほど
設計用固有周期 \\( T \\) が長く \\( R_t \\) が小さくなるため、判定が割れた場合に S を採らないことが
安全側になります。
