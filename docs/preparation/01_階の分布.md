# 階の分布

建物概要（節点数・部材数・支点数・階数・剛床数・地盤面 GL・建物高さ \\( h \\)・鉄骨造高さ比
\\( \alpha \\)・地震用重量の総和 \\( \Sigma W \\)・質量モデル）と、階ごとの一覧を上階から順に示します。

| 列 | 内容 |
| --- | --- |
| 床レベル | 階の標高 [mm]（モデル座標） |
| 階高 | 直下階との標高差 [mm]。最下階は地盤面 GL からの高さ |
| 節点数 | その階に属する節点の数 |
| 剛床数 | その階に定義された剛床（ダイアフラム）の数 |
| 地震用重量 \\( W_i \\) | 階の地震用重量 [kN]（固定荷重＋地震用積載） |
| 累積 \\( \Sigma W_j \\) | 当該階以上の地震用重量の合計 [kN] |
| 構造・種別 | 階の主要構造種別（RC / S / SRC）と階種別（一般 / PH / 地下） |

剛床数が 0 の階、地震用重量が 0 の階には地震力・風荷重を載荷できないため、強調表示します。

支点数には、階の生成が作る剛床代表節点（面外拘束を持つ仮想節点）は含めません。

主要構造種別は、その階に属する柱・梁の構造種別
（[2.5 構造種別の判定](../calc_basis/02_材料/05_構造種別の判定.md)）を集計して決めます。
RC を RC、S を S、鉄骨とコンクリートが一体で働く SRC・CFT を SRC とし、階に属する部材で
もっとも多い種別を採ります。部材の所属階は、材端節点のうちもっとも高い節点の所属階と
します（階 \\( i \\) の階高区間にある柱は上端が階 \\( i \\) に、階 \\( i \\) のレベルにある梁も
階 \\( i \\) に属します）。種別ごとの本数が同数の場合、および断面も材料も割り当てられていない
部材だけの階は RC とします。主要構造種別は略算周期の鉄骨造高さ比
\\( \alpha \\)（[1.1 地震力](../calc_basis/01_荷重/01_地震力.md)）にのみ効き、S の階が増えるほど
設計用固有周期 \\( T \\) が長く \\( R_t \\) が小さくなるため、判定が割れた場合に S を採らないことが
安全側になります。
