# 地震力（Ai 分布）

算定諸元（設計用固有周期 \\( T \\) とその算定法、地盤種別と \\( T\_c \\)、振動特性係数 \\( R\_t \\)、
地域係数 \\( Z \\)、標準せん断力係数 \\( C\_0 \\)、基部せん断力 \\( Q\_1 \\)、ベースシア係数 \\( Q\_1/\Sigma W \\)）と、
階ごとの \\( W\_i \\)・\\( \Sigma W\_j \\)・\\( \alpha\_i \\)・\\( A\_i \\)・\\( C\_i \\)・\\( Q\_i \\)・\\( P\_i \\) を示します。

\\( \alpha\_i \\)・\\( A\_i \\) は一般階でのみ算定するため、PH 階・地下階の欄は「—」と表示します。
\\( C\_i \\) の欄は、一般階では層せん断力係数、PH 階では震度 \\( k \\)、地下階では水平震度 \\( K \\) を表します。

層の水平外力 \\( P\_i \\) も表示します。負値が現れて 0 へクランプした場合は、警告を表示します
（階の地震用重量の並びが上階ほど重くなっているなど、入力の確認が必要です）。

設計用固有周期に精算（固有値解析）を選択していて固有値解析が未実行の場合は、
Ai 分布を算定せず、固有値解析の実行を促すメッセージを表示します（略算周期へ黙って
読み替えることはしません）。

算定根拠は [地震力](../calc_basis/01_荷重/01_地震力.md)を参照してください。
