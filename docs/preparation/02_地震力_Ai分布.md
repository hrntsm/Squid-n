# 地震力（Ai 分布）

算定諸元（設計用固有周期 \\( T \\) とその算定法、地盤種別と \\( T_c \\)、振動特性係数 \\( R_t \\)、
地域係数 \\( Z \\)、標準せん断力係数 \\( C_0 \\)、基部せん断力 \\( Q_1 \\)、ベースシア係数 \\( Q_1/\Sigma W \\)）と、
階ごとの \\( W_i \\)・\\( \Sigma W_j \\)・\\( \alpha_i \\)・\\( A_i \\)・\\( C_i \\)・\\( Q_i \\)・\\( P_i \\) を示します。

\\( \alpha_i \\)・\\( A_i \\) は一般階でのみ算定するため、PH 階・地下階の欄は「—」と表示します。
\\( C_i \\) の欄は、一般階では層せん断力係数、PH 階では震度 \\( k \\)、地下階では水平震度 \\( K \\) を表します。

層の水平外力 \\( P_i = Q_i - Q_{i+1} \\) に負値が現れて 0 へクランプした場合は、警告を表示します
（階の地震用重量の並びが上階ほど重くなっているなど、入力の確認が必要です）。

設計用固有周期に精算（固有値解析）を選択していて固有値解析が未実行の場合は、
Ai 分布を算定せず、固有値解析の実行を促すメッセージを表示します（略算周期へ黙って
読み替えることはしません）。

算定根拠は [1.1 地震力](../calc_basis/01_荷重/01_地震力.md)を参照してください。
