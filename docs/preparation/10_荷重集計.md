# 荷重集計

荷重ケースごとの節点荷重数・部材荷重数と、全体座標系での外力の合計
\\( \Sigma F_x \\)・\\( \Sigma F_y \\)・\\( \Sigma F_z \\) [kN] を示します。部材荷重は、集中荷重はその大きさ、
分布荷重は \\( \frac{w_1 + w_2}{2}(b - a) \\) を作用方向へ投影して積算します（等価節点力へ
置換する前の外力の総和であり、支点反力と釣り合います）。鉛直下向きが負のため、
重力系の荷重ケースでは \\( \Sigma F_z \\) が負値になります。

荷重が定義されていない荷重ケースは淡色で表示します。

算定根拠は [積載荷重](../calc_basis/01_荷重/02_積載荷重.md)・
[床荷重の分配](../calc_basis/01_荷重/03_床荷重の分配.md)・
[自重の長期応力解析への接続](../calc_basis/01_荷重/06_自重の長期応力解析への接続.md)・
[床の断面と自重](../calc_basis/01_荷重/08_床の断面と自重.md)を参照してください。

**実装**：荷重ケースごとの集計は `squid_n_app::app::App::build_prep_load_cases`（`crates/squid-n-app/src/app/preparation.rs`）が行い、集計対象の荷重は `squid_n_app::app::App::sync_auto_load_cases_action`（`crates/squid-n-app/src/app/actions/loads.rs`）が `squid_n_job::auto_loads::compute_auto_load_cases` の算定結果をモデルへ同期します。
