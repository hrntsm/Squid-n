# 幅厚比

鋼系（S・CFT）の代表最大幅厚比と、それによる部材ランク（FA〜FD）を示します。断面・材料が
割り当てられ、形状定義を持つ鋼系の部材を、断面・部材用途（柱／梁）・材料ごとに集計します。
これらが同じ部材は 1 行にまとめ、該当部材数を添えます。幅厚比やランクを算定できない形状も、
この集計条件を満たせば表に表示します。

部材ランク FA〜FD は、保有水平耐力計算の構造特性係数 \\( D\_s \\) の算定に用います。
FC は黄色、FD は赤で強調します。

鋼系のブレースは、断面と材料が割り当てられていれば本表の集計対象です。用途欄は、柱以外を
「梁」としてまとめます。保有水平耐力計算での筋かいの部材種別は、有効細長比から別途判定します。

構造種別が RC/SRC の要素、または形状定義を持たない断面は本表の集計対象外です。

**円形鋼管・CFT 円形鋼管**は代表最大幅厚比を表示しませんが、板厚が正であればランクを表示します。
幅厚比を算定できない場合は、最大幅厚比欄を「—」と表示します。幅厚比の数値の有無にかかわらず、
ランクが `None` の場合は「判定不可」と表示します。幅厚比表に行のない形状（溝形・T形・山形等）は、
集計対象であっても、最大幅厚比が算定できる場合を含めてランクは「判定不可」です。

判定条件の算定根拠は [部材ランク（FA〜FD）](../calc_basis/07_二次設計/03_部材ランク.md)を参照してください。
