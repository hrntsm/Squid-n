# 応力図（N/Q/M 図）への変形の重ね表示

N/Q/M 図の表示中に「変形表示」を有効にすると、[変形図の表示倍率](./01_変形図の表示倍率.md)で変形させた節点
座標を基準に架構を描画します。応力図は変形後の材軸方向（要素ローカル y 軸）へ
張り出すため、図も変形形状に追従します。応力の値・最大値の正規化は変形の重ね
表示による影響を受けません。

さらに「内部たわみ」表示が有効なときは、梁の張り出しの基準線（張り出し量 0 の
線）を節点間の直線ではなく梁の変形後 Hermite 曲線とし、梁の描画曲線に沿って
応力図を描きます（基準線は梁の線描画と同一の曲線）。無効なときは変形後の節点間
直線を基準線とします。張り出し方向（要素ローカル y 軸）と応力値の正規化はいずれの
場合も変わりません。
