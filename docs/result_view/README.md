# 結果の表示（3D ビューア）

3D ビューアにおける解析結果の表示仕様のうち、計算を伴うもの（変形図の表示倍率と、
床・二次部材の変形追従）の根拠を示します。ここでの計算はいずれも**画面表示のための
処理**であり、解析結果（節点変位・部材応力）そのものには影響しません。
