# 画面構成と工程タブ

Squid-n の画面は、上部の工程タブ、左右のアイコン列とドック、中央のビュー、下部のドックと
ステータスバーからなります。工程タブは解析の流れ（モデル→荷重→解析→結果→設計→レポート）に
沿って並びますが、**進行をロックしません**。構造設計は断面変更と再計算を繰り返すため、
いつでも前の工程へ戻ってモデルを編集できます。

本節では、画面の構成と、ドック・ログ・stale（要再計算）・断面編集の現行挙動を紹介します。
準備計算の内容とモデル整合性チェック（診断）は
[準備計算](../preparation/README.md)、結果の表示は
[結果の表示](../result_view/README.md)を参照してください。

<div class="impl-ref">

**実装参照**：工程タブは `squid_n_app::app::Tab`（`crates/squid-n-app/src/app/mod.rs`）が表し、タブ切替時のドック配置は `squid_n_app::app::App::apply_tab_preset`（`crates/squid-n-app/src/app/actions/mod.rs`）が設定します。

</div>

## 工程タブとドックの初期配置

上部ツールバーに、ファイル操作、工程タブ、Undo/Redo のボタンを置きます。工程タブは
モデル・荷重・解析・結果・設計・レポートの 6 つです。

工程タブのクリックは、その工程に適したドック配置へ切り替える**プリセット**として働きます。
以後のドック開閉・パネル切替の手動変更は妨げません。

| タブ | 切替時の初期配置 |
| --- | --- |
| モデル | 左ドックにナビゲータ、下ドックにモデル表、右ドックにインスペクタ |
| 荷重 | 左ドックにナビゲータ、下ドックに荷重表、右ドックにインスペクタ |
| 解析 | 右ドックに ① 準備計算、下ドックにログ |
| 結果 | 左ドックにナビゲータ、右ドックにインスペクタ |
| 設計 | 右ドックにインスペクタ |
| レポート | 変更なし |

**結果が陳腐化しているときは、結果タブ・設計タブの見出しに「⚠」を付けます**（[stale](#stale要再計算)）。

<div class="impl-ref">

**実装参照**：タブ見出しの stale マークは `squid_n_app::app::App` のツールバー描画（`crates/squid-n-app/src/app/mod.rs`）が `Staleness::results_stale` を見て付けます。

</div>

## 左右のアイコン列（ドック）

左右の端に、ドックを開閉するアイコン列を常時表示します。対象のドックが開いていてそのパネルが
アクティブならクリックで閉じ、それ以外は開いてそのパネルをアクティブにします。

- **左アイコン列**：ナビゲータ、作成パレット
- **右アイコン列**：インスペクタ、① 準備計算、静的解析、固有値、増分解析、時刻歴応答、質点系

右ドックは縦スクロールでき、① の番号は準備計算の見出しにだけ付けます。各解析パネルの先頭には
最終実行時刻と stale 表示を出します。左右ドックは境界をドラッグして幅を変えられます。

<div class="impl-ref">

**実装参照**：左右のアイコン列は `squid_n_app::app::panels::activity_bar`（`crates/squid-n-app/src/app/panels/activity_bar.rs`）が描き、アイコンは `assets/icons/` の SVG です。

</div>

## 下ドックとステータスバー

下ドックのタブは、ログ・モデル・荷重・準備計算・診断です。

- ログの見出しには件数を付けます。
- 準備計算は陳腐化しているとき「準備計算 *」と表示します。
- 診断は最新で不備があるとき「診断 (E…/W…)」とエラー・警告の件数を表示します。

ステータスバーのアイコンでも下ドックを開けます。ファイル名には未保存の変更があるとき
「●」を付け、実行中はジョブ名と経過秒を表示します。解析結果の状態は
**✓ 最新 ／ ⚠ stale ／ ▷ 未実行** の 3 つです。直近のエラーは 1 行で表示し、クリックすると
下ドックを開いてログタブへ切り替えます。右端には部材・節点・断面の件数を表示します。

<div class="impl-ref">

**実装参照**：下ドックのタブとステータスバーは `squid_n_app::app::panels::status_bar`（`crates/squid-n-app/src/app/panels/status_bar.rs`）が描きます。

</div>

## イベントログ

イベントログは、セッション内の出来事（エラー・注意・ジョブの開始と完了など）を時系列で
保持し、下ドックに表示します。レベルは 情報・注意・エラーの 3 段階で、時刻は
**アプリ起動からの経過時間**です。保持件数の上限は 1000 件で、超えたものは古い順に捨てます。

- **エラー**はステータスバーの 1 行表示とログの両方へ反映し、下ドックを自動で開きます。
  エラーが埋もれると解析結果を誤って信頼しかねないためです。
- **注意**はステータスバーとログへ反映しますが、自動では開きません。
- **情報**はログのみに残します。

<div class="impl-ref">

**実装参照**：ログは `squid_n_app::app::{LogLevel, LogEntry, EventLog}`（`crates/squid-n-app/src/app/mod.rs`）が保持し、発行は `squid_n_app::app::App::{report_error, report_notice, report_info}`（`crates/squid-n-app/src/app/actions/mod.rs`）に集約しています。

</div>

## ナビゲータと選択の連動

左ドックのナビゲータは、階・部材グループ・断面・材料・荷重ケース・結果ケースなどのツリーです。
ナビゲータの選択と、3D ビューのピック、下ドックのテーブル行は**双方向に連動**します。
解析結果ツリーの操作は[ナビゲータの解析結果ツリー](../result_view/14_ナビゲータの解析結果ツリー.md)、
荷重ケースのツリーは[荷重の入力](../calc_basis/01_荷重/07_荷重の入力.md)を参照してください。

## 3D 選択から断面編集（共有編集と複製）

3D ビュー・ナビゲータ・テーブルで部材を選ぶと、右ドックのインスペクタにその断面と
算定プロパティを表示します。

- **編集はその断面を参照する全部材へ波及します**。インスペクタには
  「この断面を使う N 部材に影響」と影響する部材数を常時表示し、意図しない部材まで
  変わることを防ぎます。
- 並びの**「複製してこの部材だけ別断面に」**は、新しい断面を作って選択中の部材だけを
  割り当て直します。

いずれも編集トランザクションとして適用するため Undo でき、断面の作成・符号と階の操作は
[断面の符号と階](./02_断面の符号と階.md)を参照してください。

<div class="impl-ref">

**実装参照**：インスペクタの断面表示と波及は `squid_n_app::app::panels::inspector`（`crates/squid-n-app/src/app/panels/inspector.rs`）が担い、波及の編集は `squid_n_edit::EditSectionShape`、複製は `squid_n_edit::DuplicateSectionForMember` を用います。

</div>

## stale（要再計算）

モデル・荷重・断面などを編集すると、依存する結果や設計が古くなり（stale）、
利用者へ再計算が必要であることを示します。重い解析を勝手に走らせない方針のため、
**再計算は手動**です。

- 結果タブ・設計タブの見出しに「⚠」、ステータスバーに「⚠ stale」を表示します。
- 再計算は解析タブの実行ボタンで行います。
- 準備計算・診断にも、それぞれの陳腐化表示（「準備計算 *」・診断件数）があります。
- 通り芯のように解析結果へ影響しないデータの編集では、結果を stale にしません。

<div class="impl-ref">

**実装参照**：陳腐化は `squid_n_app::app::Staleness`（`crates/squid-n-app/src/app/mod.rs`）が保持します。解析へ影響する編集は `Staleness::mark_edited`、影響しない編集は `Staleness::mark_non_calc_edited` が更新します。

</div>
