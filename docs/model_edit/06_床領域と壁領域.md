# 床領域と壁領域

本節では、床で扱う「床領域」と、壁で扱う「壁領域」の概念を説明する。

## 床領域

床領域は、1 つの床版とその床版に直交する小梁群をまとめたグループである。

- `Slab` は床版そのものを表す
- `Slab.secondary_joist_ids` は、その床領域に属する小梁の ID 一覧を表す
- 小梁は `SecondaryMemberKind::Joist` であり、同一床領域に同じ小梁 ID が重複して入ることはない

この構成により、ひとつの床版に対して「その床を支える小梁」が明示的に定義される。床領域の境界と小梁の所属が分離されているため、同じ小梁を別の床領域に含める設計上の誤りを、モデル検証で早く見つけられる。

### 版なし床領域について

`Slab` は床版そのものを表す型であり、床領域に対して `None` になる状態はモデル上に存在しない。

床版のない構成を表したいときは、`Slab` そのものではなく、`WallRegion.wall` が `None` のように「版なしの壁領域」として扱う。

すなわち、床領域は常に `Slab` により床版を表し、床版が存在しない構成はモデルに持たない。小梁の所属整理は `Slab.secondary_joist_ids` で行い、版がない床領域という概念は使わない。

## 壁領域

壁領域は、1 つの壁版とその壁版に直交する間柱群をまとめたグループである。

- `WallRegion` は壁版と間柱グループをまとめる
- `WallRegion.wall` は壁版の要素 ID を指す。`None` は版なしを意味する
- `WallRegion.post_ids` は、その壁領域に属する間柱の ID 一覧を表す
- 間柱は `SecondaryMemberKind::Post` であり、同一壁領域に同じ間柱 ID が重複して入ることはない

壁領域の設計上の意味は、壁版が持つせん断や剛性に対して、どの間柱がその壁を補強・支持しているかを明確に分離することである。

### 版なし壁領域

壁領域の `wall` が `None` の場合、壁版そのものが存在しない構成とみなす。間柱だけのグループであっても、`post_ids` による所属整理は成立する。

例えば、壁版を持たない間柱群のグループや、部材としては壁として扱わない補助的な間柱束を整理するときに使う。

## `secondary_joist_ids` と `post_ids`

- `secondary_joist_ids`: その床領域に属する小梁 ID リスト
- `post_ids`: その壁領域に属する間柱 ID リスト

どちらも「該当領域に属する二次部材の一覧」であり、二次部材自身がどの領域に属するかを直接管理するのではなく、領域側が子要素の ID を持つ形で整理する。

この設計では、床領域・壁領域は対象の版に対するグループの役割を持ち、二次部材はそのグループに一覧で登録される。

## 重複不可・種別チェック

`Slab.secondary_joist_ids` と `WallRegion.post_ids` は、以下の検証が行われる。

- 重複 ID を持てない
- 参照先が実在する二次部材であること
- `Slab.secondary_joist_ids` の参照先は `Joist` であること
- `WallRegion.post_ids` の参照先は `Post` であること

このため、誤って小梁を壁領域に登録したり、間柱を床領域に登録したりすることは、モデル検証で弾かれる。

## 既定値

- `secondary_joist_ids`: 空リスト（デフォルト）
- `wall_regions`: 空リスト（デフォルト）

このため、特に割り当てを行わない場合でもモデルは妥当な状態を保つ。領域に所属する二次部材を定義しない限り、参照は空である。

## まとめ

床領域と壁領域は、版とその関連する二次部材をグルーピングするための仕組みである。床領域では `Slab` が常に床版を表し、壁領域では `WallRegion.wall` が `None` のときのみ版なし壁領域とみなす。所属する小梁・間柱は `secondary_joist_ids` / `post_ids` に保持し、これらは重複を許さず、Joist / Post であることが検証される。
