# 床領域と壁領域

床領域は、水平な大梁が囲む 1 スパンの閉領域です。版の仕様は持たず、名前・境界・所属する床板・所属小梁・手入力小梁ラインをまとめます。
床板は床領域内の版（大梁または小梁で囲まれる）、または主架構に取り付く版（片持ち・バルコニー・出隅）です。1 つの床領域は複数の床板を持ちえます。

壁領域は、柱・梁が囲む鉛直構面内の閉領域です。版の仕様は持たず、名前・境界・所属する壁版・間柱をまとめます。
壁版は断面・開口を持つ実体です。柱・梁に囲まれた壁版と、梁または床に取り付く壁版（パラペット・構面外の腰壁・垂れ壁・自立壁）があります。

解析用の壁要素はモデルに保存しません。準備計算・解析・診断の直前に、囲まれた壁版から都度生成します。

荷重分配・小梁検定・壁エレメントの計算根拠は次を正とします。

- [1.3 床荷重の分配](../calc_basis/01_荷重/03_床荷重の分配.md)
- [6.5 小梁・床の断面検定](../calc_basis/06_一次設計/05_小梁・床の断面検定.md)
- [4.5 壁エレメントモデル](../calc_basis/04_要素剛性/05_壁エレメントモデル.md)
- [準備計算](../preparation/README.md)
- [ST-Bridge 形式](../model_io/02_ST-Bridge_形式.md)

本章は入力場所と既定値、ナビゲータからの二次部材操作を説明します。床領域・壁領域の追加や削除、所属の付け直しは準備計算が行います。実行すると解析結果は陳腐化します。

## 入力場所

| 対象 | 場所 |
|------|------|
| 床板（囲まれ・取り付き）、床領域名、手入力小梁ライン | 下ドック・モデルタブ「床板（スラブ）」 |
| 壁版（囲まれ・取り付き）、断面・開口・三方スリット・取付き先 | 下ドック・モデルタブ「壁版」。3D の壁作成モードでも囲まれた壁版を 4 点で追加できる |
| 床領域・壁領域の一覧、所属小梁・間柱、未割当二次部材 | 左ドック・ナビゲータ |
| 同上の編集（MCP） | `model_edit` / `model_query`（[ツール一覧](../mcp_server/03_ツール一覧.md)） |

利用者は床領域・壁領域そのものを追加・削除できません。表示名の変更と、二次部材の所属操作だけが手入力です。間柱・小梁の所属は、次の準備計算で幾何から入れ直されます。

### 既定値

- 床領域名・壁領域名: 空（ナビでは `床領域 {id}` / `壁領域 {id}`）
- 手入力小梁ライン: 空
- 所属小梁・間柱: 空。ST-Bridge 取り込み後は未割当へ入り、準備計算で領域へ振り分け
- 未割当小梁・未割当間柱: 空
- 床板の分配法: 三角形・台形（`TriTrapezoid`）
- 取り付く床板の取付き区間: 全長 `[0.0, 1.0]`、荷重の出口は取付き線への分布、張り出し量の UI 初期値は 1000 mm
- 壁版: 断面未割当、開口面積 0 mm²、個別開口なし、開口部重量 0 N、三方スリットなし
- 取り付く壁版の取付き区間: 全長 `[0.0, 1.0]`。張り出しの正は鉛直上向き
- 同じレベルとみなす Z 差: 1 mm。辺上 1 mm 以内は内部に含めない。部材材軸の許容差: 10 mm

レベル一致・辺上・材軸の許容差は [1.3](../calc_basis/01_荷重/03_床荷重の分配.md) と同じです。

取り付く床板・取り付く壁版の取付き先種別（線・点・床領域）は作成時に決め、作成後に変える場合は削除して作り直します。

どの床領域にも入らず、水平大梁にちょうど 1 辺が全長載り自由端が 1 点または 2 点の床板は、準備計算で取り付く床板へ変換します。自由端が 3 点以上のとき（出隅・L 形など）は囲まれた床板のまま残し、版があれば診断が警告します。手入力で出隅（点取付き）を作ることはできます。壁版も、水平な辺がちょうど 1 つ大梁に全長載り自由端が 1〜2 点なら取り付く壁版へ変換します。自立壁（床への取り付き）は自動検出しません。

階への複製は、囲まれた床板と二次部材を写します。取り付く床板と壁版は複製しません（[階への複製](./05_階への複製.md)）。

## ナビゲータ

左ドックの「ナビゲータ」に、次の 3 つの折りたたみセクションがあります。

### 床領域

準備計算が生成した各床領域を、表示名（未設定時は `床領域 {id}`）で一覧します。
領域名をクリックすると、下ドックのモデルタブ「床板（スラブ）」を開きます。
子ノードとして、その領域に属する小梁（`小梁 n1–n2` 形式）が並びます。

- 小梁をクリックすると、両端節点が 3D ビューで選択されます。
- 小梁横の 🗑 ボタンで、領域から外します（実体は「未割当」へ移ります）。
- 床領域の追加・削除はナビからは行えません。

### 壁領域

壁領域も同様に一覧し、子として間柱（`間柱 n1–n2`）を表示します。
領域名をクリックすると、モデルタブ「壁版」を開きます。
間柱のクリック・🗑 による領域からの外しも、床領域の小梁と同じです。
壁領域の追加・削除もナビからは行えません。

### 未割当

どの床領域・壁領域にも属さない小梁・間柱を列挙します。

- クリックで両端節点を 3D 選択。
- 🗑 で実体ごと削除。
- フォーム（種別・節点 2 つ・断面（任意））から未割当へ追加できます。
  同じ端点の重複は無視されます（変更なし）。

編集はすべて undo / redo の対象です。変更後は解析結果が陳腐化するため、準備計算と解析をやり直してください。
