# 5.8 段階的耐力喪失解析

せん断降伏後の耐力劣化を再載荷で疑似的に考慮します（段階的耐力喪失解析）。
塑性回転角 a は FEMA 356 Table 6-7 に基づきます。

**算定式**：耐力喪失変形角を超過した部材を、両端ピンかつせん断非負担へ置換して荷重 0 から再載荷します。
FEMA C 判定（せん断補強良好）は FEMA 356 Table 6-7 脚注のとおり \\( s \le d/3 \\) かつ \\( V_s \ge 0.75V \\)（d は有効せい）とし、塑性回転角 a はテーブル 4 隅値の双線形補間で求めます。

除去した部材の「両端ピン」は、非線形梁要素でも材端解放として厳密に反映されます
（[4.9.6 非線形梁要素の材端条件](../04_要素剛性/09_非線形梁要素のモデル化.md)）。
除去を重ねると残存構造が機構となり、再載荷の剛性行列を分解できなくなります。これは
「これ以上の再載荷は物理的に意味を持たない」状態であり、**その時点までのパスを結果として
解析を正常終了します**（初回パスで分解できない場合は元モデル自体が不安定なのでエラーとします）。

**実装**：`nonlinear::strength_loss`（`strength_loss/mod.rs`）が算定します。
