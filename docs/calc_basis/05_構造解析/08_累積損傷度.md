# 累積損傷度（鉄骨梁端部）

鉄骨梁端部の累積損傷度を、レインフロー法（ASTM E1049-85 3 点法）と Miner 則を用いて算定します。

**算定式**

破断寿命および損傷度を次とします:

\\[ N\_f = (\mu/C)^{-1/\beta} \\]

\\[ D = \sum \text{count} \cdot (\mu/C)^{1/\beta} \\]

振幅は振れ幅（peak-to-peak）としてカウントされるため、片振幅としての \\( \mu \\) は振れ幅の 1/2 とします。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( N\_f \\) | 片振幅 \\( \mu \\) に対する破断寿命（繰返し回数） | 回 |
| \\( D \\) | 累積損傷度（Miner 則） | - |
| \\( \mu \\) | 部材塑性率の片振幅（振れ幅の 1/2） | - |
| \\( C \\) | 疲労強度係数 | - |
| \\( \beta \\) | 疲労指数 | - |
| \\( \text{count} \\) | レインフローで抽出したサイクルの繰返し回数（全サイクル 1.0・半サイクル 0.5） | 回 |
