# 6.5 小梁・床の断面検定

床の中の小梁とスラブの断面検定は、全体 FEM から独立して行い、設計タブの「小梁・床の設計」表に出します。実際に載る荷重の分配は[1.3 床荷重の分配](../01_荷重/03_床荷重の分配.md)のとおり床領域・床板の境界へ配るため、この検定は主架構の解析結果とは別に、小梁・床板それぞれを単純梁・一方向版とみなした略算です。

## 6.5.1 小梁の検定

**床領域の手入力小梁ライン**（`FloorRegion.joists`）はこの表の対象です。
床スラブに紐づいた小梁で交差があるものは、床格子 FEM（[1.4.3 交差小梁の床格子サブストラクチャ解析](../01_荷重/03_床荷重の分配.md#143-交差小梁の床格子サブストラクチャ解析床-phase-f)）の部材力（\\( M \\)・\\( Q \\)・たわみ \\( \delta \\)）で検定します。
交差がない小梁は、単純支持梁として次式で検定します。

\\[ M = wL^2/8,\quad Q = wL/2,\quad \delta = 5wL^4/384EI \\]

たわみの制限は \\( \delta/L \le 1/250 \\) です。
斜めの小梁を含む床は、大梁への取付きを格子の支点として正確に表せないため、格子解析は行いません。その場合は単純支持梁として検定します。

**ST-Bridge から取り込んだ小梁**（二次部材）も、床スラブの小梁一覧には載せずこの表で検定します。
床荷重を小梁経路と二次部材経路の両方で渡すと二重に計上されるためです。
断面検定では、二次部材の小梁を**単純支持梁**として見ます。
荷重は、床領域の分配計算（[1.3 床荷重の分配](../01_荷重/03_床荷重の分配.md) の `distribute_region`）が床板境界から返す `LoadTarget::Span`（小梁両端節点対）の線荷重形状（三角形・台形・等分布など）を、小梁スパン上で重ね合わせ、曲げ・せん断・たわみの最大値として求めます。床領域内に複数の床板がある場合は、各床板の分配結果を同一小梁へ合算します。代表床板（表示・室用途の参照）は、小梁が所属する床領域の `slab_ids` 先頭です（床領域所属が未設定のときは、分配に用いた床領域の先頭床板）。

小梁の許容曲げ応力度は鋼の長期許容値（既定 \\( F = 235 \\) の \\( F/1.5 \\)）を用います。

**実装**：`squid_n_job::floor_grillage`（`build_slab_grillage`・`solve_grillage`・`joist_design_forces`）と `squid_n_job::auto_loads`（`slab_grillage_node_reactions` 等）が床格子を算定します。
`squid_n_load::floor::secondary_joist_distribution_loads` が分配 `Span` を集め、`simple_beam_extremes` が単純梁の最大部材力を求め、`App::floor_design_checks` が二次部材小梁を `design_joist_from_forces` で検定します。

## 6.5.2 床（スラブ）の一方向検定

版があり板厚が正の床板だけを検定します（版 = 断面が割り当たり板厚が正）。
囲まれた矩形は単純支持相当 \\( M = wL^2/8 \\)（係数 8）、取り付きは片持ち \\( M = wL^2/2 \\)（係数 2）です。
取り付きのスパン \\( L \\) は張り出し量の絶対値の大きい方（\\( \max |extent| \\)）です。台形などで矩形寸法が取れなくても、この \\( L \\) が正なら検定します。
版なし・スパン非正・厚さ 0 は検定しません。

**実装**：`squid_n_design_jp::floor::design_slab_oneway` が算定し、`App::floor_design_checks` から呼びます。
