# 6.1 材料の許容応力度

## 6.1.1 コンクリート

コンクリートの許容応力度を建築基準法施行令 第91条に基づいて算定します。

**算定式**

- 許容圧縮応力度 \\( f_c \\) = 長期 \\( F_c/3 \\)、短期 = 長期×2
- 許容せん断応力度 \\( f_s \\) = 長期 \\( \min(F_c/30, 0.49 + F_c/100) \\)、短期 = 長期×1.5
- 付着（異形鉄筋）\\( f_a \\) = 長期上端筋 \\( \min(F_c/15, 0.9 + (2/75)F_c) \\)、その他 \\( \min(F_c/10, 1.35 + F_c/25) \\)、短期×1.5
- 軽量コンクリート 1 種・2 種は許容応力度 0.9 倍

**実装**：`material_strength::{concrete_allowable_compression, concrete_allowable_shear, concrete_allowable_bond, concrete_class_factor}` が算定します。

## 6.1.2 鉄筋（径区分に注意）

鉄筋の許容応力度は、建築基準法施行令 第90条（表）に基づいて算定しますが、異形鉄筋の許容引張応力度には径区分がある点に注意してください。

**算定式（許容引張、長期／短期）**

- SR235 = 155/235、SD295 = 195/295、SD345/390/490 は \\( D \ge 29 \to 195/ \\)、\\( D < 29 \to 215/ \\)（短期は 345/390/490）
- USD685 = 215/685（径によらず）
- せん断補強筋: 長期は SR235 のみ 155、他は 195。短期は基準強度（SR235 = 235、
  SR295/SD295 = 295、SD345 = 345、SD390 = 390）。SD490 の短期はせん断のみ \\( F = 390 \\) に頭打ち

**実装**：`material_strength::{rebar_allowable_tension, rebar_allowable_shear}` が算定します。

### 鉄筋の材質はどこで指定するか

主筋・せん断補強筋の材質（グレード）と呼び名サイズは、**断面（配筋）の属性**として指定します（断面タブの「配筋」欄）。部材に割り当てる材料はコンクリート（\\( F_c \\)）を表すため、鉄筋の強度は断面側で持ちます。

| 項目 | 指定場所 | 選択肢 |
|------|----------|--------|
| 主筋の材質 | 断面の配筋「主筋 材質」 | SD295A・SD295B・SD345・SD390・SD490・USD685（認定品名の直接入力も可） |
| 主筋の呼び名 | 断面の配筋「X主筋／Y主筋 径」 | D10・D13・D16・D19・D22・D25・D29・D32・D35・D38・D41 |
| せん断補強筋の材質 | 断面の配筋「せん断補強筋 材質」 | 上記の異形鉄筋に加え、高強度品（KH785・UB785・KSS785・SHD685・SPR785・MK785・SBPD1275） |
| せん断補強筋の呼び名 | 断面の配筋「せん断補強筋 径」 | 主筋と同じ呼び名一覧 |

グレード名から強度を解決する規則は次のとおりです。

- 異形鉄筋 `SD`・丸鋼 `SR` は接頭辞に続く数値を基準強度とします（`SD345` → 345 N/mm²）
- 高強度鉄筋の認定品名は名称末尾の数値を降伏点とします（`KH785` → 785、`SBPD1275` → 1275 N/mm²）
- 材質が未設定の場合は、部材材料の \\( f_y \\)（設定されていれば）を用います。せん断補強筋の \\( \sigma_{wy} \\) は、未設定なら SD295 相当（295 N/mm²、規格上の最小グレード）を既定とします
- 主筋の材質も材料の \\( f_y \\) もない RC 部材は、非線形解析（保有水平耐力計算・非線形時刻歴応答解析）を**エラーで停止**します（[5.7 増分解析](../05_構造解析/07_プッシュオーバー解析.md)「解析前の入力チェック」）。既定値 345 N/mm² で補うと、SD295 の部材で耐力を過大評価するためです

せん断補強筋に普通強度（`SD*`・`SR*`）を指定した場合は令90条の表、高強度品を指定した場合は製品別の認定値（6.1.3）を用います。

**実装**：`squid_n_core::material_grade::{rebar_grade_f_value, rebar_yield_strength, shear_rebar_yield_strength}` が解決し、検定側の材質選択は `material_strength::{main_rebar_grade, shear_rebar_grade, is_high_strength_shear_grade}` によります。

## 6.1.3 高強度せん断補強筋（pw 上限）

高強度せん断補強筋の pw 上限を、各製品の大臣認定・製品技術資料の製品別 pw 上限（Category B）に基づいて定めます。

**算定式（pw 上限、短期・安全確保）**：KH785 = \\( \min(1.2\\%, 1.0\\% \cdot F_c/27) \\)、KH685/SPR685 = \\( \min(1.2\\%, 1.2\\% \cdot F_c/27) \\)、SHD685/MK785 = 1.2% 固定、ウルボン系 = 1.0〜1.2% ほか（製品別表）。
w_ft は長期 195、短期は SBPD1275 = 585・他 590 とします。

**実装**：`material_strength::{high_strength_pw_cap, high_strength_w_ft}` が算定します。

## 6.1.4 鋼材（F 値・許容応力度・座屈）

鋼材の F 値・許容応力度・座屈を、建築基準法施行令 第90条・98条／告示、および鋼構造設計規準 1973 に基づいて算定します。

**算定式**

- F 値（板厚区分）: SS400/SN400 = 235(\\( t \le 40 \\))/215、SN490/SM490 = 325/295 ほか
  （グレード別の F 値一覧は [2.4 標準材料（プリセット）一覧](../02_材料/04_標準材料一覧.md)）。
  F 値は部材に割り当てた材料の名称から前方一致で解決します（`SN490B` → `SN490` 等）。
  名称から解決できない材料（直接入力材料）は、材料に登録した Fy を基準強度として用います。
  Fy も未設定の場合は F = 235 とします。
- 許容引張 \\( f_t \\) = 長期 \\( F/1.5 \\)、短期 \\( F \\)、許容せん断 \\( f_s \\) = 長期 \\( F/(1.5\sqrt{3}) \\)、短期 \\( F/\sqrt{3} \\)
- 圧縮（座屈考慮）:

\\[ \Lambda = 1500/\sqrt{F/1.5} \\]

\\[ \nu = 3/2 + (2/3)(\lambda/\Lambda)^2 \\]

\\[ \lambda \le \Lambda: f_c = F(1 - 0.4(\lambda/\Lambda)^2)/\nu \\]

\\[ \lambda > \Lambda: f_c = (18/65)F/(\lambda/\Lambda)^2 \\]

**実装**：`material_strength::{steel_f_value, steel_ft, steel_fs, steel_fc, big_lambda}` が算定します。
