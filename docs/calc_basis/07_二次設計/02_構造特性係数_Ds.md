# 7.2 構造特性係数 Ds

昭和55年建設省告示第1792号 第1 に基づき、架構形式と部材ランクに応じて構造特性係数 Ds を定める。

**算定式（Ds 値表）**
- RC ラーメン: FA 0.30 / FB 0.35 / FC 0.40 / FD 0.45
- RC 耐震壁付: 0.35 / 0.40 / 0.45 / 0.55
- S ラーメン: FA 0.25 / FB 0.30 / FC 0.35 / FD 0.40
- S ブレース付: 0.30 / 0.35 / 0.40 / 0.50

**崩壊機構による補正**

Ds は部材ランクに加えて、プッシュオーバーで判定した崩壊機構を層別に反映する。

- 全体崩壊形: 標準 Ds 表をそのまま適用する。
- 層崩壊形: 崩壊が生じる層の代表ランクを1段階不利側（FA→FB→FC→FD、FD は据え置き）に扱う。
- 崩壊機構が未形成（部分崩壊形）: 機構が確定していないため機構補正は行わず部材ランクのみで算定し、その旨を暫定値として明示する（崩壊機構の確定が必要保有水平耐力算定の前提となる）。

**部材ランク**

各部材のランク（FA〜FD）は、RC はせん断余裕度 \\( Q_{su}/Q_{mu} \\)（柱は軸力を考慮した終局曲げ強度から \\( Q_{mu} \\) を算定）、鋼は幅厚比区分から定め、層の代表ランクは所属部材の最も不利なランク（worst）をとる。

**実装**：`holding_capacity::ds_value` が値表を引き、層ごとの Ds は代表ランクと崩壊機構から算定する（`secondary::member_rank::story_ds`）。
