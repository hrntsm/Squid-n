# 7.5 層間変形角

建築基準法施行令 第82条の2 に基づき、各層の層間変形角が 1/200 以下（帳壁等の変形追従性が確認できれば 1/120 まで緩和）であるかを確認します。

**算定式**

\\[ \text{層間変形角} = \delta/h \le 1/200 \\]

層間変位 δ には柱の最大値（`secondary::stiffness_ratio::max_column_drift`）を用います。
各柱の δ は、当該層の**上下端床レベル上の節点間**の加力方向水平変位差です。
中間節点で分割された鉛直材は、上下端を結ぶ連なりとして 1 本の柱とみなします。

**実装**：`holding_capacity::check_story_drift` が判定します。
