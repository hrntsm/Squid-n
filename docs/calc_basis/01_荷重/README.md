# 荷重・外力

このソフトは、固定荷重、積載荷重、積雪荷重、地震力を算定するもので、地震力は建築基準法施行令 88 条および昭和 55 年建設省告示第 1793 号を根拠とします。風圧力は算定しません。風荷重を考慮する場合は、荷重ケースを種別「風荷重」で作成し、荷重を直接入力します。
