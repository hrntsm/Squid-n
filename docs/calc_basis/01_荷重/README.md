# 1. 荷重・外力

このソフトは、固定荷重、積載荷重、積雪荷重、風圧力、地震力を算定します。
地震力は建築基準法施行令 88 条および昭和 55 年建設省告示第 1793 号、風圧力は令 87 条および平成 12 年建設省告示第 1454 号を根拠とします。

> 各項目は「導入文（何を・どの基準で）、算定式、実装」の順で記します。（[凡例](../README.md#このセクションの読み方)）
