# 自重の長期応力解析への接続（DL 荷重ケース）

部材自重・壁自重・ダンパー自重を、固定荷重（`LoadCaseKind::Dead`）の標準荷重ケース「DL」の内容として自動生成し（スラブ固定荷重の分配と合算）、長期応力解析・荷重組合せへ接続します。
**床（スラブ）の自重はここには含まず**、床の断面の板厚と材料から算定して床荷重の分配へ乗せます（[床の断面と自重](./08_床の断面と自重.md)）。自重の算定対象を部材・壁・ダンパーに限ることで、床の重量が両方から二重に載るのを防いでいます。
梁は自重による等分布荷重（梁自重による CMQ に相当）、柱は軸力、壁・シェルは頂点への節点荷重となります（上下とも躯体と一体なら四隅へ等分、梁際にスリットがあれば切れていない側の 2 節点へ全量。[壁の断面と自重](09_壁の断面と自重.md)）。壁の自重そのものの算定は[壁の断面と自重](09_壁の断面と自重.md)を参照してください。壁・シェルは解析要素（4 節点の耐震壁等。[壁エレメントモデル](../04_要素剛性/05_壁エレメントモデル.md)）を持つ壁版だけが対象です。取り付く壁版の自重は、取付き先が梁（線アンカー）なら床側と同じ幾何解決の経路で「DL」ケースへ合流し、取付き先が床領域（自立壁）ならスラブ固定荷重の分配へ等価な面荷重として上乗せされます（[地震用重量・層データの生成](05_地震用重量_層データの生成.md)）。

## 解析要素にならない壁版の自重

どの壁版が解析要素になるかは [壁エレメントモデル](../04_要素剛性/05_壁エレメントモデル.md) が定めます。解析要素にならない柱・梁に囲まれた壁版（間柱で分割された壁版、壁領域の一部を占める腰壁・垂れ壁など）の自重は、**壁版の境界の辺へ配ります**。

壁版ごとに、自重を伝える境界辺とその負担率を明示します。囲まれた壁版の境界は壁版自身ではなく壁版割当領域が保持し（ADR 0020）、その閉領域の辺順に並べ、最後の辺から最初の辺へ戻る閉じる辺を含めて、非負の負担率を指定します。総和は 1（画面では 100%）で、許容差は 1e-9 です。例えば下辺が最初の辺なら `[1, 0, 0, 0]` は下辺へ全量、`[0.75, 0, 0.25, 0]` は下辺へ 75%、上辺へ 25% を表します。負担率は支持条件・接合部の納まりに基づいて利用者が決めます。

**既定は未指定（空配列）です。** 自重を持つ壁版が解析要素にならない場合、未指定・負担率の合計不正・負値・非有限値・壁版割当領域の境界の欠落や支持部材を解決できない場合・指定辺のスリットは解析前チェックのエラーです。支持辺を幾何から推定するフォールバックは行わず、指定できない辺の負担分を別の辺へ自動的に振り替えることもありません。上下の梁際をともに切った壁版は、境界が 4 節点の囲まれた壁版に限り、その納まりを実際に想定しないため、負担率の指定内容や柱際の状態によらず、解析要素になるかどうかにかかわらず解析前チェックが一律にエラーとします。切れていない辺へ振り替えないため、いずれかの梁際のスリットを外してください。境界が 4 節点でない壁版ではスリットが効かず、指定が残っていても警告のみで解析は止めません（[準備計算の診断](../../preparation/README.md)）。自重は躯体・仕上げ・増打ち・開口部重量を含む総重量に負担率を乗じ、各辺へ等分布荷重として与えます。

各辺の支持部材と材軸区間は、壁版割当領域の境界を正本としてそのまま使います（ADR 0020）。壁版割当領域は柱・梁・間柱を構面ごとに面走査して分割した閉領域で、境界の 1 辺は 1 つの支持部材の材軸区間に対応します。同じ種類どうし（主架構どうし・間柱どうし）の重なりは解析前チェックのエラーであり、異種の重なりは主架構を優先します。同種の重なりを自動で一意化しないため、再構築でどの支持部材が残るかは要素順に依存します。辺の全長を覆うかは領域の構成から決まり、節点座標からの支持先の再推定はしません。境界が参照する支持部材が実在し、種別（柱・梁・間柱）が適合し、材軸を解決できることは `Model::validate` が確認します。境界の頂点にモデル節点が無くても（間柱の端が梁の材軸中間にある場合など）支持先と荷重を取り落としません。

実際に梁で受ける壁の自重を柱へ指定すると、その梁の曲げを過小評価する危険側のモデルとなります。境界辺の存在だけで荷重の伝達を判断せず、実際の納まりに応じて指定してください。間柱を支持辺にする場合は、その間柱が壁版の境界となるよう壁版を分割します。

実装は `WallPlate::self_weight_shares` と `squid_n_load::wall_plate_load` です。地震用重量の直接集計も同じ支持辺・間柱端部の負担率を用い、主架構へ伝えた荷重を支持部材の両端反力として節点重量に加算します。DL からの集計と密度からの直接集計は同じ荷重伝達を扱い、支持先のない壁版や端部負担率が不正な間柱を含む直接集計はエラーを返します。解析要素となる壁版は要素自重の経路を使い、この指定を使用しません。取り付く壁版は既存の取付き先・荷重伝達方法を使います。

柱が受け持つ分は、その柱の材軸方向の分布荷重として載せます。軸力は、節点変位による内力に、切断位置までの部材荷重を含む固定端内力を重ね合わせて求めます。引張を正とし、下端固定・上端自由の鉛直柱に下向き等分布荷重 w が作用する場合、下端からの距離 x における軸力は N(x) = −w(L−x) です。下端は柱が受け持つ全重量を圧縮軸力として負担し、上端の軸力は 0 となります。上下端とも拘束される場合の負担は、架構の変形適合条件と釣合いから決まります。

間柱が受け持った荷重は、二次部材の反力の逐次伝達が主架構へ運びます（[床荷重の分配](03_床荷重の分配.md)）。鉛直な間柱では、壁から間柱への負担率とは別に、**間柱の上下端への負担率も明示入力が必要**です。既定は未指定で、解析前エラーとなります。間柱自身の自重にも同じ端部負担率を適用します。

**指定した支持辺に荷重を流せない壁版は、解析前チェックがエラーで止めます。** 自重の行き先が決まらないためです。行き先のない荷重を節点荷重として残すと、要素が接続しない節点への節点荷重は解析の自由度から外れるので、荷重の一覧には見えるのに解析からは消えます。

**算定式**：総重量は [自重の長期応力解析への接続（DL 荷重ケース）](06_自重の長期応力解析への接続.md#自重の長期応力解析への接続dl-荷重ケース) の自重算定規則（`enumerate_self_weight`）と同一とし、線材は次式の等分布荷重、その他は節点荷重に変換します（総量保存）。

\\[ w = \text{総重量}/\text{節点間長} \\]

**実装**：解析要素にならない壁版の自重の辺への分配は `squid_n_load::wall_plate_load::distribute_enclosed_wall_plates`（`crates/squid-n-load/src/wall_plate_load.rs`）が担います。DL 荷重ケース本体の生成は `squid_n_load::self_weight::self_weight_case_content`（`crates/squid-n-load/src/self_weight.rs`）が行い、アプリの解析実行系（`sync_gravity_load_cases_action`）がスラブ分配と合算して「DL」へ冪等に同期します。
地震用重量の集計では DL（自重を含む）を重力ケースとして算入し、階の生成では密度からの自重直接算入を無効にします（`generate_stories_with_opts` の `include_density_self_weight = false`。両方行うと二重計上になります）。DL ケースがないモデルでは、階の生成で密度から自重を直接算入します。

間柱の端部支持条件で自由端とした端には、端部負担率0を指定してください。自由端への正の負担率は入力エラーとし、反対側へ自動的に振り替えません。
