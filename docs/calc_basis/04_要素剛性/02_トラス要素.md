# トラス（ブレース）要素

軸剛性のみをもつブレースを次式で算定します（トラス要素の力学）。

\\[ K_B = E \cdot A/L \\]

軸剛性のみを持ち、曲げ・せん断・ねじりはゼロとします。

**実装**：`squid_n_element::frame::truss`（`crates/squid-n-element/src/frame/truss.rs`）が算定します。

## 引張専用ブレースの扱い

引張専用ブレース（`ElementKind::Brace { tension_only: true }`）は要素側では特別扱いせず、一般ブレースと同じ全剛性 \\( E\,A/L \\) のトラス要素として扱います。圧縮側の無効化は線形応力解析の active-set 反復で実現し、計算条件で切り替えます。

- **一括解析（既定, `false`）**：引張専用ブレースも全剛性 \\( E\,A/L \\) のまま 1 回だけ解くため、圧縮側でも軸力を負担します。
- **active-set 反復（真の引張専用, `true`）**：各反復で圧縮側（軸伸び δ < 0）に入った引張専用ブレースの軸剛性を残留比 1e-6 まで縮小して無効化します。無効化ブレースの節点変位から求めた軸伸びが引張へ転じれば再び active に戻します。active 集合が前反復と一致した時点で収束とみなします。収束後は active な引張ブレースのみが \\( N = E\,A/L \cdot \delta \\) を負担し、圧縮ブレースの軸力はほぼ 0 となります。

**実装**：要素側は `squid_n_element::frame::truss::TrussElement`（`crates/squid-n-element/src/frame/truss.rs`）が `tension_only` の有無によらず一般ブレースと同じ全剛性 \\( E\,A/L \\) のトラス要素として扱い、圧縮側の無効化は `squid_n_solver::statics::linear`（`crates/squid-n-solver/src/statics/linear/mod.rs`）の `solve_tension_only_iterative` が active-set 反復で行います。計算条件は `squid_n_core::model::StressAnalysisCfg::tension_only_iteration`（`crates/squid-n-core/src/model/stress_cfg.rs`、既定 false）が保持します。
