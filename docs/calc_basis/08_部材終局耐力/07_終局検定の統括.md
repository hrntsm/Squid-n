# 終局検定の統括

部材別のせん断、付着、軸の余裕度を統括して算定します（保有水平耐力計算における部材種別判定・余裕度検定の実務的取扱い）。
両端ヒンジは \\( Q\_{mu} = \text{上限強度倍率} \cdot (M\_{u\text{上}} + M\_{u\text{下}})/\text{内法} \\) とし、余裕度 \\( Q\_{su}/Q\_{mu}, Q\_{bu}/Q\_{mu} \ge 1.0 \\) で OK と判定します。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q\_{mu} \\) | 曲げ終局時せん断力 | N |
| \\( Q\_{su}, Q\_{bu} \\) | 終局せん断耐力・付着割裂耐力 | N |
| \\( Q\_L \\) | 長期せん断力 | N |
| \\( Q\_{mx}, Q\_{my} \\) | x・y 方向の曲げ終局時せん断力 | N |
| \\( Q\_{ux}, Q\_{uy} \\) | x・y 方向の終局せん断耐力 | N |
| \\( M\_{u\text{上}}, M\_{u\text{下}} \\) | 上端・下端の終局曲げモーメント | N·mm |
| \\( \text{内法} \\) | 部材の内法長さ | mm |
| \\( b\_{ai} \\) | 接合部有効幅の片側分 | mm |
| \\( b\_i \\) | 梁幅 | mm |
| \\( D \\) | 柱の断面せい | mm |

**算定式**：部材別にせん断、付着、軸の余裕度を算定します。
梁の余裕率は長期せん断力 QL を分子から控除した \\( \frac{Q\_{su} - Q\_L}{Q\_{mu}} \\)・\\( \frac{Q\_{bu} - Q\_L}{Q\_{mu}} \ge 1.0 \\) とします。
ここで QL は重力ケース集合（Dead と地震用 Live、なければ Live）の解析せん断力を加算したものです。
柱の 2 軸せん断余裕度は \\( 1/((Q\_{mx}/Q\_{ux})^2 + (Q\_{my}/Q\_{uy})^2)^{1/2} \\) とします。
曲げ Mu は at 式によります（`squid_n_core::rc_capacity::{rc_mu_simple, rc_column_mu_simple}`。柱は軸力を考慮）。
せん断は塑性理論式（既定）または[靭性指針式せん断信頼強度 Vu / Vbu](02_RC_終局せん断.md#靭性指針式せん断信頼強度-vu--vbu)を切り替えます。
接合部終局の有効幅は \\( b\_{ai} = \min(b\_i/2, D/4) \\)（許容応力度検定と同じ）。
検定対象は用途別 RC 断面（RC 梁・RC 矩形柱・RC 円形柱）とします。梁の曲げ Mu は実配筋の上端・下端と曲げ符号から引張側を選んで算定します（曲げ 0 のときは引張鉄筋量の小さい側）。対応 RC 断面で Fc 未設定・Fc/断面寸法不正・材料未設定・主筋降伏強度未解決・配筋不整合・有効せい 0 以下・せん断補強筋の未対応グレードまたは fy 未設定がある場合は対象外とせず部材 ID 付きエラーとします。柱の 2 軸せん断余裕度は指定により検定します。
