# クライアント設定例

## Claude Code

```bash
claude mcp add squid-n -- /path/to/squid-n-mcp model.scz
```

もしくはプロジェクトの `.mcp.json` に登録します。

```json
{
  "mcpServers": {
    "squid-n": {
      "command": "/path/to/squid-n-mcp",
      "args": ["model.scz"]
    }
  }
}
```

## Claude Desktop

`claude_desktop_config.json` に以下のエントリを追加します。

```json
{
  "mcpServers": {
    "squid-n": {
      "command": "/path/to/squid-n-mcp",
      "args": ["model.scz"],
      "env": {
        "SQUID_N_RESULT_DIR": "/path/to/results"
      }
    }
  }
}
```
