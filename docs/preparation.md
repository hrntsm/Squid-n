# 準備計算（解析前の確認）

**準備計算**は、応力解析に先立って解析入力を確定させる計算である。解析を実行する前に
単独で実行でき、階の分布・剛域・地震力（Ai 分布）・風圧力・荷重の集計を確認したうえで
各解析へ進める。

準備計算は解析設定パネルの「🛠 準備計算 実行」で実行し、結果は下ドックの「準備計算」
タブに表示される。各解析（線形静的・荷重組合せ・地震静的・風荷重）の実行時にも
準備計算は自動的に最新化されるため、解析結果は常に確認できる準備計算の内容に基づく。

## 準備計算が確定させる内容

| 項目 | 内容 |
| --- | --- |
| 階（層）データ | 節点標高からの階の判定、階高、剛床（ダイアフラム）、階の地震用重量 Wi |
| 剛域 | 部材端の剛域長 λ・柱フェース距離（接続する直交部材のせいから算定） |
| 床荷重・自重・積載 | スラブ荷重の梁への分配、躯体自重、用途別の積載荷重を標準荷重ケースへ集計 |
| 地震力（Ai 分布） | 設計用固有周期 T・Rt から αi・Ai・Ci・Qi・Pi を算定し、水平力を EX・EY へ生成 |
| 風圧力 | 建物高さ H・速度圧 q・層ごとの見付面積と風圧力・層水平力 |
| モデル整合性チェック | 解析を妨げる不備（支点なし・断面未割当・空の地震荷重ケース参照など）の検出 |

階（層）データは剛域を除くすべての項目の前提であり、階が未定義のまま準備計算を
実行した場合は節点標高から自動生成する。既に階が定義されている場合は、手入力した
地震用重量・階種別を保つため再生成しない（再生成は「🏢 階の自動生成」で行う）。

- 風圧力: [1.2 風圧力](./calc_basis/01_荷重/02_風圧力.md)
- 積載荷重: [1.3 積載荷重](./calc_basis/01_荷重/03_積載荷重.md)
- 床荷重の分配: [1.4 床荷重の分配](./calc_basis/01_荷重/04_床荷重の分配.md)
- 階の生成・地震用重量: [1.6 地震用重量・層データの生成](./calc_basis/01_荷重/06_地震用重量_層データの生成.md)
- 自重: [1.7 自重の長期応力解析への接続](./calc_basis/01_荷重/07_自重の長期応力解析への接続.md)

## 表示される内容

### 階の分布

建物概要（節点数・部材数・支点数・階数・剛床数・地盤面 GL・建物高さ $h$・鉄骨造高さ比
$\alpha$・地震用重量の総和 $\Sigma W$・質量モデル）と、階ごとの一覧を上階から順に示す。

| 列 | 内容 |
| --- | --- |
| 床レベル | 階の標高 [mm]（モデル座標） |
| 階高 | 直下階との標高差 [mm]。最下階は地盤面 GL からの高さ |
| 節点数 | その階に属する節点の数 |
| 剛床数 | その階に定義された剛床（ダイアフラム）の数 |
| 地震用重量 $W_i$ | 階の地震用重量 [kN]（固定荷重＋地震用積載） |
| 累積 $\Sigma W_j$ | 当該階以上の地震用重量の合計 [kN] |
| 構造・種別 | 階の主要構造種別（RC / S / SRC）と階種別（一般 / PH / 地下） |

剛床数が 0 の階、地震用重量が 0 の階には地震力・風荷重を載荷できないため強調表示する。

支点数には、階の自動生成が作る剛床代表節点（面外拘束を持つ仮想節点）は含めない。

### 地震力（Ai 分布）

算定諸元（設計用固有周期 $T$ とその算定法、地盤種別と $T_c$、振動特性係数 $R_t$、
地域係数 $Z$、標準せん断力係数 $C_0$、基部せん断力 $Q_1$、ベースシア係数 $Q_1/\Sigma W$）と、
階ごとの $W_i$・$\Sigma W_j$・$\alpha_i$・$A_i$・$C_i$・$Q_i$・$P_i$ を示す。

$\alpha_i$・$A_i$ は一般階でのみ算定するため、PH 階・地下階の欄は「—」と表示する。
$C_i$ の欄は、一般階では層せん断力係数、PH 階では震度 $k$、地下階では水平震度 $K$ を表す。

層の水平外力 $P_i = Q_i - Q_{i+1}$ に負値が現れて 0 へクランプした場合は警告を表示する
（階の地震用重量の並びが上階ほど重くなっているなど、入力を確認する必要がある）。

設計用固有周期に精算（固有値解析）を選択していて固有値解析が未実行の場合は、
Ai 分布を算定せず、固有値解析の実行を促すメッセージを表示する（略算周期へ黙って
読み替えることはしない）。

### 風圧力

風向によらない算定諸元（建物高さ $H$、基準風速 $V_0$、地表面粗度区分、速度圧 $q$、
$E_r$・$G_f$・$E$）を示したうえで、X 方向・Y 方向それぞれについて基部せん断力と、
階ごとの負担高さ区間・見付幅・見付面積・$K_z$・風圧力・層水平力を示す。見付幅は
風向直交方向の座標範囲で決まるため、方向ごとに異なる。

平面的に一方向へ広がりが無いモデル（平面架構など）では、その方向の見付幅が 0 に
なり片方向だけ算定できない。この場合、算定できなかった風向とその理由を表示する。

風圧力の対象は地上一般階のみで、PH 階・地下階は含まない。

### 剛域

剛域長 $\lambda$ または柱フェース距離を持つ梁要素を一覧する。

| 列 | 内容 |
| --- | --- |
| 材長 $L$ | 節点間距離 [mm] |
| $\lambda_i$ / $\lambda_j$ | 各端の剛域長 [mm]。括弧内は出所（自動／手動） |
| 可とう長 $L'$ | $L' = L - \lambda_i - \lambda_j$ [mm] |
| フェース $i/j$ | 柱フェース距離 [mm]（断面算定の危険断面位置の基準） |
| 剛域比 | $(\lambda_i + \lambda_j) / L$ |

剛域長 $\lambda$ は剛性計算に、フェース距離は断面算定の危険断面位置に用いる別々の量で
あり、S 造の仕口では $\lambda = 0$ でもフェース距離は付く。剛域比が 0.5 を超える部材、
可とう長が 0 以下になる部材は、直交部材せいの入力を確認するため強調表示する。

部材端の剛域を含む立体形状は、モデル化ビュー（結果タブ「モデル化」）でも確認できる。

### 荷重集計

荷重ケースごとの節点荷重数・部材荷重数と、全体座標系での外力の合計
$\Sigma F_x$・$\Sigma F_y$・$\Sigma F_z$ [kN] を示す。部材荷重は、集中荷重はその大きさ、
分布荷重は $\frac{w_1 + w_2}{2}(b - a)$ を作用方向へ投影して積算する（等価節点力へ
置換する前の外力の総和であり、支点反力と釣り合う）。鉛直下向きが負のため、
重力系の荷重ケースでは $\Sigma F_z$ が負値になる。

荷重が定義されていない荷重ケースは淡色で表示する。
